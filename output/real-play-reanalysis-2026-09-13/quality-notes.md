# 재분석 품질 검토 메모

최종 통합 결과가 나오기 전의 구간 응답을 검토한 내용입니다. AI 원문은 ai-output.md에 수정 없이 보존합니다.

## 구간 1

- 개선: 전체 556건 중 47건만 봤다고 명시하며, 구간 안에 상품 선택이 없다는 것으로 범위를 제한했습니다.
- 오류: 목표와 다른 구역의 예로 음료(drink)를 들었습니다. 실제 목표에는 생수(water)가 있고, 생수는 drink 구역에 있습니다.
- 주의: 안내문을 넘긴 행동에서 읽기·절차 이해를 가설로 제시했습니다. 실제 읽기 여부는 알 수 없으며 대안 설명도 함께 읽어야 합니다.

## 구간 2

- 오류: ITEM_SEARCH_STARTED를 검색 기능 활성화, 검색 도구 사용으로 서술했습니다.
- 실제 구현: frontend/src/behavior/marketMovementDetector.ts에서 lastPoint가 없는 첫 이동 샘플에 자동으로 발생시키는 MOVE_IN_MARKET 이벤트입니다. 검색창 조작이나 검색어 입력을 뜻하지 않습니다.
- 영향: 검색 결과를 확인한 뒤 이동했다는 후속 가설도 입력으로 뒷받침되지 않습니다.

## 검사 범위

현재 자동 검증은 JSON 구조, 관찰/한계의 개수와 길이, 근거 ID 존재·범위, 필수 항목, 허용된 난이도 등을 검사합니다. 문장 속 이벤트 의미나 공간/상품 관계의 사실성까지 검증하지 않습니다. 따라서 검증 통과는 내용 정확성의 보증이 아닙니다.


## 최종 실행 결과

18분22초 처리 후 INVALID_AI_ANALYSIS로 실패했다. 11개 구간 중 2개만 통과했으며 최종 통합/연습 계획은 생성되지 않았다. 출력 한도 문제는 이번 실행에서 재현되지 않았지만 배열/문자열 형식 불일치가 3개 응답에서 발생했다.

## 구간 3 (거절된 응답)

- 실제 바나나 1개 선택을 포착했다.
- ITEM_SEARCH_STARTED를 검색 도구 사용으로 오인하는 문제는 계속 나타났다.
- 첫 응답에는 한국어 문장 중 '다음购买商品'이라는 중국어가 섞였다.
- 'produce'를 '생산품 선반'으로 직역한 표현이 나왔다. 원본은 과일/채소 구역이다.
- 첫 응답은 E121~E132를 약 7초로 설명했지만 원본 시각 차이는 0.734초다. 시간 계산도 틀렸다.

## 판단

한도를 늘려 이번에는 JSON 잘림을 피했지만, 현재 구조로는 실제 플레이 전체를 안정적으로 처리하지 못했다. 형식 오류는 명확한 배열 예시·필드별 재시도 오류 안내로, 내용 오류는 이벤트 발생 조건/뜻과 상품-구역 관계를 알려주는 것으로 각각 다뤄야 한다. 검증을 끄는 것은 내용 오류를 고치지 못한다. 이는 한 번의 실행 결과이며 일반적인 정확도 점수는 산출하지 않았다.
