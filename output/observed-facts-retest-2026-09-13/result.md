# 원본 계산값 제공 후 분석 결과

## 변경 사항
- ObservedFacts가 해당 구간의 사건 시각 차이를 ms/초 단위로 계산한다. 반복 이동 샘플·이동 구간 요약 이벤트는 시간 비교 지점에서 제외한다. 사건 자체는 원본 입력에 그대로 남는다.
- 계산값마다 앞/뒤 사건 ID를 붙인다. 세션을 넘어서 계산하지 않고 역전된 시간은 계산하지 않는다.
- 해당 세션의 저장된 장면에서 목표 상품의 categoryId를 추출하고 장면 출처 사건 ID를 함께 보낸다. 현재 상품 목록으로 덮어쓰지 않는다.
- 사건 간 시간 차이는 정지·인지·행동의 지속시간 자체를 의미하지 않는다고 명시한다.
- AiBehaviorAnalysisPromptFactory의 관찰 입력에 observedFacts를 추가하고 프롬프트 버전을 v18로 변경했다.

## 비교 조건
- 동일한 E112–E154, 43개 사건과 이전 이벤트 의미 설명을 사용했다.
- 계산값 추가 전 입력 프롬프트·시스템 지시가 이전 실험과 동일함을 assertion으로 확인했다.
- 8K 문맥을 유지하기 위해 이번 시험의 출력 상한은 1800에서 1606으로 줄였다. 실제 출력 795토큰, stop 종료여서 상한에 잘리지 않았다. 운영의 관찰 출력 상한 1800은 그대로이며 입력 분할에서 추가 사실의 토큰 비용을 계산한다.
- 같은 서버의 임시 내부 게이트웨이를 사용했다. 전체 세션/프로젝트의 운영 API 흐름을 재검증한 것은 아니다.

## 결과
- 호출 216.936초(약 3분 37초), HTTP 200, 형식 및 구간 근거 ID 검사 통과.
- 입력 6147토큰(캐시 5391), 출력 795토큰.
- 입력 처리 3.88초, 생성 208.28초. 이전보다 약 9초 짧지만 캐시·로딩·출력량이 달라 속도 개선 효과로 단정할 수 없다.
- 관련 테스트 14개, 실패 0개.

## 실제 출력 검토
| 항목 | 원본/제공값 | 모델 출력 | 평가 |
|---|---|---|---|
| 이동 정지 기록→선반 열기 | 0.779초 | 약 0.8초 | 반올림 값 일치 |
| 선반 열기→수량 변경 | 1.421초 | 약 1.4초 | 반올림 값 일치 |
| 수량 변경→선반 닫기 | 0.867초 | 약 0.9초 | 반올림 값 일치 |
| 선반 닫기→이동 시작 | 0.559초 | 직후 | 정확한 수치를 출력하지 않아 숫자 검증 대상 아님 |
| fresh 목표 상품 | 우유=fresh, 생수=drink | 흰 우유 | 이번 응답에서 생수 배치 오류 없음 |
| 검색 이벤트 의미 | 이동 시작 시 자동 기록 | 검색 기능 활성화/검색 모드 전환 가능성 | 잘못된 해석 재발 |

## 남은 위험
수치와 근거 ID가 맞아도 해석은 틀릴 수 있다. 이번 출력은 검색 기능 추정과 함께, 짧은 시간 간격으로 탐색 효율성 또는 명확한 의사결정을 추정했다. 전자는 수집 코드와 맞지 않고, 후자는 사건 기록만으로 뒷받침되지 않는다. 반대 설명에 올바른 이벤트 의미를 적었지만 본문 추정을 철회하지 않아 내부 모순도 남았다.
따라서 이번 결과를 전체 품질 개선으로 평가하지 않는다. 확인된 개선은 시간 수치 일치이며, 다음 과제는 사건 정의와 모순되는 설명 및 시간 간격에서 인지·의도를 단정하는 해석을 검증하는 것이다.
