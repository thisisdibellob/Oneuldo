# 장보기 공통 콘텐츠

서버와 프론트가 함께 사용하는 게임 데이터다. 사용자 능력 평가 규칙이나 학습된 모델이 아니다.

- `catalog.json`: 진욱 패키지의 상품 60종. 내용은 원본을 유지하고 저장소에 포함했다.
- `quests.json`: 진욱 패키지의 시나리오 16개 정의. 모든 정의가 실행 가능하다는 뜻은 아니다.
- `runtime.json`: 오늘도 2페이즈 실행 범위. 활성 S01/S02, 가상 초기 재고 5개(구매 단위), 실제 지원 기능만 명시한다.

원본 위치: `jinuk-shopping-ai-evidence-2026-09-04/jinuk-research-2026-09-04/scenario/`.
파일 제공일: 2026-09-04. 통합일: 2026-09-05.

상품 가격·브랜드·재고는 가상이다. 원본의 disclaimer, 구매 단위 의미, 보관 조건 의미를 유지한다. 원문 문헌·검사 도구·RAG 카드는 이 디렉터리에 복사하지 않았다.

`distractor_skus`는 오답 목록이 아니다. S02의 사과 조건은 품종을 제한하지 않으므로 초록 사과도 허용된다. `match`의 조건에 맞는 SKU 후보를 제공하되 AI의 사용자 평가를 대신하지 않는다.

프론트는 이 JSON을 직접 import하며, Gradle `processResources`가 같은 파일을 JAR의 `market/`에 넣는다. 런타임에 사용자 PC의 원본 패키지 디렉터리가 필요하지 않다.

변경 시 카탈로그/시나리오 버전과 양쪽 테스트를 같이 갱신한다. 출시된 버전의 의미를 바꿔 과거 로그의 가격·규격을 덮어쓰지 않는다. 버전 아카이브·seed별 장면 스냅샷은 3페이즈에서 확장한다.
