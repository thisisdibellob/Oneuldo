# 프론트엔드 작업 인수인계

이 디렉터리는 `thisisdibellob/Oneuldo`의 Expo React Native 프론트엔드다. 작업을 시작할 때 [최신 인수인계 목차](../docs/handoff/README.md)와 담당 기능 문서를 먼저 읽는다. 주차별 활동 일지 요청이면 활동 근거와 작성 규칙도 읽는다.

- Git 상태·브랜치·원격을 확인하고, 깨끗할 때만 `git pull --ff-only`로 최신화한다. 기존 변경을 임의로 되돌리지 않는다.
- 현재 작업은 사용자 요청으로 2026-11-15에 `develop`에서 분기한 `feat/8-장보기-게임-구체화`다. `feat/8-시뮬레이션-게임-장보기-구현`의 UI·성능·게임·문서를 이 작업 트리에 함께 반영했다. 이전 브랜치와 `develop`은 보존한다. 기능과 검증 경계는 [장보기 훈련 테스트](docs/market-training.md)를 읽는다. 신규 작업은 팀의 Issue 연결 `feat/... → develop PR` 흐름을 따른다. `main`, `release`, `develop` 직접 커밋/푸시, force push, `git reset --hard`를 금지한다. 커밋·푸시는 사용자 요청 범위에서 한다.
- `backend/`, `docs/collaboration.md`, 다른 사람의 브랜치, 이전 개인 저장소는 요청 없이 변경·삭제하지 않는다.
- Expo SDK와 의존성은 현재 `package.json`·`pnpm-lock.yaml`을 따른다. 과거 SDK 54 문서로 다운그레이드하지 않는다. Flutter나 새 게임 엔진을 임의로 도입하지 않는다.
- 모바일 우선, 공통 이동/상호작용 UI, 기존 폰트, 모션 감소, 하나의 마을 안에서 연결되는 생활 게임 흐름을 유지한다. UI/아트 변경은 최신 사용자 지시와 현재 스타일을 따른다.
- 코드 변경은 타입 검사·관련 테스트를 하고 범위에 따라 전체 테스트/웹 빌드를 확인한다. 문서 변경은 내용·링크·Git diff를 검토한다.
- 게임 스크린샷은 `http://localhost:8081/` 기본 앱에서 실제 게임 진입 흐름을 거쳐 촬영한다. `marketLab` 등 게임 전용 개발·테스트 진입 화면의 캡처로 대신하지 않는다. 사용자 요청(2026-11-20)이며, 이 지침 추가를 위해 기존 스크린샷을 다시 찍지는 않는다.
- “서버 열어줘”는 Expo Go 외부 터널까지 의미한다. 로그인 상태를 확인하고 현재 터널 manifest·QR·Expo Go 직접 링크·웹 링크를 제공한다. 실행한 서버는 종료 요청까지 유지한다. 자세한 절차는 인수인계의 실행 절을 따른다.
- `.env*`의 비밀값, 로그인 파일, `node_modules`, `.expo`, `dist`, 개인 PC 설정을 커밋하지 않는다.
- 현재 코드, 과거 보고서, 요청만 받은 기능, 실제 기기 검증, 연구 해석을 구분한다. 주차별 일지에서 커밋 날짜를 실제 개발일로 단정하지 않는다.
