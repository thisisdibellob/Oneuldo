# 웹 폰트

기존 OTF/TTF의 전체 글리프와 Unicode 매핑을 유지한 WOFF2 파일입니다. 한글을 일부 글자로 제한하는 서브셋을 만들지 않습니다. 원본 파일은 iOS/Android에서 그대로 사용합니다.

- 전체 폰트: 19,418,688 → 7,449,340바이트, 61.64% 감소
- 로그인 첫 화면에 필요한 3개 폰트: 1,314,268바이트
- 나머지 8개는 로그인 화면이 그려진 뒤 미리 불러옵니다. 앱 본문과 개발용 마트 화면은 필요한 폰트가 모두 준비된 후 표시합니다.
- 모든 이름·매핑·글리프 순서·윤곽선·힌팅·레이아웃 테이블을 검증했습니다. WOFF2 컨테이너 변경에 필요한 체크섬, head 플래그 bit 11과 오래된 DSIG 서명만 예외입니다.
- 폰트 로딩이 30초 이상 걸리거나 실패하면 다시 시도할 수 있으며, 다운로드 중인 본문을 대체 폰트로 먼저 표시하지 않습니다.

재생성: 임시 개발 환경에 `fonttools[woff]==4.65.0`을 설치한 뒤 `python scripts/generate-web-fonts.py`를 실행합니다. 앱 실행에 Python 의존성은 없습니다. 원본/압축 SHA-256, 모든 글자 수와 바이트 수는 [manifest.json](manifest.json)에 기록합니다.
