사용자 소유 Figma `qhD1bhkDWesf29T22fWlhP`의 Sett3~Sett5에서 2026-11-13에 내려받았다. 생성 이미지나 대체 아이콘을 사용하지 않는다. 임시 Figma 다운로드 URL은 런타임에서 참조하지 않는다.

- `layout-edit.png`: Sett3의 `568:4376` / Sett4의 `568:4385`에서 참조하는 원본 이미지. UI 표시 86×86dp. 다운로드 이미지에 반영된 투명도를 중복 적용하지 않는다.
- `direction-pad.svg`: Sett5 `568:4568`의 원본 84×84 SVG. `direction-pad.png`는 원본 도형을 수정하지 않고 투명 배경으로 3배 래스터화했다. UI는 84×84dp에 표시하며 네 방향의 터치 영역은 별도로 제공한다.
- `chevron-up.svg`: 구조/목록 펼치기의 원본 8.93119×8 SVG. 원본 크기를 유지하여 시안의 12×12 프레임 안에 배치한 투명 PNG를 사용한다.
- `step-up.svg`: 인원 조절의 원본 17.8624×16 SVG. 시안의 24×24 프레임 안에서 원래 크기를 유지해 투명 PNG로 제공한다. 아래쪽 화살표는 프레임을 180도 회전한다.

PNG 사용은 iOS/Android에서도 동일한 에셋을 표시하기 위한 것이다. SVG 도형 경로·색상은 수정하지 않았다. Figma 노드 전체 PNG 내보내기에 섞였던 초록 바탕은 사용하지 않고, 원본 SVG의 투명 영역을 유지한다.
