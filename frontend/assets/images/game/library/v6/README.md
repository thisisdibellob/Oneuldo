# 연결 서가와 양면 서가 v6

2026-10-01 사용자 피드백: 서로 다른 크기의 책장이 독립 카드처럼 떠 있는 기존 배치를 실제 도서관에 가까운 연결 서가와 통로로 바꾼다.

## 새 이미지

내장 `image_gen`으로 네 이미지를 생성했다. 스타일 참고는 v4 안내 데스크와 v5 추천 도서 전시대다. 모두 정면에서 윗면이 조금 보이는 동일한 투시, 밝은 목재·갈색 선·세이지 받침을 사용한다.

- `wall-left.png`: 세 칸·세 단 연결 서가. 총류·철학·종교에 사용한다.
- `wall-right.png`: 같은 규격의 세 칸·세 단 연결 서가. 사회과학·자연과학·기술과학에 사용한다.
- `island-arts.png`: 두 칸·두 단의 낮은 양면 독립 서가. 예술·언어에 사용한다.
- `island-story.png`: 같은 규격, 책 배치가 다른 낮은 양면 독립 서가. 문학·역사에 사용한다.

`source/*.png`는 생성 원본이며 `source/prompts.json`은 실제 프롬프트다. `scripts/prepare-library-art-v6.cjs`로 알파 경계를 자르고 두 종류의 가구별로 높이와 너비를 맞춘다. 미세한 생성 비율 차이를 정규화하여 옆으로 연결했을 때 상판·받침 높이가 일정하다. 가장자리에 투명 여백 2px을 유지한다. 런타임은 벽 서가 1200×368, 양면 서가 800×248로 실제 표시 크기의 두 배 이상이며, 합계 2,532,223바이트다.

## 배치와 검증 기준

- 뒤벽은 **창문 → 570×174.8 연결 서가 → 창문 → 570×174.8 연결 서가 → 창문** 순서다. 창문 x=50/840/1630, 서가 x=250/1040이며 사이 간격은 모두 20px, 양끝 여백은 각각 50px이다. 두 서가는 이전 600×184의 95%로 같은 비율을 유지한다. 여섯 칸은 000→500 순서다.
- 서가 밑동은 y=320으로 벽·바닥 접점 y=300보다 20px 앞에 놓인다. 뒤쪽과 밑동에 얕은 그림자를 두어 가구 두께가 보이게 했으며 충돌 범위와 이용 지점(y=392)은 새 크기·바닥에 연동한다. 벽 뒤쪽으로 걸어들어갈 틈은 두지 않는다.
- 중앙 두 양면 서가는 400×124이며 사이 통로는 200px이다. 왼쪽·가운데·오른쪽과 양면 서가 뒤쪽을 실제로 걸어갈 수 있다.
- 생성 그림의 공통 헤더 위에 18px 분류 번호·이름을 한 줄로 부착한다. 바닥에 떠 있던 분류 카드와 서가 아래 러그는 제거했다.
- 창문은 책장 옆에 180×162 영역 안에서 원본 비율을 유지하여 배치했고, 창턱은 바닥보다 50px 높다. 큰 창문을 수용하도록 방 너비를 1860px로 늘렸고 높이는 1520px다. 시계와 벽등은 창문·책장과 겹치지 않는다. 캐릭터, PC, 안내 데스크, 라운지 크기는 유지했다.
- 가구 단위 충돌 범위를 사용하여 칸 사이를 통과할 수 없다. 렌더·이동 회귀 검사는 양면 서가의 앞뒤, 벽 서가 앞쪽, 모든 업무 지점 사이 경로, 모든 통로, 투명 PNG 해시·크기를 확인한다.
- 좁은 화면은 캐릭터 발의 화면 초점을 최대 445px, 하단 여유 최소 128px로 맞춘다. 375×812와 320×568에서 여섯 벽 서가의 실제 이용 지점과 벽 최접근 위치를 이동시켜 분류 표지가 업무 카드 아래에 나타나고 하단 툴바 위에 28px 이상 여유가 남는지 검사한다. 넓은 화면 카메라는 그대로다.
