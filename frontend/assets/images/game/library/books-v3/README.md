# 도서관 신규 표지 14종

2026-10-01 내장 `image_gen.imagegen`으로 책마다 한 번씩 생성한 고유 표지다. 기존 `book-01.png`~`book-12.png`는 변경하지 않았으며, 총 26권을 `src/game/libraryArt.ts`의 책 ID별 정적 require로 연결한다. 카탈로그 순서나 나머지 연산으로 표지를 선택하지 않는다.

- `<book-id>.png`: 게임에서 불러오는 높이 256px PNG. 전체 14개 약 1.61MB.
- `source/<book-id>.png`: 생성 원본을 바이트 그대로 보존한 PNG.
- `source/qa-contact-sheet.png`: 최종 신규 표지 14종 검수판.
- `asset-manifest.json`: 기존 12권과 신규 14권의 ID, 파일, 해시, 크기, 알파 통계.
- `prompts.json`: 14개 정확한 생성 프롬프트와 원본 경로.
- `provenance.json`: 원본 및 런타임 해시, 크롭·축소 방식, 시각 검수 결과.
- `provenance-main.json`, `provenance-half.json`: 두 병렬 제작 묶음의 상세 기록.

표지는 기존 그림처럼 따뜻한 갈색 외곽선, 둥근 모서리, 정면 표지, 얇은 왼쪽 책등과 아래 페이지 가장자리를 사용한다. 책 제목은 UI가 표시한다. 언어 표지의 `가`, `나`, `다`, `Hello`만 주제 삽화에 들어간다.

보이는 실루엣의 알파가 16보다 큰 경계를 기준으로 원본 8px 여백을 더한 직사각형을 크롭했다. 크롭 안의 원본 색상과 알파는 수정하지 않았다. Lanczos3로 높이 252px까지 같은 비율로 축소한 뒤 사방에 투명 2px을 추가했다. 직접 그리기, 재색칠, 픽셀별 알파 제거는 사용하지 않았다. 모든 원본과 게임용 표지의 전체 외곽·삽화·문자·잘림 여부를 시각 검수했다.

`finalize-covers.cjs`는 Node.js와 `sharp`로 전체 매핑·원본 해시·PNG 규격·투명 테두리·고유 이미지 해시를 검사하고 최종 manifest, provenance, prompts 및 검수판을 재생성한다. `sharp`를 사용할 수 있는 환경에서 이 폴더의 스크립트를 실행한다. 생성 원본을 보존하므로 생성 도구의 개인 PC 경로가 없어도 검증할 수 있다.
