# 도서관 게임 이미지

2026-09-29, 도서관 첫 근무 게임을 위해 새로 생성한 원본 이미지와 런타임 PNG입니다.

## 제작 방식

- 생성 및 투명 배경 보정: 내장 `image_gen.imagegen` 도구. API/CLI 대체 경로는 사용하지 않았습니다.
- 플레이어 원본 `Group 6854.png`는 사서의 그림체·갈색 선·비율 참고용으로만 사용했습니다. 사서는 별도 캐릭터로 생성했습니다.
- 가구는 정면 평행 시점, 오크·크림·세이지 팔레트, 굵고 둥근 갈색 선을 공통 기준으로 삼았습니다.
- `prompts.json`에 실제 생성/보정 프롬프트를 저장했습니다.
- `source/`에는 선택된 생성 원본, 플레이어 스타일 참고 원본, 확인용 합성 이미지를 보관했습니다.
- 캐릭터나 가구의 그림을 코드로 새로 그리거나 대체하지 않았습니다. `scripts/prepare-library-art.cjs`는 생성된 RGBA의 알파를 유지하며 개별 영역 추출과 크기 조절만 수행합니다.

## 코드 연결

`src/game/libraryArt.ts`의 `libraryArt`가 모든 런타임 파일을 정적 require로 내보냅니다. `books`는 위 표 순서와 같습니다. 이미지의 가로세로 비율은 `contain`으로 유지하고, 캐릭터·가구의 발밑을 월드 좌표의 기준으로 정렬합니다.

재추출이 필요하면 Sharp를 사용할 수 있는 Node 환경에서 `node scripts/prepare-library-art.cjs`를 실행합니다. 앱 런타임에는 Sharp가 필요하지 않습니다. 정확한 원본 추출 좌표와 결과 크기는 `asset-manifest.json`에 기록되어 있습니다.
