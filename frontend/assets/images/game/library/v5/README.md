# 도서관 실내 장식 v5

2026-10-01 사용자 요청에 따라 아치 창문, 낮은 추천 도서 전시대, 두 화분 묶음을 새로 생성했다. `source/prompts.json`에 실제 생성 프롬프트와 스타일 참조를 보관했다. `source/*.png`는 내장 `image_gen` 도구의 원본이며 runtime 파일은 같은 이름의 상위 PNG다.

- 기존 v4 안내 데스크와 v2 낮은 서가를 그림체 기준으로 사용했다. 정면에서 윗면이 살짝 보이는 투시, 크림·세이지·따뜻한 목재와 작은 테라코타 포인트를 유지했다.
- 생성 배경의 알파를 보존했다. `scripts/prepare-library-art-v5.cjs`는 원본 알파 경계만 자르고 모바일용 384–640px 이미지로 줄이며 투명 여백 3px을 넣는다. 색·형태를 코드로 다시 그리지 않는다.
- `libraryWorld.ts`의 장식 정보가 그림 크기, 바닥 충돌 범위, 앞뒤 표시 순서의 공통 기준이다. 창문은 벽에만 배치하며 충돌체를 추가하지 않는다.
- 방 1660×1520, 캐릭터·사서·안내 데스크 356×116·중앙 라운지 250×114의 크기는 유지했다. 전시대와 식물은 업무 통로 바깥에 배치했다.
- 10개 서가, 안내·검색 자리, 반납 카트, 확인함, 이용자, 출입문의 접근 지점을 그대로 유지했다.

목재 벽 몰딩과 하부 패널, 작은 벽시계·벽등, 공간별 러그와 입구 발매트는 기존 React Native 도형으로 구성했다. 조명 깜빡임이나 임의의 파티클은 사용하지 않는다.
