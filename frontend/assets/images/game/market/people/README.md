# 마트 인물 아트

현재 사용: `*-chibi-v2.png` 16종. 종업원 4종, 성인·노년·어린이 손님 각 4종이다. 기존 `*-v1.png`는 보존한다.

- 기준: 플레이어 `characters/player/chibi-user-v3/chr_player_chibi_front_idle_f00.png`의 큰 머리·짧은 팔다리, 갈색 윤곽선, 단순한 얼굴과 차분한 색감.
- 제작: 내장 `image_gen`으로 인물마다 별도 편집했다. 기존 머리 모양·의상·안경·연령 구분을 참고했다. 원본과 생성 출력의 실제 경로·프롬프트는 로컬 검증 폴더에, 이식 가능한 최종 파일·해시·프롬프트는 [chibi-v2-prompts.json](chibi-v2-prompts.json)에 기록했다.
- 패키징: 투명 여백을 정리하고 종횡비를 유지해 리사이즈했다. 256×384 캔버스, 약 344px의 불투명 인물 높이, 신발 하단을 공통 바닥에 정렬한다. 그림을 가로나 세로로 따로 늘이지 않는다.
- 화면: 성인은 약 92 월드 px로 플레이어의 약 86px와 비슷한 크기다. 어린이는 기존 0.76배를 유지한다. 발 기준 위치와 기존 물리 충돌 범위를 보존한다. 새 그림의 폭과 머리 크기로 이동·상호작용 판정을 확대하지 않는다.
- 계산대 직원도 같은 아트를 사용한다. 가까운 종업원의 말풍선은 새 머리 위에 배치한다. 인물 아래 이름표는 다시 추가하지 않는다. 정지 인물 그림이며 NPC 걷기 스프라이트를 새로 제작한 것은 아니다.
- 런타임에는 `marketPeopleArt.ts`의 정적 require만 사용한다. 생성 원본은 앱에서 불러오지 않는다. Image의 초기 페이드는 끈다.

패키징 스크립트: `frontend/scripts/prepare-market-chibi-people.cjs`.
