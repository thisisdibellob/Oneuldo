# 플레이어 앞대각선 걷기 v4

2026-09-23에 검수한 `revision-v4-root` 후보를 게임에 적용했다. 오른쪽 앞(`frontRight`)과 왼쪽 앞(`frontLeft`)의 걷기만 교체하며, 각 8프레임의 1배(128×192)·2배(256×384) PNG 총 32개를 포함한다. 다른 여섯 방향과 모든 정지 이미지는 기존 `fresh-v1` 에셋을 계속 사용한다.

## 제작과 정렬

기존 플레이어 그림체를 참고해 전신 걷기 이미지를 생성하고, 02·04·05·06·07의 자세를 이미지 생성 도구로 교정했다. 특히 04의 팔과 어깨 연결, 02·06의 낮은 통과 자세, 05의 지지 다리, 07의 다음 발 전진을 확인했다. 교정 프롬프트는 함께 둔 `revision-prompts.json`에 기록했다. 왼쪽 앞 이미지는 오른쪽 앞 이미지의 좌우 반전이다.

생성된 전신 이미지의 배경을 투명하게 처리하고 전체 크기와 위치를 정렬했다. 머리·몸·팔·다리를 잘라 교체하거나 합성하지 않았으며 관절이나 신체 일부를 별도로 늘이거나 줄이지 않았다. 교정 원본 5개에는 동일 배율을 적용했다.

최종 `revision-v4-root`에서는 v4의 전신 그림 전체를 정수 Y좌표로만 이동했다. X좌표, 크기, 신체 부위 사이의 상대 위치와 가시 픽셀의 색상은 그대로다. 캔버스 밖으로 잘린 부분은 없다. 1배 파일은 정렬한 2배 파일에서 다운샘플링했다. 적용 시 `_v3` 파일명만 `_v4`로 바꾸었으며 PNG 내용은 검수 후보와 바이트 단위로 같다.

## 보행 위상과 발의 깊이

앞대각선에서는 앞으로 내민 발이 몸 아래를 통과하는 발보다 화면에서 낮게 보인다. 매 프레임 가장 낮은 발바닥을 같은 Y에 고정하면 이 깊이 차이가 몸 전체의 상하 흔들림으로 바뀌므로, 최종 정렬은 그 방식 대신 전체 캐릭터의 높이를 안정시켰다.

2배 캔버스에서 머리 꼭대기는 `[29, 32, 27, 28, 29, 32, 27, 28]`, 최저 발바닥은 `[375, 376, 365, 369, 372, 370, 356, 362]`다. `ModularCharacter`의 기본 게임 표시 비율을 이 캔버스 좌표로 환산하면 그림자 중심은 Y356, 세로 범위는 Y332~380이다. 06의 통과 발은 그림자 중심, 00의 전진 발은 앞쪽에 놓인다. 머리 높이 범위는 17px에서 5px로 줄었다. 이 수치는 정렬 근거이며 실제 접지감은 그림자와 게임 이동을 포함한 반복 재생으로 확인했다.

게임의 보행 위상은 실제 이동거리로 진행한다. 이동속도와 보행 한 주기 거리 144는 이번 이미지 적용에서 변경하지 않았다.
