# 사용자 제공 캐릭터 게임 적용 후보

사용자가 제공한 `f2f2cbb8-1631-463a-96f2-2460c054a8b7.png` (3840×2160)에서 분리한 캐릭터다. 원본 그림을 다시 생성하거나 팔다리·얼굴을 변형하지 않았다. 배경 투명화, 전체에 동일한 배율 적용, 좌표 정렬 후 확정된 PNG를 바이트 그대로 복사했다.

- 제공 방향: 정면, 오른쪽 앞, 오른쪽. 왼쪽 앞과 왼쪽은 각각 오른쪽 그림의 수평 반전이다.
- 게임에 사용할 방향: 위 5개. 뒤쪽 3방향 그림은 원본에 없으므로 뒤왼쪽은 왼쪽, 뒤오른쪽과 뒤는 오른쪽 그림을 임시로 사용한다. 뒤쪽 전용 걷기 그림이 추가되면 교체해야 한다.
- 걷기: 원본 방향별 36프레임 중 18~33의 16프레임을 순서대로 사용한다. 파일의 walk_f00~f15가 원본 18~33에 대응한다.
- 정지: 정면은 원본 00, 나머지 네 방향은 원본 06 한 장씩 사용한다. 파일명은 idle_f00이다.
- 크기: 논리 PNG 128×192, @2x PNG 256×384. 기준점은 논리 좌표 (64, 186).
- 파일 수: 5방향 × (정지 1장 + 걷기 16장) × 2밀도 = PNG 170장.
- 게임 매핑: `frontend/src/game/chibiPlayerAvatar.ts`의 `chibiPlayerAvatar`. Metro 정적 require를 사용한다.
