# 마을의 민수·지영 — chibi v1

2026-09-26 사용자 요청으로 제작. 원본 주인공의 둥근 비율, 갈색 윤곽선, 부드러운 채색을 기준으로 민수와 지영을 각각 만들었다.

- 민수: 사용자가 다시 선택한 이전 모습. 둥근 검정 머리와 원래 세로 타원 눈, 기본핏 흑백 체크 셔츠·흰 이너·연청 바지. 앞머리 끝을 조금 가볍게 정리하고, 주인공 원본을 참고한 굵은 회갈색 선·연한 갈색 입 및 깨끗한 채색을 적용했다.
- 지영: 갈색 중단발 웨이브, 흰 긴팔 상의, 검정 긴바지.
- `*-turnaround.png`: 정면 / 오른쪽 앞 사선 / 오른쪽 측면 / 오른쪽 뒤 사선 / 뒷면의 투명 PNG 시트.
- `*-front.png`, `*-front@2x.png`, `*-front@3x.png`: 정면 PNG의 128×192, 256×384, 384×576 버전. 생성 원본에서 각각 축소해 저장한다.
- `*-front-display.png`: 실제 마을이 불러오는 384×576 정면 PNG. 웹의 정적 이미지 import가 1x 파일을 선택해 확대 시 흐려지는 현상을 확인하여, 화면용은 높은 해상도를 명시했다. 표시 크기는 계속 `ModularCharacter`의 128×192 논리 캔버스와 배율 0.5를 따른다.
- 발 기준점은 (64,186)이며 주인공과 동일한 게임 배율 0.5를 사용한다. 민수와 지영 모두 그림 키를 170px 기준으로 맞췄다(주인공 대기 프레임 170~172px). 얼굴·옷의 고유 비율은 비례 축소로 유지한다.
- 기존 NPC 위치, 대화와 퀘스트 연결은 유지했다. 이번 작업은 정면 정지 그림이며 걷기 애니메이션은 추가하지 않았다.

## 생성 및 가져오기

내장 `image_gen`으로 캐릭터를 생성했다. 전체 프롬프트는 `prompts.json`에 보관했다. 첫 생성의 체크무늬는 실제 픽셀이어서 사용하지 않았다. 같은 도구로 단색 초록 분리 배경을 가진 시트를 만든 뒤, 게임용 이미지 가져오기 스크립트에서 그 색을 알파로 변환하고 정면을 잘라 크기와 발 위치를 맞췄다. 흰 옷과 신발은 불투명하게 보존했다.

`source/`는 최종 선택한 생성 원본이며 앱에서 불러오지 않는다. 재생성 없이 PNG 포장만 다시 하려면 `frontend/`에서:

```powershell
node scripts/prepare-village-friends.cjs assets/images/game/characters/village/chibi-v1/source/minsu-key.png assets/images/game/characters/village/chibi-v1/source/jiyoung-key.png
```

원본 플레이어 레퍼런스는 `../../player/reference/player-original-turnaround.png`에 별도로 보관되어 있다.

## 민수 수정

### 현재 사용 버전: 굵고 깨끗한 갈색 선·검정 머리

복원한 민수의 얇고 붉은 선을 주인공 원본의 저채도 갈색 선을 참고해 굵게 정리했다. 선의 얼룩과 머리의 잘게 끊긴 광택을 줄이고, 색 보정으로 입과 외곽선의 붉은 기를 완화했다. 사용자의 추가 지시대로 머리 채움색은 모든 방향에서 붉은기 없는 부드러운 검정으로 맞췄다. 얼굴·눈·머리 형태와 기본핏 셔츠 디자인을 유지했다.

전체 편집 프롬프트는 `minsu-bold-clean-lines-prompts.json`, 수정 전 그림은 `source/minsu-key-v6.png`에 보관했다. 현재 원본 `source/minsu-key.png`에서 투명 시트와 게임용 정면 1x/2x/3x 및 표시 파일을 다시 추출했다. 게임의 키·발 기준점·위치는 동일하다.

### 이전 버전: 사용자가 선택한 이전 원화 복원

첨부 `codex-clipboard-62b4ab56-c683-4b19-9608-cb4851ef1201.png`가 `source/minsu-key-v2.png`와 RGBA 픽셀까지 동일함을 확인했다. 이 그림을 편집 기준으로 사용해 얼굴·눈매·체형·옷·머리의 전체 형태를 이전 디자인으로 복원했다. 수정 범위는 앞머리 끝의 미세한 정리, 주인공을 참고한 옅은 갈색 외곽선·입, 표면의 자글자글한 채색 정리다. `minsu-restored-clean-prompts.json`에 내장 이미지 생성 도구의 전체 프롬프트를 보관했다.

현재 원본은 `source/minsu-key.png`. 직전의 새 원화는 `source/minsu-key-v4.png`로 보관한다. 이 복원은 민수의 그림에 한정하며, 지영의 현재 크기와 양쪽의 고해상도 표시 파일, 기존 대화 기능은 유지한다.

추가 요청으로 셔츠의 어깨·소매·몸통 여유만 줄여 주인공의 오버핏 후드와 구분되는 기본핏 셔츠로 정리했다. 얼굴·머리·선 색과 바지통은 복원본을 유지한다. 해당 편집 프롬프트는 `minsu-shirt-fit-prompts.json`, 셔츠 수정 전 복원본은 `source/minsu-key-v5.png`에 보관한다.

### 이전 버전: 새 원화

이전 편집에서 생긴 질감과 형태 누적을 피하기 위해 기존 민수 그림을 입력하지 않고, 사용자의 `Group 6854.png`와 새 헤어·눈매 참고 사진으로 처음부터 생성했다. 눈매는 단순한 타원 형태를 유지하면서 조금 덜 세로로 길게 조정했다. 바지통은 더 좁히고 체크 셔츠는 더 여며 흰 이너가 적게 보인다. 검정 머리·바지통 보정 한 차례를 거쳐 적용했다. `minsu-fresh-redraw-prompts.json`에 전체 프롬프트를 보관한다. 이전 단계 원본은 `source/minsu-key-v3.png`이다.

지영은 그림을 다시 그리지 않고 키 기준만 174→170px로 줄여 민수와 맞췄다. 두 캐릭터 모두 3x 에셋을 추가했다.

### 이전 수정 이력

사용자의 헤어 사진을 참고해 가운데 가르마와 삐친 머리를 없애고, 이마를 덮는 차분한 검정 앞머리로 수정했다. 바지통도 줄였다. `minsu-revision-prompts.json`에 내장 이미지 생성 도구로 실행한 수정 프롬프트를 보관했다. 최초 생성 원본은 `source/minsu-key-v1.png`, 현재 원본은 `source/minsu-key.png`이다. 지영의 이미지는 변경하지 않았다.

추가 피드백에서 일자 앞머리와 검은 선이 묵직해 보인다는 점을 반영했다. 주인공의 회갈색 윤곽선·연갈색 작은 입을 참고하고, 머리와 볼의 둥근 덩어리를 줄였다. 앞머리는 가느다란 가닥이 서로 다른 길이로 내려오도록 바꿨다. 머리카락 내부는 검정 차콜을 유지한다. 최종 프롬프트는 `minsu-soft-lines-prompts.json`, 직전 일자 앞머리 버전은 `source/minsu-key-v2.png`이다. 현재 키 170px과 발 기준점은 유지했다.
