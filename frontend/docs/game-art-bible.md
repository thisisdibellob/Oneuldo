# 오늘도 게임 아트 바이블 v0.1

## 핵심 방향

오늘도의 게임 월드는 **한국의 일상 공간을 따뜻한 손그림으로 표현한 소프트 쿼터뷰 생활 훈련 게임**으로 제작한다.

- 탐색과 공간 이해: 고정 3/4 소프트 쿼터뷰
- 정확한 생활 훈련: 정면 클로즈업 미니게임
- 정서: 따뜻함, 신뢰감, 잔잔한 즐거움, 안전한 도전
- 표현: 비유아적 귀여움, 명확한 상호작용, 한국 생활 공간
- 고유 요소: 사람 캐릭터, AI 로봇 오늘이, 마트·버스·아파트·편의점·주민센터

특정 게임의 캐릭터, 마을, 가구, UI, 팔레트와 장면 구도를 복제하지 않는다. 생활형 게임 장르의 아늑함과 작은 일상의 발견이라는 넓은 원칙만 참고한다.

## 카메라와 화면

- 카메라: 고정 3/4 정사영에 가까운 소프트 쿼터뷰
- 바닥 축: 수평선 기준 좌우 약 `26deg`
- 회전: 없음
- 임의 확대·축소: 없음
- 기준 화면: 세로 모바일 `375 x 812` 논리 픽셀
- 좌우 안전 여백: 최소 `16px`
- 상단 HUD 안전 영역: `56~72px`
- 하단 조작 영역: `88~112px`
- 캐릭터 위치: 화면 중앙보다 조금 아래
- 상호작용 대상 터치 영역: 최소 `48 x 48px`

장면은 원경, 바닥, 후면 구조물, 캐릭터·NPC, 상호작용 소품, 전경 가림, 효과, React Native HUD 순으로 분리한다. 캐릭터와 소품의 앞뒤 순서는 발바닥 pivot의 월드 `Y` 좌표로 결정한다.

## 시각 언어

- 디지털 과슈와 고운 종이의 조합
- 둥글고 약간 불규칙한 외곽선
- 외곽선 색상: 순수 검정 대신 `#35485A` 또는 `#514841`
- 캐릭터 외곽선: 최종 논리 크기 기준 `1.8~2.2px`
- 명암: 기본색, 그늘, 밝은 면의 최대 3단계
- 종이 입자: 최종 화면에서 `3~5%` 불투명도
- 기본 광원: 화면 왼쪽 위 10시 방향
- 접지 그림자: 별도 타원 레이어, `12~18%` 불투명도
- 배경은 저채도, 상호작용 대상은 더 선명한 실루엣
- 이미지에 글자를 굽지 않고 모든 이름과 안내는 코드로 표시

### 브랜드 포인트

| 역할 | 색상 | 사용 |
|---|---:|---|
| 오늘 블루 | `#4A90E2` | 안내, 이동, 신뢰 |
| 포근 민트 | `#6BC6A4` | 기본 강조, 성공, 성장 |
| 햇살 옐로 | `#FFD561` | 보상, 발견, 따뜻한 조명 |
| 살구 피치 | `#FFBFA6` | 친근함, 인물 포인트 |
| 라이트 스카이 | `#E8F3FF` | 넓은 배경 보조색 |
| 소프트 그레이 | `#F2F4F7` | 중립 배경과 비활성 영역 |

중립·자연색 70%, 장소 고유색 20%, 브랜드 포인트 10%를 기본 비율로 사용한다. 상태는 색상만으로 표현하지 않고 아이콘, 윤곽선, 모양과 짧은 문구를 함께 사용한다.

## 모듈 캐릭터 규격

- 논리 캔버스: `128 x 192px`
- 제작 마스터: `512 x 768px`
- 기본 런타임 출력: `256 x 384px`
- pivot: 논리 좌표 `(64, 186)`
- 발바닥 기준선: `y=186`
- 하단 안전 여백: `6px`
- 월드 표시 높이: 약 `86~96px`
- 모든 파츠와 프레임은 동일한 캔버스와 pivot을 유지
- 파츠별 자동 크롭 금지

### 레이어 순서

1. `shadow`
2. `hair_back`
3. `body_skin`
4. `shoes`
5. `bottom`
6. `top`
7. `outerwear`
8. `face`
9. `hair_front`
10. `eyewear`
11. `headwear`
12. `bag_back` 또는 `bag_front`
13. `hand_item_back`
14. `hand_item_front`
15. `effect`

### 방향과 애니메이션

- 방향: `front`, `back`, `right`; `left`는 반전 가능한 파츠만 `right`를 사용
- 비대칭 헤어, 문자, 가방은 `left` 전용 에셋 제작
- `idle`: 2프레임, 1.5~2fps
- `walk`: 4프레임, 8fps
- `interact`: 3프레임, 6fps
- `celebrate`: 5프레임, 8fps
- 표정: `neutral`, `happy`, `thinking`, `surprised`, `proud`

초기 팔레트는 피부색 6종으로 제한한다. 헤어와 의상의 형태·선·명암 레이어는 유지하고 승인된 팔레트로만 색을 바꾼다.

## 환경과 상호작용

- 마트 진열대, 장바구니, 계산대
- 한국형 버스정류장, 노선 안내, 교통카드 단말기
- 아파트 현관, 엘리베이터, 우편함
- 편의점 냉장고와 상품 선반
- 횡단보도와 보도블록
- 주민센터와 직업 훈련 공간

실제 상표와 제품 로고는 사용하지 않는다. 과제에 관계없는 장식은 상호작용 대상처럼 강조하지 않는다. 같은 기능의 물체는 같은 선택 효과와 안내 방식을 사용한다.

## 접근성

- 한 화면에서 핵심 목표 하나만 강조
- 아이콘과 짧은 텍스트를 함께 사용
- 빠른 화면 흔들림, 강한 줌, 섬광과 과도한 패럴랙스 금지
- 모션 감소 설정에서 바운스, 파티클과 카메라 이동 축소
- 오답에 시간 압박이나 조롱하는 실패 연출 사용 금지
- 힌트 사용 시 목적지와 안전한 이동 경로를 직접 표시
- 목적지 터치 자동 이동을 기본으로 제공하고 조이스틱은 선택 기능으로 유지
- 핵심 물체 주변의 장식 밀도와 배경 대비를 낮춰 인지 부담 감소

## 파일 규칙

- 캐릭터와 투명 소품: PNG
- 대형 불투명 배경: WebP 또는 PNG 원본 후 WebP 변환
- 파일명: 영문 소문자 `snake_case`
- 생성 원본과 승인된 런타임 에셋 분리
- 이미지 안의 표시명은 만들지 않고 TypeScript 데이터에서 관리

예시:

```text
chr_player_hair_front_bob01_blue_front_idle_f00@2x.png
chr_player_top_hoodie01_mint_right_walk_f02@2x.png
scene_mart_floor_day@2x.webp
scene_mart_structure_back_day@2x.webp
prop_food_milk01_default@2x.png
```

## 생성과 승인 절차

1. 골든 캐릭터와 마트 장면을 생성한다.
2. 카메라, 선, 팔레트, 광원과 인체 비율을 승인한다.
3. 승인된 이미지를 이후 모든 생성·편집의 기준으로 사용한다.
4. 동일한 몸체에서 헤어, 표정과 의상을 한 요소씩 분리·편집한다.
5. 투명 배경, 캔버스, pivot과 레이어 경계를 검사한다.
6. Expo 앱에서 조합하고 375px 실기기 화면을 검수한다.
7. 승인된 에셋만 런타임 manifest에 등록한다.

AI 생성 결과는 바로 최종 에셋으로 간주하지 않는다. 손, 얼굴, 의상 경계, 투명 가장자리, 원근과 파츠 정렬을 반드시 검수한다.
