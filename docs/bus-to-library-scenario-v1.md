# 도서관 가는 길 — 마을 안의 버스 이동 시나리오 v1.2

작성일: 2026-09-29

검토·수정일: 2026-09-29

상태: 첫 플레이 가능 버전 구현 완료. 구현 범위와 확인한 항목, 후속 검증은 11절에 정리했다.

연결 대상: 하나의 게임 안에 있는 기존 마을, 버스, 도서관 외부와 도서관 업무.

사용자 피드백에 따라 버스를 별도 게임으로 고르는 구조를 제거했다. 핵심 흐름은 **마을 → 정류장에서 목적지 선택 → 버스 이동 → 도서관 업무 → 도서관 외부 → 버스로 귀가 → 원래 마을**이다. 게임 탭에는 마을 진입 하나만 둔다. 집·마트·버스·도서관은 같은 플레이 안에서 장소를 이동하며 이용한다. 아래 장면별 문구와 연출은 설계 기준이며, 세부 연출의 적용 상태는 현재 구현과 함께 확인한다.

## 1. 게임의 목적과 한 회차

플레이어가 기존 마을을 걷다가 실제 정류장에서 목적지를 고르고 버스를 탄다. 하늘도서관에 도착해 출근을 알리고 업무를 이어 한다. 건물에서 나온 뒤에는 도서관 앞에서 마을로 가는 버스를 이용한다. 목적지와 이동 정보를 확인하고, 필요한 때 사람에게 질문하며, 이동 중 실수에서 회복하는 경험을 만든다.

정상 경로의 편도 이동은 약 5~8분을 초기 설계 목표로 삼았다. 도서관 업무·귀가, 잘못 탄 뒤 돌아오기, 정보를 여러 번 확인하는 시간은 이 목표에 포함하지 않는다. 실제 소요 시간은 플레이 테스트로 조정한다. 제한 시간은 두지 않는다. 버스 대기와 주행 시간은 게임에 맞게 압축한다.

연습할 행동:

- 목적지와 탈 버스의 번호·방향 확인.
- 소지한 교통카드 확인, 정류장 찾기, 안전하게 기다리기.
- 승차 후 교통카드 사용과 승인 결과 확인.
- 안내 방송·전광판·휴대폰 경로를 활용해 하차 지점 판단.
- 정차 후 하차하고 건물까지 이동.
- 헷갈리거나 경로를 벗어났을 때 확인·질문·연락으로 해결.

각 사람에게 필요한 안내 방식은 선택할 수 있다. 게임 수행 기록은 그 회차에서 한 행동을 보여준다. 실제 단독 통근 가능 여부는 게임 결과만으로 판단하지 않는다.

## 2. 배경과 지도

### 기본 설정

하늘도서관에서 보조 업무를 하기로 한 날이다. 플레이어는 평소와 같은 마을에서 움직이며 정류장에 도착한다. 정류장의 목적지 선택에서 하늘도서관을 고르면 그 자리의 대기·승차로 이어진다. 별도의 버스 시작 화면이나 복제된 집 앞 지도로 이동시키지 않는다. 교통카드와 휴대폰은 이미 가지고 있다.

민수와 지영은 기존 친구 설정을 유지한다. 사서는 업무 장소와 도착 방법을 안내하고, 버스 기사는 정차 중 노선 질문에 답한다.

### 이동 공간

| 공간 | 포함하는 장소 | 역할 |
|---|---|---|
| 현재 마을 | 기존 집과 마트, 인도, 버스 정류장 | 자유 이동, 목적지 선택과 승차, 귀가 후 이동 |
| 버스 내부 | 앞문, 카드 단말기, 일반 좌석, 손잡이, 하차벨, 전광판, 뒷문 | 탑승과 이동, 하차 |
| 도서관 구역 | 양방향 정류장, 작은 횡단보도, 짧은 인도, 도서관 입구 | 도착·재입장·퇴근 후 이동과 귀가 승차 |
| 복구용 정류장 | 중앙공원, 늘봄주민센터, 체육관, 느티광장의 정류장 공간 | 잘못 탄 경우와 지나친 경우의 회복 |

도서관 내부는 현재 구현을 재사용한다. 도서관 외부 구역은 건물까지 짧게 걸어갈 규모로 만든다. 복구용 정류장은 양쪽 인도와 횡단보도가 있는 공통 소형 지도를 사용하되 정류장 이름·방향·노선 정보와 일부 배경 소품을 바꾼다. 종점은 차고지 안이 아닌 공개된 정류장으로 표현한다.

### 가상 노선

| 버스와 방향 | 전체 정류장 순서 | 역할 |
|---|---|---|
| 201번, 늘봄주민센터 방면 | 느티광장 → 마을앞 → 중앙공원 → 하늘도서관 → 늘봄주민센터 | 마을에서 도서관에 가는 방향 |
| 201번, 느티광장 방면 | 늘봄주민센터 → 하늘도서관 → 중앙공원 → 마을앞 → 느티광장 | 도서관에서 마을로 귀가하거나 도서관을 지나쳤을 때 돌아오는 방향 |
| 305번, 체육관 방면 | 느티광장 → 마을앞 → 중앙공원 → 체육관 | 다음 버스를 기다렸을 때 확인할 다른 노선 |
| 305번, 느티광장 방면 | 체육관 → 중앙공원 → 마을앞 → 느티광장 | 체육관까지 간 뒤 돌아오는 노선 |

기본 이동은 **마을앞 → 중앙공원 → 하늘도서관**으로, 출발 정류장을 포함해 세 정류장이다. 느티광장·체육관·늘봄주민센터는 경로를 벗어났을 때 이용한다. 번호·정류장명·운행 시간·카드 규칙은 게임 속 가상 설정이다. 실제 지역을 재현할 때는 해당 지역 정보를 별도로 확인한다.

업무 후 귀가는 **하늘도서관 → 중앙공원 → 마을앞**, `201 · 느티광장 방면`이다. 귀가를 고르면 목적지를 `마을앞`으로 바꾸고 새 이동 기록을 시작한다. 경로 카드의 그림·제목·번호·방향·정류장 순서와 기사·친구의 도움도 현재 목적지를 따른다. 도서관행 안내를 그대로 재사용하지 않는다.

버스의 행선지는 현재 운행 방향의 종점을 표시한다. 따라서 기본 승차 안내에는 `201 · 늘봄주민센터 방면 / 하늘도서관 경유`를 사용한다. 같은 201번이라도 마을앞에서 느티광장 방면으로 타면 도서관에 도착하지 않는다.

기사 답변과 경로 안내는 다음 순서로 정한다.

1. 현재 정차한 곳이 목적지라면 `여기가 하늘도서관 정류장이에요.` 또는 귀가 중에는 `여기가 마을앞 정류장이에요.`라고 먼저 안내한다.
2. 그렇지 않으면 **현재 정류장 이후, 그 방향의 종점까지 남은 정류장**에 목적지가 있는지 확인한다. 있으면 목적지까지의 순서를 안내한다.
3. 목적지를 경유하지 않으면 현재 행선지와 그 장소에서 가능한 다음 이동을 안내한다. 번호가 같다는 이유만으로 목적지에 간다고 답하지 않는다.

### 방향별 정류장과 보행 연결

정류장 이름이 같아도 승차 위치는 방향별로 분리한다. 게임 내부에서도 정류장 이름과 방향을 함께 저장한다. 화면에는 내부 식별자 대신 다음 정류장과 버스 행선지를 보여 준다.

| 장소 | 한쪽 승차 위치 | 반대편 승차 위치 | 도보 연결 |
|---|---|---|---|
| 마을앞 | 201 주민센터 방면·305 체육관 방면, 다음 중앙공원 | 201·305 느티광장 방면, 다음 느티광장 | 기존 마을의 인도와 횡단보도 |
| 중앙공원 | 201은 다음 하늘도서관, 305는 다음 체육관 | 201·305 느티광장 방면, 다음 마을앞 | 공통 정류장 지도의 횡단보도 |
| 하늘도서관 | 201 주민센터 방면, 다음 늘봄주민센터 | 201 느티광장 방면, 다음 중앙공원 | 양쪽 정류장에서 도서관 입구까지 연결 |
| 늘봄주민센터 | 201 도착·하차 위치 | 201 느티광장 방면 출발, 다음 하늘도서관 | 종점 표지와 횡단보도 |
| 체육관 | 305 도착·하차 위치 | 305 느티광장 방면 출발, 다음 중앙공원 | 종점 표지와 횡단보도 |
| 느티광장 | 201·305 도착·하차 위치 | 201 주민센터 방면·305 체육관 방면 출발, 다음 마을앞 | 종점 표지와 횡단보도 |

중앙공원에서는 번호에 따라 다음 정류장이 다르므로 노선별로 표시한다. 공통 표지에 다음 정류장 하나만 적어 오해하게 만들지 않는다.

도서관은 외부 지도 위쪽 인도에 둔다. 화면 오른쪽으로 가는 주민센터 방면 버스는 아래쪽 차로에서 아래쪽 인도로 문을 열고, 반대 방향 버스는 위쪽 차로에서 위쪽 인도로 문을 연다. 정상 경로로 내리면 횡단보도를 건너고, 주민센터에서 되돌아와 내리면 같은 인도를 따라 입구로 간다. 버스 문이 중앙선 쪽으로 열리는 배치는 사용하지 않는다.

### 종점과 다음 차량

- 종점은 하차벨 여부와 관계없이 반드시 정차한다. 기사는 `종점입니다. 내려 주세요.`라고 안내한다.
- 종점에서는 하차 완료까지 차량을 유지한다. 승객이 탄 채 노선 방향을 자동으로 뒤집지 않는다.
- 하차 후 표지와 횡단보도를 따라 반대편 출발 정류장으로 이동한다. 각 종점에서 표에 적힌 돌아오는 버스가 계속 운행한다.
- 차량을 놓쳐도 다음 차량이 온다. 첫 버전에는 막차·운행 종료를 넣지 않는다.
- 현재 위치에서 도서관까지 가는 도움 경로를 다시 계산한다. 처음 실수했을 때의 안내를 그대로 반복하지 않는다.

## 3. 장면별 기본 시나리오

장면별 상단 목표와 자동 강조는 기본값인 `안내와 함께`를 기준으로 적었다. `혼자 해보기`에서는 5절의 표시 규칙을 우선 적용한다. 방송·기사 대사의 기본 경로 예시는 실제 탑승한 노선과 현재 위치에 맞춰 바꾼다.

### 장면 1. 기존 마을 정류장 — 목적지 선택

**화면**: 기존 마을을 유지한다. 정류장 가까이에서 `버스 목적지 고르기`를 누르면 `어디로 갈까요?`가 열린다.

**목적지 선택**

- `하늘도서관으로 가기`
- `마을에 머물기`

도서관을 고르면 해당 정류장의 버스 대기 상태로 이어진다. 취소하면 같은 마을 정류장에 남는다. 목적지 선택과 휴대폰 경로에 다음 정보를 제공한다.

- 타는 곳: 마을앞 · 다음 정류장 중앙공원
- 버스: 201 · 늘봄주민센터 방면, 하늘도서관 경유
- 내리는 곳: 하늘도서관
- 경로: 마을앞 → 중앙공원 → 하늘도서관

첫 안내 회차에는 정보의 위치를 짧게 강조한다. 번호·방향·목적지를 동시에 암기하도록 요구하지 않고 휴대폰과 수첩에서 언제든 다시 확인할 수 있게 한다.

**진행 조건**: 목적지를 고르면 정류장에서 기다릴 수 있다. 목적지를 선택하거나 경로를 열었다는 사실만으로 내용을 이해했다고 판정하지 않는다. 같은 화면을 여러 번 열어도 감점하지 않는다.

### 장면 2. 소지한 카드 확인

교통카드와 휴대폰은 기존 플레이의 소지품으로 가지고 있다. 가방에서는 카드를 다시 확인할 수 있다. 별도 카드 챙기기 과제나 집 앞으로 돌아가는 절차를 반복하지 않는다.

**진입 상태**: 마을앞 정류장 대기, 도서관 목적지 선택 완료, 카드 소지. 승차·하차 단말기에서 카드를 쓰는 절차는 그대로 수행한다.

카드 누락 상태에 대한 방어 규칙은 유지할 수 있지만 정상적인 마을 진입에서 카드를 임의로 없애지 않는다. 카드 누락·집에서 챙기기를 실제 플레이 과제로 추가하려면 별도 준비물 시스템과 함께 설계한다.

첫 버전은 교통카드의 승·하차 승인 확인을 연습한다. 금액·잔액은 표시하지 않고 요금 차감도 계산하지 않는다. 반복해서 돌아오는 동안 잔액 부족으로 막히는 일은 없다. 요금·잔액·충전·환승 할인은 지역 규칙을 정한 후속 시나리오에서 다룬다.

### 장면 3. 정류장과 방향 확인

정류장에서 노선과 방향을 확인한다. 이미 도착한 정류장을 다시 찾도록 요구하지 않는다.

정류장에는 실제 표지처럼 정류장 이름, 진행 방향, 운행 번호가 표시된다. 두 정류장 모두 다음 정류장과 노선별 행선지를 표시한다.

**상호작용**: `노선 보기`.

**주요 정보**

> 마을앞
> 다음 정류장: 중앙공원
> 201 · 늘봄주민센터 방면 · 하늘도서관 경유
> 305 · 체육관 방면

반대편에서는 `다음 정류장: 느티광장 / 201·305 느티광장 방면`을 보여 준다. 거기에서 출발하는 버스도 실제로 탈 수 있으며, 느티광장 종점에서 돌아오는 절차로 이어진다. 정류장을 잘못 찾아왔다는 이유만으로 버스의 방향을 바꾸지 않는다.

친구에게 도움을 요청하면 현재 정류장과 맞은편 정류장을 구별하는 단서를 준다.

**민수**

> 정류장 이름 아래에 다음 정류장이 적혀 있어.
> 중앙공원으로 가는 쪽인지 확인해 봐.

정류장 대기 공간은 인도 안쪽에 배치한다. 차도로 내려가려는 입력은 안전 경계에서 멈추고 `인도에서 기다려요`라는 짧은 안내를 제공한다. 같은 입력을 누르고 있는 동안 알림을 연속 재생하지 않는다.

### 장면 4. 버스 번호와 방향을 확인

**첫 출발**: 도서관으로 가는 201번이 먼저 도착한다. 기존 마을 배경을 유지한 정류장 패널에 실제 버스 그림, 번호와 행선지, `마을앞 → 중앙공원 → 하늘도서관` 경로를 표시한다. 번호와 방향을 차분히 확인한 뒤 탑승하도록 안내한다.

이 순서는 최초 마을앞의 중앙공원 방향 정류장에 적용한다. `다음 버스`를 선택하면 현재 차량을 보내고 305번을 확인할 수 있다. 한 번 더 기다리면 201번이 온다. 다른 정류장과 반대 방향에서는 그곳을 지나는 노선만 운행한다. 차량 도착 순서의 무작위화는 이후에 검토한다.

정류장 패널에서 `201번 버스 타기`, `기사님께 물어보기`, `다음 버스`를 선택할 수 있다. 도착한 차량에 맞춰 승차 버튼의 번호를 바꾼다. 탑승을 선택한 시점에 같은 차량의 승차 상태를 버스 내부로 이어 주며, 별도의 집이나 마을 정류장 지도로 전환하지 않는다.

**기사에게 물어보기**: 현재 목적지인 하늘도서관에 가는지 묻는다. 답변은 현재 도착한 차량의 번호와 방향을 사용한다.

**마을앞에서 체육관 방면 305번 기사**

> 이 버스는 체육관으로 가요.
> 하늘도서관은 201번을 타세요.

305번을 확인한 뒤 `다음 버스`를 선택하면 305번이 떠나고 이후 201번이 도착한다. 기다림과 기사에게 확인한 뒤 기다림을 모두 적절한 해결로 기록한다.

**마을앞에서 주민센터 방면 201번 기사에게 같은 질문을 했을 때**

> 네, 하늘도서관에 가요.
> 중앙공원 다음 정류장에서 내리시면 돼요.

반대 방향 201번은 `지금은 느티광장으로 가요. 길 건너에서 늘봄주민센터 방면 201번을 타세요.`라고 답한다. 주민센터에서 되돌아오는 201번은 `네, 다음 정류장이 하늘도서관이에요.`라고 답한다. 기사 대사는 번호만 보고 고정하지 않는다.

잘못 타는 선택도 복구 가능한 경로로 연결한다. 구체적인 회복 과정은 4절을 따른다.

**시간 처리**: 마을 출발 패널에서는 자동 출발하지 않는다. `다음 버스`를 직접 선택하면 잠시 기다린 뒤 다음 차량이 도착한다. 다른 정류장에서도 노선표·휴대폰·대화를 보고 있는 동안 버스의 출발 카운트는 멈춘다. 글을 읽고 있는 동안 버스를 놓치게 하지 않으며, 기다리던 차를 놓쳐도 다음 차가 온다.

### 장면 5. 승차와 카드 사용

버스가 완전히 멈추고 앞문이 열린 뒤 승차한다. 이 과정은 201·305와 양방향에 공통으로 적용한다. 버스 안으로 짧게 이동하는 전환 후 카드 단말기가 가까이 보인다. 문턱을 넘는 순간부터 카드 확인과 자리 확보까지 출발 대기는 멈춘다.

**상단 목표**: `교통카드 찍기`.

가방의 교통카드를 선택해 단말기에 대거나 `카드 찍기` 버튼을 누른다. 인식에 성공하면 짧은 소리와 화면의 승인 표시가 함께 나온다. 소리가 꺼져 있어도 완료 여부를 알 수 있다.

**단말기 표시**: `승차 처리되었습니다`.

같은 승차 중에는 단말기를 반복 눌러도 승인과 기록을 한 번만 처리한다. 다른 버스에 다시 타면 새로운 승차로 기록한다. 첫 회차에는 인식 오류를 발생시키지 않는다.

아직 출발하지 않은 차에서 내리기로 했다면 기사에게 `여기서 내릴게요`라고 말하고 열린 앞문으로 돌아갈 수 있다. 승차 기록은 출발 전 하차로 마무리하고, 탑승 중이라는 상태를 남기지 않는다.

**출발 조건**: 승차 승인이 완료되고, 좌석에 앉거나 손잡이를 잡았으며, 열린 패널·대화와 문 통과 중인 동작이 없다. 단말기 승인 표시가 나왔다는 사실은 기록하지만 그 표시를 이해했다고 자동 판정하지 않는다.

### 장면 6. 이동 중 내릴 곳 확인

일반 좌석 한 자리와 잡을 수 있는 손잡이를 제공한다. 출발 조건을 만족하면 문을 닫고 출발한다. 주행 중에는 자리에서 이동하는 자유 조작을 잠그고, 전광판 확인·안내 다시 듣기·하차벨·휴대폰 경로 확인을 사용할 수 있게 한다. 이동 패드는 비활성 상태를 표시하고 `이동 중`이라는 짧은 상태만 보여 준다. 정차하면 이동이 다시 가능해진다.

하차벨은 앉아 있거나 손잡이를 잡은 위치에서도 닿는 곳에 배치한다. 주행 중 통로를 걸어가야만 누를 수 있는 구성은 사용하지 않는다.

**첫 안내 방송**

> 이번 정류장은 중앙공원입니다.
> 다음 정류장은 하늘도서관입니다.

전광판에도 동일한 정류장명이 나타난다. 플레이어는 지금 내리는 곳과 다음 내리는 곳을 구별한다.

하차 요청이 있으면 중앙공원에 정차하고, 없으면 중앙공원을 통과한다. 중앙공원 구간을 지난 뒤에는 도서관 접근 안내를 한다.

**두 번째 안내 방송**

> 이번 정류장은 하늘도서관입니다.
> 다음 정류장은 늘봄주민센터입니다.

**상단 목표**: 안내 모드에서는 `내릴 곳 확인하기`, 혼자 모드에서는 계속 `하늘도서관 가기`를 유지한다.

접근 안내에서 말하는 `이번 정류장`은 지금 차량이 서 있는 곳이 아니라 **다음에 도착할 정류장**이다. 전광판에는 같은 이름과 `곧 도착`을 함께 표시해 구별한다. 하차벨을 누르면 해당 정류장에 대한 요청이 저장되고 벨의 불과 전광판에 `하차 요청`이 표시된다. 한 번 누르면 유지되며 연타해도 중복 기록하지 않는다.

초기 검증값은 접근 안내부터 정차·통과 결정까지 최소 15초다. 자막의 자동 읽기가 끝나기 전에는 확인 구간을 종료하지 않고, 패널·대화·안내 다시 듣기를 사용하는 동안 진행을 멈춘다. 읽기나 다시 듣기를 마친 뒤 최소 5초를 남긴다. 통과가 확정되어 다음 정류장 이름으로 바뀐 후 누른 벨은 새로 표시된 정류장에 적용된다. 대상 이름이 바뀌는 시점과 요청 대상을 함께 갱신한다.

하차벨을 중앙공원 전에 눌렀다면 버스가 중앙공원에 정차한다. 잘못 요청했음을 확인한 뒤 타고 있어도 된다. 버스의 요청등은 정차 후 꺼지고, 도서관 전에 다시 요청할 수 있다. 게임에서 현실에 없는 하차벨 취소 버튼을 추가하지 않는다.

플레이어가 정류장에서 기다릴 때는 그 방향을 지나는 차량이 승차를 위해 정차한다. 플레이어가 탑승한 뒤에는 다른 승객의 승·하차 수요를 넣지 않으므로, 일반 정류장은 플레이어의 하차 요청이 있으면 정차하고 없으면 통과한다. 이것은 이번 가상 회차의 운행 조건이며, 실제 버스가 항상 이 조건만으로 정차한다고 설명하지 않는다.

### 장면 7. 정차 후 하차

하늘도서관 접근 구간에서 요청했다면 버스가 정차한다. 요청하지 않았다면 통과해 늘봄주민센터로 이어진다. 같은 정차·하차 규칙을 중앙공원과 다른 정류장에도 사용한다.

완전히 정차하고 뒷문이 열린 뒤 좌석에서 일어나거나 손잡이를 놓고 뒷문으로 이동한다. 캐릭터가 문으로 이동하거나 카드를 찍거나 문턱을 넘는 동안에는 버스가 출발하지 않는다. 하차벨 요청은 정차 시 소진하며, 정차 중에는 새로운 요청을 받지 않는다.

이 게임의 노선은 승·하차 모두 교통카드를 확인하는 설정으로 한다. 뒷문 카드 단말기에 카드를 대고 승인 표시를 확인한 뒤 내린다. 이 설정을 실제 모든 지역의 동일한 규칙으로 설명하지 않는다.

**단말기 표시**: `하차 처리되었습니다`. 같은 승차에 대한 하차 승인도 한 번만 기록한다.

안내 모드에서는 목적지 정차 후 `하늘도서관에서 내리기`를 표시할 수 있다. 혼자 모드에서는 상단 목적지를 유지하고 현재 정류장명·문 열림·차량 정차 상태만 제공한다. 실제 버스처럼 모든 정류장의 방송과 전광판을 같은 방식으로 보여 준다.

너무 일찍 벨을 눌러 계속 타려면 좌석이나 손잡이 위치에서 `계속 타기`를 선택한다. 이 기능은 **일반 정류장이고, 자리를 확보했으며, 하차 카드 승인을 아직 하지 않은 경우**에만 표시한다. 자리에서 일어났다면 다시 자리로 돌아온 뒤 선택할 수 있다. 이미 하차 승인했다면 이번 승차를 종료하고 인도로 내린 뒤 다음 버스를 이용한다. 종점에서는 `계속 타기`를 제공하지 않는다.

`계속 타기`는 정차 후 생각하고 조작할 시간을 보장하기 위한 게임 기능이다. 별도 확인 팝업 없이 기존 상호작용 영역에서 제공한다. 재출발 시 문을 닫고 다음 정류장을 설정한 뒤 하차벨을 다시 사용할 수 있게 한다.

하차 지점은 인도다. 버스 앞이나 뒤에서 바로 차도를 가로질러 도서관 입구로 갈 수 없도록 지도에 인도와 횡단보도를 분명하게 배치한다.

### 장면 8. 도서관까지 걷기

도서관 입구가 정류장에서 보인다. 주민센터 방면 버스에서 내리면 아래쪽 인도에서 횡단보도로 이동하고, 주민센터에서 돌아오는 버스에서 내리면 위쪽 인도를 따라 입구로 이동한다. 두 경로 모두 실제 하차한 위치에서 시작한다.

횡단보도 앞에서 `주변 살피기`를 누르면 좌우 차량을 볼 수 있는 짧은 시야 이동을 제공한다. 모션 감소 설정에서는 시야 이동 대신 같은 정보를 정지 화면으로 보여 준다. 보행 초록 신호이고 차량이 멈췄으며 건널 시간이 충분할 때 진입할 수 있다. 건너는 중에는 충돌 차량을 진입시키지 않고, 늦게 걷거나 중간에 멈춰도 안전한 다음 인도까지 이동을 보장한다. 달리기를 요구하지 않는다. 안내 모드와 혼자 모드 모두 이 안전 보조를 유지한다.

모든 교차로에 긴 확인 팝업을 띄우지 않는다. 길 찾기가 필요하면 안전한 인도에서 휴대폰을 열어 도서관 입구 표시를 확인할 수 있다.

**상단 목표**: `도서관 안내 데스크로 가기`.

### 장면 9. 출근 알리기와 도서관 업무

기존 도서관에 입장한다. 사서에게 말을 걸면 출근 보고 선택지가 먼저 나온다.

**플레이어 선택지**

- `안녕하세요. 도서관 업무를 하러 왔어요.`

**사서**

> 안녕하세요. 잘 오셨어요.
> 준비되면 오늘 할 일을 알려드릴게요.

출근 보고를 마치면 이동 완료 기록을 한 번 확정하고 기존 책 정리 업무로 바로 이어진다. 버스 전용 결과·별점·재시작 화면을 사이에 넣지 않는다. 이동 기록과 업무 기록은 구분하되 플레이 공간은 이어진다. 업무를 끝내기 전에도 출근 이동 기록은 완료 상태다.

게임 탭에 도서관만 바로 시작하는 선택은 없다. 개발용 도서관 미리보기는 화면 검증용이며 일반 진입 경로와 완료 조건을 우회하는 사용자 기능이 아니다.

### 장면 10. 도서관 밖으로 나오기와 귀가

기존 도서관 업무에서 나가면 건물 앞 인도에 선다. 도서관에 다시 들어갈 수 있으며, 재입장만으로 이전 출근 완료를 중복 기록하지 않는다. 도서관 문을 나오는 순간 마을로 보내지 않는다.

마을로 돌아가려면 도서관 정류장에서 귀가 목적지를 고른다. 도서관 쪽 인도의 `201 · 느티광장 방면`에 승차하고, 승차 카드 승인과 자리 확보 후 출발한다. 경로는 `하늘도서관 → 중앙공원 → 마을앞`이다. 마을앞 접근 안내에 벨을 누르고 정차 후 하차 승인을 받아 내린다. 하차가 끝나면 기존 마을의 정류장으로 연결하고 자유 이동을 이어간다.

귀가 중 중앙공원에 일찍 내렸다면 같은 방향 201 또는 305로 마을앞까지 갈 수 있다. 마을앞을 지나치면 느티광장 종점에서 내려 반대 방향 201 또는 305를 타고 마을앞으로 돌아온다. 도서관행과 같은 종점·카드·벨·안전·시간 정지 규칙을 적용하며, 도움 경로는 현재 목적지인 마을을 기준으로 계산한다.

| 상태 | 가능한 행동 | 다음 단계로 넘어가는 조건 |
|---|---|---|
| 정류장 대기 | 노선·가방·휴대폰 확인, 인도 이동 | 해당 방향 차량 도착 |
| 승차 가능한 정차 | 앞문 승차, 기사에게 질문, 계속 기다리기 | 승차하면 출발 대기 중지. 타지 않으면 대기 시간 후 출발 |
| 승차 확인 | 카드 승인, 자리 확보, 출발 전 하차 | 카드 승인 + 자리 확보 + 열린 패널 없음 |
| 주행·정류장 접근 | 벨, 전광판, 안내 다시 듣기, 휴대폰 | 확인 구간 종료 후 요청 여부 판단. 종점은 항상 정차 |
| 요청 없는 정류장 통과 | 안전한 자리 유지, 정보 확인 | 다음 정류장으로 접근 대상 변경 |
| 완전히 정차한 상태 | 일어나기, 단말기로 이동, 기사에게 질문 | 하차 승인 또는 조건을 만족한 `계속 타기` |
| 하차 승인 후 | 열린 문으로 이동 | 발 위치가 인도에 도착하면 하차 완료 |
| 하차 완료 | 현재 정류장 확인, 걷기, 다음 차 기다리기 | 탑승 상태 정리 후 차량 출발, 인도 위치를 복구 기준으로 저장 |

주행 중의 벨은 전광판에 표시된 다음 도착 지점 한 곳에만 연결한다. 정차 때 요청을 소진하고, 다음 구간을 시작하기 전까지 비활성화한다. 승·하차 전환, 카드 승인, 완료 보고는 같은 입력이 연속 들어와도 한 번만 실행한다.

패널을 여러 개 열었다가 하나만 닫았거나 앱이 백그라운드에 들어갔다면 시간을 재개하지 않는다. 모든 방해 화면을 닫고 앱으로 돌아왔을 때 남은 단계부터 이어 간다. 정차 화면과 메뉴를 닫는 입력이 동시에 승차·하차·벨 입력으로 처리되지 않게 한다. 이 절의 상태 정지와 승인 후 하차 완료 절차는 첫 버전의 게임 진행 규칙이다.

## 4. 실수와 돌발상황의 회복

첫 출발은 목적지로 가는 201번부터 안내한다. 305번은 사용자가 다음 버스를 기다렸을 때 선택할 수 있고, 아래의 상황은 사용자의 선택에서 실제로 발생했을 때 처리한다. 첫 회차에 임의의 사건을 강제하지 않는다.

| 상황 | 화면과 대사 | 해결 경로 | 기록 |
|---|---|---|---|
| 버스를 놓침 | 현재 정류장을 지나는 다음 차량 표시 | 안전한 대기 장소에서 경로에 필요한 다음 차 기다리기 | 다음 차 확인·대기 |
| 마을앞에서 체육관 방면 305번을 잘못 탐, 출발 전 | 기사에게 목적지를 묻으면 해당 차가 체육관 방향임을 설명 | 문이 열린 출발 정류장에서 내려 주민센터 방면 201번 기다리기 | 노선 수정 |
| 마을앞에서 체육관 방면 305번을 탄 뒤 출발함 | 차량은 체육관 방면이고, 휴대폰 목적지는 하늘도서관 | 벨 요청 후 중앙공원에서 하차 → 같은 쪽 정류장에서 주민센터 방면 201번 승차 | 현재 위치 확인·갈아타기·도움 여부 |
| 305번에서 중앙공원도 지나침 | 체육관 종점 안내 | 체육관 하차 → 횡단보도로 출발 정류장 이동 → 느티광장 방면 305번 → 중앙공원 하차 → 길 건너 주민센터 방면 201번 | 종점에서 경로 회복 |
| 마을앞에서 반대 방향 버스를 탐 | 느티광장 방면 행선지·종점 안내 | 느티광장 하차 → 횡단보도로 출발 정류장 이동 → 주민센터 방면 201번 → 마을앞·중앙공원을 지나 하늘도서관 | 방향 재확인·종점에서 재승차 |
| 주민센터 방면 201번에서 중앙공원에 너무 일찍 내림 | 정류장 표지에는 중앙공원, 휴대폰 목적지에는 하늘도서관 표시 | 같은 쪽 주민센터 방면 201번을 다시 타고 다음 정류장으로 이동 | 목적지 재확인·재승차 |
| 도서관을 지나침 | 늘봄주민센터 종점 안내 | 주민센터 하차 → 정류장 이름 확인 → 돌아갈 길 확인 → 횡단보도로 출발 정류장 이동 → 느티광장 방면 201번 → 다음 하늘도서관에서 하차 | 경로 회복 |
| 돌아오는 201번에서 도서관을 또 지나침 | 중앙공원 또는 마을앞이 다음 정류장으로 표시 | 벨을 눌러 그곳에서 하차 → 횡단보도로 반대편 이동 → 주민센터 방면 201번 | 현재 방향을 반영한 재탐색 |
| 돌아오는 305번에서 중앙공원을 또 지나침 | 마을앞 또는 느티광장 표시 | 마을앞에서 내렸다면 길 건너 주민센터 방면 201번. 끝까지 갔다면 느티광장 종점 복구와 동일 | 반복 실수 후 회복 |
| 돌아오는 길의 정류장을 모두 놓침 | 느티광장 종점 안내 | 느티광장에서 반드시 정차·하차 → 주민센터 방면 201번으로 다시 시작 | 반복 실수 후 회복 |
| 벨을 일찍 눌렀지만 아직 내리지 않음 | 정차한 현재 정류장명 표시 | 하차 승인 전, 좌석·손잡이 위치에서 `계속 타기` → 목적지 접근 때 다시 벨 요청 | 하차 요청 수정 |
| 차량 이동 중 기사에게 대화 시도 | `정차하면 물어볼 수 있어요` | 현재 위치를 확인하거나 다음 정차 때 질문 | 안내 제공 |
| 귀가 중 중앙공원에 일찍 내림 | 목적지는 마을앞, 현재 위치는 중앙공원 | 같은 인도의 느티광장 방면 201 또는 305 → 마을앞 하차 | 귀가 경로 재확인·재승차 |
| 귀가 중 마을앞을 지나침 | 느티광장 종점 안내 | 종점 하차 → 길 건너 주민센터 방면 201 또는 체육관 방면 305 → 다음 마을앞 하차 | 귀가 경로 회복 |

각 경로는 잘못 고르면 다시 같은 상황으로 이어질 수 있지만, 종점과 정류장에 돌아오는 차가 계속 있어 막다른 상태가 되지 않는다. 길 안내는 정류장 이름뿐 아니라 **현재 인도·방향·탑승 노선**을 기준으로 만든다. 예를 들어 중앙공원도 체육관에서 돌아와 내린 경우에는 길을 건너야 한다. `같은 방향으로 다시 타세요`라는 문구를 모든 중앙공원 하차에 재사용하지 않는다.

### 정류장에서 다시 시작하기

자연스러운 되돌아오기와 별도로, 휴대폰의 이동 도움에 `정류장에서 다시 시작`을 둔다. 선택하면 돌아갈 정류장 이름을 보여 주고 확인 후 실행한다. 목적지로 바로 보내는 기능은 아니다.

- 기준은 **플레이어가 마지막으로 인도에 서 있었던 정류장과 그 방향의 대기 위치**다. 정류장 대기 구역 진입, 반대편 정류장으로 횡단 완료, 하차 완료 때 갱신한다. 차도 위나 버스가 지나가기만 한 정류장으로 갱신하지 않는다. 도서관행의 첫 기준은 마을앞 정류장, 귀가의 첫 기준은 도서관 정류장이다.
- 교통카드 소지 여부, 현재 목적지, 안내·조작 설정은 유지한다. 소지품을 없애거나 귀가 목적지를 도서관으로 되돌리지 않는다.
- 현재 차량에서 내린 상태로 정리한다. 승차 중 상태, 승·하차 승인 플래그, 자리 확보, 하차벨, 문 통과 애니메이션, 열린 대화·패널·예약 타이머를 모두 정리한다.
- 현재 차량과 대기열은 해당 정류장의 새 운행으로 시작한다. 돌아간 방향에서 실제 운행하는 버스만 도착한다. 다음 승차에는 새로운 식별자를 사용한다.
- 이전 행동 기록은 삭제하지 않는다. 복구 전후 구간을 구별하고 `정류장 복귀 도움 사용`을 남긴다. 복구를 직접 경로를 찾아 돌아온 행동으로 기록하지 않는다.
- 복구 화면에서 취소하면 기존 상태로 돌아온다. 확인 전에는 위치나 기록을 바꾸지 않는다.

복구 사용 여부는 이동 기록에 남기되 반복 재시도 횟수로 처벌하지 않는다. 차량 사이로 이동하거나 움직이는 버스에서 내리는 행동은 충돌 경계와 상태 제한으로 막는다.

### 정류장을 지나쳤을 때 친구에게 전화하는 예

전화 앱에서 기존처럼 지영·민수를 선택한다. 친구가 플레이어의 위치를 자동으로 알고 있다고 전제하지 않는다.

**플레이어**

> 도서관을 지나친 것 같아.

**지영**

> 지금 있는 정류장 이름을 확인해 줄래?

정류장 표지 또는 휴대폰의 현재 위치를 확인한 뒤 이름을 전달한다. 이름 선택 목록을 제공할 때는 실제로 확인한 현재 위치를 포함하고, 읽기 지원도 사용할 수 있게 한다.

**플레이어**

> 늘봄주민센터야.

**지영**

> 거기서 느티광장 방면 201번을 타면 하늘도서관에 가.
> 횡단보도로 건너가서 노선표를 확인해 봐.

통화를 마치면 휴대폰에 현재 위치와 돌아가는 경로를 남겨 다시 확인할 수 있게 한다. 전화 한 번으로 캐릭터를 목적지에 자동 이동시키지 않는다.

체육관에서 연락했다면 `305번으로 중앙공원까지 돌아오기 → 횡단보도 건너기 → 주민센터 방면 201번 타기`를 한 단계씩 안내한다. 느티광장에 있다면 그곳에서 출발하는 201번을 안내한다. 친구 답변과 휴대폰 경로는 같은 노선 정보를 사용한다.

## 5. 안내와 조작

- 기존 공통 이동 패드, 상호작용 버튼, 걷기·달리기 설정을 재사용한다.
- 조이스틱 모드에서는 먼 물체를 탭해도 자동 이동하지 않는다. 터치 이동 모드만 경로 이동을 사용한다.
- 주행 중에는 차량 내부 이동을 잠근다. 정차 후에는 필요한 이동을 다시 사용할 수 있다.
- 대화는 현재 마을·마트·도서관의 대화창, 선택지 등장 애니메이션, 부드러운 텍스트 효과음을 사용한다.
- 상단에는 목적지 또는 현재 할 일 하나만 간결하게 표시한다. 지도·노선표·대화에 같은 설명을 중복해서 상시 배치하지 않는다.
- 버스 번호, 정류장명, 행선지는 이미지 속에 굽지 않고 읽을 수 있는 텍스트로 표시한다. 확대와 다시 읽기를 제공한다.
- 노선은 색과 함께 번호·문자·방향 정보를 사용한다. 색만으로 정답을 구별하지 않는다.
- 기본 안내는 `안내와 함께`. `혼자 해보기`로 플레이 중에도 바꿀 수 있으며, 이미 진행한 구간을 다시 시작하거나 행동 기록을 지우지 않는다.
- 안내 방송은 자막을 함께 제공하며 `다시 듣기`가 가능하다. 자동 읽기, 소리, 모션 감소는 설정을 따른다.
- 패널·대화를 열면 이동과 버스의 진행 시간을 멈춘다. 닫으면 남은 상황부터 이어진다.
- 카드 조작은 탭으로 완료할 수 있다. 끌기나 좁은 위치에 정확히 놓는 동작만으로 통과 여부를 결정하지 않는다.

### 안내 단계에 따라 달라지는 것

| 요소 | 안내와 함께 | 혼자 해보기 |
|---|---|---|
| 상단 목표 | 지금 수행할 단계 한 가지 | 도서관행은 `하늘도서관 가기`, 귀가는 `마을로 돌아가기` 유지. 도착 후 다음 행동 안내 |
| 자동 강조 | 번호·행선지·단말기 등 현재 확인 대상. 필요하면 다음 행동 안내 | 정답 버스·정류장·벨 누를 순간의 자동 강조 없음 |
| 현재 목적지 접근 때 | 목적지 접근과 벨 위치를 안내할 수 있음 | 다른 정류장과 같은 방송·전광판만 제공 |
| 휴대폰·노선표·친구·기사 | 자유롭게 이용 | 자유롭게 이용. 요청하면 구체적인 해결 경로 제공 |
| 읽는 동안 시간 정지·다시 듣기 | 유지 | 유지 |
| 안전 경계·자리 확보·정차 후 하차 | 유지 | 유지 |

안내 유무는 정답 단서의 제공 정도를 조절한다. 읽기 지원·터치 대안·안전 보조는 두 모드 공통이다. `카드 찍기`, `일어나기`, `계속 타기`처럼 현재 가능한 조작 이름은 두 모드 모두 표시한다. 안내 모드의 목적지 자동 강조가 있었는지, 혼자 모드에서 도움을 요청했는지는 행동 기록에 함께 남긴다.

## 6. 이동 기록과 장소 연결 기준

버스 전용 결과 화면은 열지 않는다. 출근 보고 후 도서관 업무로, 귀가 하차 후 기존 마을 이동으로 이어진다. 버스 이동은 같은 게임의 이동 수단이며 별도 미니게임 종료로 표현하지 않는다.

내부 기록은 실제 수행한 행동에 근거해 요약한다. 기록 예시는 다음과 같다.

- `도서관 방향 버스를 탔어요.`
- `교통카드 사용을 확인했어요.`
- `도서관/마을앞 안내에 하차벨을 누르고 내렸어요.`
- `기사에게 물어보고 버스를 골랐어요.`
- `지나친 뒤 돌아오는 길을 찾았어요.`

화면 확인만으로 학습자의 기억력이나 장애 특성을 단정하지 않는다. 도서관행 완료와 귀가 완료를 구별하며, 완료한 이동을 도서관 재입장 때 다시 저장하지 않는다.

버스 별점 입력은 통합 흐름에서 제거한다. 기존 도서관 업무 자체의 결과·만족도는 해당 업무의 기준을 따른다. 이동 수행 기록에는 완료한 행동, 제공된 안내, 질문, 잘못 선택한 뒤의 수정, 체크포인트 복구를 남긴다. 이 버전에는 행동 감점이나 속도 점수를 넣지 않는다.

도움을 요청하거나 같은 정보를 다시 확인했다는 이유로 감점하지 않는다. 게임에서 패널을 열었다는 사실만으로 내용을 이해했다고 판정하지 않고, 이후 선택·이동 결과와 구분해 기록한다. 조작 실수와 노선 판단 실수도 구분한다.

시간은 테스트·관찰을 위한 보조 기록으로만 사용한다. 빨리 도착하는 보상으로 안전한 확인 행동을 생략하게 만들지 않는다. 중도 종료를 목적지 도착이나 실패 점수로 기록하지 않는다.

`내릴 정류장을 확인했어요`는 경로 창을 한 번 열었다는 이유로 표시하지 않는다. 목적지 접근 구간에서 요청하고 해당 정류장에 내렸다는 관찰 결과와 제공된 안내를 근거로 삼는다. 벨을 누르지 못했지만 종점에서 되돌아왔다면 그 회차에는 경로 회복 행동을 표시한다. `정류장에서 다시 시작`을 사용한 회차는 그 전의 실수를 숨기거나 처음부터 혼자 도착한 것으로 표시하지 않는다.

## 7. 첫 제작 범위와 이후 확장

### 첫 제작 범위

- 가상 노선 201·305의 양방향 운행과 기본 세 정류장 이동.
- 기존 마을의 목적지 선택부터 출근 보고·도서관 업무·외부 복귀·귀가까지 연결된 플레이.
- 다음 버스를 기다리면 305번을 확인하고 선택할 수 있는 흐름.
- 잘못 탄 뒤 갈아타기, 목적지를 지나친 뒤 되돌아오기, 반복 실수 후 종점에서 다시 출발하기.
- 중앙공원·늘봄주민센터·체육관·느티광장은 공통 소형 정류장 지도를 재사용.
- 정상적인 경로 회복과 별도로, 상태를 정리해 정류장에서 다시 시작하는 도움 기능.
- 게임 탭의 단일 마을 진입, 실제 정류장에서 목적지 선택, 도서관을 나온 뒤 같은 외부 구역에서 재입장 또는 버스 귀가.
- 정류장 이름을 전달하고 도움을 구하는 대화.
- 현재 조작·대화·캐릭터 시스템 재사용.

정상 도착 회차와 함께 같은 차량·정류장 구조로 잘못 탄 경로와 종점 귀환을 연결했다. 실수 때문에 갈아타는 과정도 첫 버전에서 지원한다.

### 후속 회차 후보

- 교통카드 잔액 부족과 충전.
- 기존 마을의 소지품 시스템과 연계한 카드 누락·준비물 챙기기.
- 혼잡한 버스, 이용할 수 없는 좌석, 긴 대기.
- 목적지 또는 버스 번호 변경, 처음부터 환승해야 도착하는 목적지.
- 출근 시간에 맞춰 출발 시각을 계획하고 지연을 연락하기.
- 실제 지역의 정류장명·번호·교통카드 규칙을 사용하는 맞춤 연습.

이후 확장은 기본 회차를 사용자와 함께 플레이한 뒤 정보량·조작 난도·상황 이해를 확인하고 결정한다.

## 8. 새로 필요한 그림과 연출

- 기존 인물 크기에 맞는 버스 외관과 앞·뒷문 개폐 상태.
- 실제 버스에서 구별해야 하는 카드 단말기, 전광판, 하차벨, 일반 좌석과 손잡이가 명확한 내부.
- 도서관 외부와 정류장, 공통 복구용 정류장 공간.
- 같은 그림체의 버스 기사. 친구·사서·주인공은 현재 에셋 재사용.
- 승하차의 짧은 전환, 문 개폐, 카드 승인, 하차벨 점등, 정차 시 감속, 창밖 풍경 이동.

버스 외관은 양쪽 진행 방향에서 문이 인도와 맞도록 준비한다. 숫자·행선지·문 위치까지 통째로 좌우 반전하지 않는다. 도로 배치와 캐릭터 크기를 먼저 확정하고 이미지를 제작한다. 같은 버스 그림을 번호·행선지 텍스트로 재사용하되 201·305를 색만 보고 고르게 만들지 않는다. 도서관 외부와 소형 정류장에도 기존 마을의 부드러운 색감, 굵은 갈색 선, 인물과 사물의 비례를 이어 간다.

새 공간에서도 캐릭터와 가구의 크기, 발 위치 기준 앞뒤 정렬, 충돌 범위를 동일한 기준으로 맞춘다. 그림에는 실제로 눌러야 하는 것과 장식의 구분이 드러나야 한다. 필요한 에셋은 제작 단계에서 생성·검수한다.

## 9. 근거 자료와 설계 판단

국립특수교육원의 「장애학생 교과연계 전환역량 향상 프로그램」 중 지역사회생활 자료는 목적지 경로 확인, 시내버스 이용 절차, 교통안전과 모의 연습 후 지역사회 실습을 다룬다. 이 문서는 이를 확인 행동과 승하차 과제를 선정하는 참고로 사용했다. [공식 자료, PDF 1~6쪽 / 인쇄면 84~89쪽](https://nise.go.kr/teemh/pdf/edu/2th/1-5.pdf)

가상 노선, 도서관 출근 이야기, 대사, 돌발상황 빈도, 시간 정지, 회복용 지도, 이동 기록 방식은 이 게임을 위한 설계 제안이다. 자료가 특정 게임의 효과를 검증했다는 뜻은 아니다. 실제 지역의 교통 환경과 이용자의 지원 필요에 맞추어 동행 연습으로 이어갈 수 있도록 한다.

## 11. 현재 구현과 검증 기록 — 2026-09-29

### 연결된 플레이 흐름

- 게임 탭의 `오늘도 마을 들어가기` 하나로 진입한다. 버스·도서관의 별도 시작 카드와 마트 전용 진입 버튼을 제거했고, 기존 마을의 집·마트·주민·정류장을 이용한다.
- 실제 마을 정류장에서 `버스 목적지 고르기` → `하늘도서관으로 가기`로 이어진다. 목적지 선택을 취소하면 현재 마을 위치를 유지한다. 기존 마을 배경 위에서 첫 201번의 번호·방향을 확인하고 기사에게 물어보거나 다음 305번을 기다릴 수 있다. 탑승을 선택해야 버스 내부로 전환한다. 교통카드를 이미 소지한 상태이며 복제된 집·마을 정류장이나 카드 챙기기 화면을 다시 열지 않는다.
- 양방향 정류장 이동, 노선과 기사에게 확인, 승차 승인과 자리 확보, 방송·하차벨, 정차 후 하차 승인, 횡단보도와 도서관 입구, 사서에게 출근 보고를 연결한다.
- 305 오승차·반대 방향 승차·목적지 통과 후 돌아오는 경로와 종점 하차, 정류장 체크포인트 복구를 제공한다. 안내 모드 변경과 질문·전화·경로 다시 보기도 사용할 수 있다.
- 사서 보고 뒤 별도 버스 결과·만족도 화면 없이 기존 도서관 업무로 이어진다. 업무에서 나오면 도서관 앞 공간으로 복귀하며, 다시 입장하거나 정류장에서 버스로 귀가한다.
- 기존 마을의 도서관 모양 건물은 `마을회관`으로 표시하고 원격 도서관으로 직접 들어가는 문은 제거했다. 도서관에서 마을로 귀가할 때는 `201 · 느티광장 방면`, `하늘도서관 → 중앙공원 → 마을앞` 경로를 안내한다. 실제 마을앞 하차 후 기존 마을의 정류장으로 연결한다.
- 조이스틱·터치 이동 설정을 장소 사이에 유지한다. 버스·도서관 내부와 목적지 선택·정류장 패널이 열린 동안 배경 마을의 이동을 잠근다. 마을에서 수락한 버스 퀘스트는 실제 출근 보고 완료 때만 완료 처리한다.
- 개발용 `busPreview=1`도 실제 마을 정류장에 서 있는 상태로 시작한다. `libraryPreview=1`은 업무 화면 검증용으로만 유지하며 일반 게임 메뉴에는 노출하지 않는다. 두 개발용 경로는 프로덕션 진입을 우회하지 않는다.

구현 진입점은 `frontend/src/screens/BusSimulationScreen.tsx`이며, 상태·노선 규칙은 `busSession.ts`, 이동 공간은 `BusWorld.tsx`와 `busWorld.ts`, 일시 정지와 한국어 읽어주기는 `useBusRuntime.ts`에서 관리한다. 버스 양방향 외관·내부·도서관 외부·정류장·기사와 주인공 앉기 그림 7종과 제작 기록은 [버스 아트 기록](../frontend/docs/bus-art-prompts.md)에 있다. 번호와 행선지는 그림에 넣지 않고 화면 텍스트로 표시한다.

### 기록과 이번 버전의 경계

완료한 이동 회차는 도서관·마트·AI 기록과 분리하고 도서관행과 귀가 목적지를 구별한다. 별도 버스 만족도 입력은 사용하지 않는다. 웹은 사용 가능한 브라우저 저장소에 최근 최대 20회차를 보관한다. 네이티브 앱과 브라우저 저장소를 사용할 수 없는 환경에서는 현재 앱 실행 중 메모리에만 보관하므로 앱 종료 후 복원을 보장하지 않는다. 회차 도중의 체크포인트도 현재 실행 중인 이동을 위한 복구이며, 앱 종료 후 이어하기 기능은 아니다.

요금·잔액·충전·환승 할인, 실제 지역 교통 정보, 서버 API 연동, 계정 간 기록 동기화는 이번 구현에 포함하지 않는다. 방송은 기기의 음성 읽기와 자막을 함께 사용하며, 음성 엔진이 없거나 꺼져 있어도 자막과 조작으로 진행할 수 있다. 실제 휴대폰에서의 한국어 음성·터치 편의성은 별도 플레이 확인이 필요하다.

### 이전 버전에서 확인한 기반 동작

- 단일 마을 통합 이전에 전체 자동 테스트 68개 묶음·728개가 통과했다. 이후 터치 경로의 경유점 오차와 도착 애니메이션 중 버튼 상태를 보완하고 버스·공통 조작 관련 8개 묶음·96개 테스트를 다시 실행해 통과했다. 당시 타입 검사와 웹 빌드도 통과했다.
- 브라우저에서 201 승차 → 카드 승인 → 앉기 → 도서관 안내 때 하차벨 → 하차 카드 → 뒷문 → 도서관 앞 횡단 → 사서 보고를 실제 조작으로 완료했다. 375×667, 390×844, 768×1024 화면에서 배치와 공통 조작 UI를 확인했다. 당시 존재한 별도 준비·결과·만족도 화면은 이번 통합 흐름에서 제거한다.
- 목적지를 지나쳐 주민센터 종점에서 내린 뒤 횡단 → 반대 방향 201 재승차 → 손잡이 확보 → 도서관 하차 → 사서 보고까지 실제 화면에서 완료했다. 복귀 경로 안내와 완료 사실이 현재 회차에 맞게 바뀌는 것을 확인했다. 현재는 그 뒤 결과 버튼을 고르는 단계 없이 도서관 업무로 이어진다.
- 터치 이동이 화단 모서리에 걸리는 문제를 실제 화면에서 재현했다. 경유점에 조금 덜 도착한 상태에서 방향을 꺾던 오차를 수정하고, 실제 프레임 루프로 집 앞에서 횡단보도까지 이동하는 회귀 테스트를 추가했다. 웹 포커스 때문에 월드가 스크롤되던 현상도 차단했다.
- 노선·종점·카드 승인·하차벨·체크포인트·기록 보관, 충돌과 횡단보도, 시간 정지·재개·음성 콜백에 대한 자동 회귀 테스트를 추가했다. 10절의 실제 조작 검증과 함께 유지한다.
- 웹 빌드가 완료됐고 로컬 게임 미리보기 서버가 정상 응답한다. Expo Go 외부 터널의 iOS manifest에서 SDK 57 및 로그인 계정 정보를 확인했고, 외부 iOS JavaScript 번들도 HTTP 200으로 수신했다. 이 확인을 휴대폰에서 직접 플레이한 결과로 간주하지 않는다.
- 패키지 선언과 잠금 파일의 frozen 검증은 통과했다. Expo 호환성 검사에는 기존 SDK 57 패키지 10개의 최신 패치 권고가 남아 있다. 설치 정리 중 `jest-watch-typeahead` 임시 폴더 오류도 재현돼 설치 목록 메타데이터 정리는 남겨 두었으며, 현재 앱 번들과 패키지 로딩은 확인했다. 이 작업에서 SDK나 권고 패키지 버전을 임의로 변경하지 않았다.
