# 마트 크기·진열대·화면 전환 수정 보고서

작성일: 2026-09-11. 대상: `frontend/`의 Expo 장보기 게임.

후속 개편은 [마트 구조 개편 v2 보고서](market-layout-v2.md)에 기록했다. 기본 배율을 최소 배율로 고정하고, 정면 진열대·생활용품·세로 계산대 2개·새 입출구 배치로 변경했다. 아래 수치는 당시 작업 기록이다.

요청한 NPC 축소, 진열대 절반 크기와 쌍 배치, 계산대 축소, 마트 화면 확대, UI 전환 애니메이션을 적용했다. 마을에서 들어가는 마트와 개발용 독립 마트 화면에 같은 가구·사람 배치 기준을 사용한다.

## 적용한 크기

| 대상 | 변경 | 동작과 배치 |
| --- | --- | --- |
| 종업원·손님·계산원 | 기존 몸체의 68% | 발 위치를 기준으로 축소하고 사람의 충돌 영역도 맞춤. 이름표는 읽을 수 있는 크기 유지 |
| 진열대 한 개 | 가로·세로 각각 기존의 50% | 이미지 한 개는 월드 좌표 기준 141×94. 같은 분류의 두 진열대를 나란히 배치 |
| 계산대 | 가로·세로 각각 기존의 70% | 그림·그림자·직원 공간·충돌 영역을 함께 축소하고 기존 중앙 위치와 계산 접근점 유지 |
| 마트 내부 화면 | 기본 1.3배 | 마을에서 입장할 때 약 260ms 동안 확대. 퇴장할 때 입장 전 마을 배율 복원 |

크기 수치는 카메라 확대 전 월드 좌표 기준이다. UI의 글자·버튼은 마트 카메라 확대에 포함하지 않는다. 일반 게임의 기존 휠·핀치 배율 조절과 확대된 화면의 터치 좌표 계산을 유지한다.

확대된 화면 밖의 버튼에 포커스가 갈 때 브라우저가 지도만 별도로 스크롤하던 현상도 수정했다. 웹의 지도 경계를 CSS `overflow: clip`으로 처리해 카메라와 플레이어의 중앙 위치를 유지한다. 네이티브에서는 기존 경계 처리를 사용한다.

## 두 진열대가 한 분류로 동작하는 방식

냉장 식품, 과일/채소, 간편 식품, 음료마다 기존 그림과 새 그림을 한 쌍으로 배치했다. 총 8개 그림이며 분류·상호작용 지점·재고는 기존처럼 4개다. 두 그림은 하나의 선택 영역과 이름표를 공유하며, 어느 쪽을 눌러도 같은 분류로 접근하고 같은 상품 화면을 연다. 환경 설정의 진열대 순서를 바꾸면 두 그림이 함께 이동한다.

과일은 표시 이름을 `과일/채소`로 바꾸고, 과일 그림 옆에 양파·감자·오이·브로콜리·배추가 담긴 같은 형태의 목재 진열대를 추가했다. 내부 식별자 `produce`는 유지하므로 기존 환경 JSON과 에피소드의 분류 ID를 바꿀 필요가 없다.

진열대 그림은 분류를 나타내는 장식이고, 실제 구매 가능한 상품·개수는 세션의 12칸·9종 재고를 따른다. 두 그림 때문에 재고가 두 배로 늘어나지 않는다.

새 투명 PNG 파일은 모두 `frontend/assets/images/game/market/interior/`에 있다.

| 파일 | 두 번째 진열대의 내용 |
| --- | --- |
| `shelf_fresh_variant_v1.png` | 요구르트·치즈·버터·초코 우유·딸기 우유 |
| `shelf_produce_variant_v1.png` | 양파·감자·오이·브로콜리·배추 |
| `shelf_meal_variant_v1.png` | 컵라면·파스타·참치캔·수프·죽 |
| `shelf_drink_variant_v1.png` | 녹차·커피·두유·스포츠 음료·레몬 음료 |

기존 가구를 참고해 이미지를 생성한 뒤 원본의 투명 윤곽을 보존해 적용했다. 네 이미지 모두 1536×1024 RGBA PNG이며 원본의 alpha와 모든 픽셀이 일치한다. 생성 프롬프트·원본·검증 기록은 [냉장 식품과 채소](design-concepts/2026-09-11-shelf-variants-a.md), [간편 식품과 음료](design-concepts/2026-09-11-shelf-variants-b.md)에 기록했다.

## 부드러운 UI 전환

- 시작 안내, 환경 설정, 이전 기록, 이용 방법, 장바구니, 직원 대화, 구매 확정, 실패·재시도, 종료·별점 화면에 약 220ms 페이드를 적용했다.
- 진열대 화면의 등장·퇴장 전환을 유지하고 진열대 안 장바구니에는 높이 변화와 페이드를 함께 적용했다.
- 닫히는 화면이 사라질 때까지 배경 이동과 터치를 막아, 닫기 버튼을 누른 입력이 뒤의 지도에 전달되지 않게 했다.
- 전환 중에도 장바구니·설정·시도 횟수 등 게임 상태를 유지한다.
- 기기 및 웹 브라우저의 모션 감소 설정에서는 해당 전환을 즉시 처리한다.

## 개발자가 조절할 파일

| 목적 | 파일 |
| --- | --- |
| 사람 크기와 발 기준 프레임 | `frontend/src/game/marketPersonLayout.ts` |
| 진열대 크기·쌍 간격 | `frontend/src/game/marketFixtureLayout.ts` |
| 진열대 슬롯·사람 충돌 영역 | `frontend/src/game/marketEnvironment.ts` |
| 계산대 크기·계산원 위치 | `frontend/src/game/prototypeWorld.ts` |
| 마트 기본 배율 | `frontend/src/game/worldZoom.ts` |
| 마트 팝업 전환·모션 감소 처리 | `frontend/src/components/game/MarketPanelTransition.tsx` |

정우·재현이 사용하는 환경 JSON과 에이전트 행동 계약은 그대로다. 가구 그림을 두 개로 늘려도 AI는 기존 분류 하나로 관측·이동·상호작용한다. 실행 시 반환되는 `environment`의 실제 좌표를 사용하고, 이전 지도 좌표를 외부 실행기에 고정하지 않으면 된다. 전체 환경 변수와 AI 연결 설명은 [기존 인수인계 보고서](market-environment-handoff.md)를 참고한다.

## 검증

- 타입 검사와 웹 빌드 통과.
- 전체 테스트 `pnpm test --silent`: **20개 테스트 묶음, 129개 테스트 전부 통과**. 통합 테스트도 전환 완료와 이동 잠금 해제를 기다린 뒤 플레이하도록 갱신했다.
- 진열대 한 쌍의 단일 동작, 축소된 충돌 영역, 100개 시드의 통행 경로, 1.3배 화면의 터치 좌표 변환을 검증했다.
- Headless 플레이 검증에서 118개 이벤트, 2회 제출 후 성공, 분류별 12칸·9종을 확인했다.
- 브라우저에서 마을 내 마트의 새 크기와 8개 진열대 그림을 확인했다. 375×812 화면에서 분류 접근, 상품 담기, 장바구니 열기·닫기를 조작했고 계산대 구매 확인 화면까지 확인했다.
- 웹 개발용 마트의 오류 로그가 비어 있음을 확인했다. 확대 지도에서 포커스로 생겼던 가로 스크롤이 수정 후 0으로 유지되고 플레이어가 화면 중앙에 표시됨을 확인했다.
- 실제 iOS·Android 기기 화면은 이번 수정에서 직접 검증하지 않았다.
