## 📝 프로젝트 소개
> 이 서비스는 자폐 아동이 일상생활과 관련된 게임을 수행하며 사회적 자립심을 키우는 앱입니다.<br>
> 아동은 기능성 게임을 통해 거부감 없이 사회에 적응하는 법을 배우며, 부모는 자식의 수행과정을 확인할 수 있습니다.
