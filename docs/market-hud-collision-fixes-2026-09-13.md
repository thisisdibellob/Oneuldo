# 마트 HUD·벽 충돌·출구 경보기 수정

2026-09-13. 이번 요청 다섯 항목과 추가로 확인한 메뉴·뒤로가기 동작을 정리한다. 상품·재고·구매 판정·재시도 규칙은 유지한다.

## 요청별 반영

| 요청 | 반영 내용 | 주요 파일 |
| --- | --- | --- |
| 1. 엘리베이터 사이 벽 진입 차단 | 보이는 벽면 전체 (50,96,236,148)를 하나의 충돌 영역으로 사용한다. 두 문 사이와 벽 뒤쪽에 들어갈 수 없고, 문 앞 y260 접근로는 열린다. 기존 문·뒷벽 충돌은 이 영역으로 합쳤다. | frontend/src/game/marketEnvironment.ts, MarketArchitectureLayer.tsx |
| 2. 출구 경보기와 미결제 감점 | 기존 입구·측면 경보기에 출구 (850,1010,160,40)를 추가했다. y1030을 매장 밖 방향으로 넘으면 설정 점수를 차감한다. 짧은 경계 왕복은 중복 감점하지 않으며, 매장 안쪽 x355 이상·y970 이하로 복귀하면 다시 활성화한다. | marketEnvironment.ts, marketSession.ts |
| 3. 마트에서도 마을의 시간·코인·메뉴 사용 | 기존 GameHud를 재사용해 위쪽 시간·코인과 아래 가방·수첩·휴대폰·설정을 제공한다. 마트 패널이 열렸을 때 HUD 표시와 입력 잠금을 함께 처리한다. | GamePrototypeScreen.tsx, GameHud.tsx |
| 4. 하늘마트 안내 중앙 정렬 | 독립 실행·마을 내부 실행 모두 MarketHud 카드를 중앙 배치하고 최대 폭 420으로 제한한다. 마을 내부에서는 top112로 시간·코인 아래에 놓는다. 일반 팝업 제목도 중앙 정렬한다. | MarketHud.tsx, MarketSimulationScreen.tsx의 ModalCard |
| 5. 직원 대화를 마을 대화 스타일로 통일 | 어두운 둥근 말풍선, 금색 기울어진 이름표, 흰색 둥근 선택지를 사용한다. 아래쪽 배치와 작은 화면 스크롤을 지원한다. 계산원 요청, 상품 1개·전체 반납, 돌아가기·감사·포기를 유지한다. | MarketStaffDialogue.tsx, MarketSimulationScreen.tsx |

표에서 경로를 줄여 쓴 화면은 frontend/src/screens/, 컴포넌트는 frontend/src/components/game/, 게임 모델은 frontend/src/game/에 있다.

getMarketElevatorFacadeRect(objects,walls)가 표시와 충돌에 같은 사각형을 제공한다. 이전 layout-v3 환경에 이 벽 충돌이 빠져 있으면 장애물 조회에서 보완한다.

출구 경보는 미결제 상품이 있는 경우에만 적용된다. 빈 장바구니, 결제된 장바구니, 공용 복도·공동 출입문 이동은 감점 대상이 아니다. 기존 이벤트 이름 entrance_alarm은 연동 호환을 위해 유지하며 payload.gateId='exit'로 출구를 구분한다. 환경 schemaVersion1·layoutVersion3과 시드·상품 기록 계약을 유지한다.

설정 표시와 접근성 이름을 **출입 경보기 감점**으로 바꾸고, 도움말에 **입구·출구·측면 출입문**을 명시했다. 출구 표지에도 경보기를 표시한다. 이전 보고서의 “정상 출구에는 경보 감점 없음”은 이번 추가로 변경된 내용이다. 최신 규칙은 [AI 연동 계약](../frontend/docs/market-agent-contract.md)을 따른다.

## 함께 보완한 동작

휴대폰 메뉴에서 포기한 뒤 메뉴 상태가 남지 않도록 정리했다. Android 뒤로가기는 직원 반납 도움 → 직원 대화 → 장보기 순서로 돌아오도록 보완했다. 위치 복구는 marketRecovery.ts에서 장바구니를 유지하며 경보를 건너뛰지 않도록 처리한다.
