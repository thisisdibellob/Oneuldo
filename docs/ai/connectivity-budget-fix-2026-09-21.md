## 코드 변경

1. **학교 기본 예산:** 컨텍스트 18,432 / 요청 예산 18,000으로 통일했다. 게이트웨이 한도 18,176과 추가 포장 32토큰 안에 들어간다. 관찰·최종 출력은 각각 1,800, AI 검토는 활성 상태로 유지한다.

3. **시작 단계 설정 검사:** 컨텍스트와 요청 예산이 맞지 않으면 `OLLAMA_ANALYSIS_BUDGET_MISMATCH`로 즉시 알린다. 시작 로그에 실제 두 값을 남긴다. 키는 기록하지 않는다.
4. **최종 분석 예산:** 고정 `2 × 출력 상한 + 1500` 대신 초안 요청과 현재 검토 템플릿의 토큰을 별도로 계산하고 둘 중 큰 값을 사용한다. 검토에는 아직 생성되지 않은 초안의 출력 상한과 포장 여유 256을 예약한다. 추정치이며 모든 가능한 초안의 크기를 보장하지 않으므로, 실제 요청도 전송 직전에 다시 검사한다. 사건 삭제나 내용 판단을 규칙으로 대체하지 않는다.
5. **연결 진단:** 요청별 UTC 시작·종료 시각, 연결 주소와 포트를 기록한다. 최대 10회 반복과 `--direct` IPv4/프록시 우회 비교를 지원한다. 인증서 검증과 기존 기본 경로 검사는 유지한다.
