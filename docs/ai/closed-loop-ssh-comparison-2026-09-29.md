# SSH 경로 재검증과 AI 분석·퀘스트 비교 — 2026-09-29

17:01 KST 중간 정리. 사용자가 실수로 앱을 건드린 뒤 현재 결과부터 정리하도록 요청하여 새 플레이를 시작하지 않았다. 일반 과제 2회차 AI 분석은 계속 실행 중이다. 이전 공개 HTTPS 실패 이력은 [이전 보고서](closed-loop-repeat-analysis-2026-09-29.md)에 보존한다. 운영 서버 배포·모델 교체·방화벽 수정은 하지 않았다.

## 연결과 기준 분석

사용자가 연 SSH 공유 연결을 통해 로컬 18083 → 학교 게이트웨이 8081로 호출했다. 인증된 모델 목록 조회 3회는 각각 0.029/0.024/0.023초, 인증 없는 요청은 401, 실제 채팅은 9.932초에 성공했다. 공개 HTTPS 경로의 일반적인 안정화까지 입증하지는 않는다.

같은 7,972개 이벤트 스냅샷을 재개했을 때 SSH 연결은 성공했지만 통합 근거 오류가 재현됐다. 자식 관찰이 인용한 ID만 `allowedEvidenceEventIds`로 제공하도록 통합 프롬프트를 보완했다. 요약·불확실성·범위 경계 ID를 관찰 근거로 승격하지 않도록 명시했다. 검증기를 완화하거나 모델 출력을 사후 수정하지 않았다.

보완 후 분석 `7706626b-6baa-455f-a967-68148e254180`은 16:16:40 KST에 READY가 됐다. 서비스 724.205초, 클라이언트 724.783초. 관찰 41개 checkpoint를 재사용하고 통합 10회·초안·검토 총 12회는 실제 모델을 호출했다. 이는 캐시 없는 전체 분석 시간과 다르다.

## 기준 분석의 내용과 한계

- 흰 우유 1개와 낱개 바나나 1개를 선택한 사실, 목표의 바나나 1송이와 실제 상품 ID가 다른 점을 포착했다.
- 선택 동기, 이동 의도, 장바구니 내용을 실제로 읽고 이해했는지는 판단할 수 없다고 구분했다.
- 다음 연습은 우유 1개·바나나 1송이 선택과 제출 전 목표-장바구니 비교다.
- 최종 판단은 UNDETERMINED다. 이미 드러난 품목 불일치를 ‘품목 일치 여부가 불확실’로 표현한 점은 과도한 유보다. 제출 조작과 서버 수락을 구분하는 것과 상품 불일치 자체를 불확실하게 만드는 것은 별개다.
- 초안의 바나나 근거 ID 오류는 최종 AI 검토에서 수정됐다. READY는 구조·근거 검증 통과이며 임상적·교육적 타당성 인증이 아니다.

## 프로필과 퀘스트 연결

원래 `/resume`은 분석만 저장하므로 격리 DB 전용 opt-in 테스트에서 실제 `AiUserProfileService.updateFromSession`을 호출했다. READY 분석·회원·고정 입력·최신 완료 세션을 확인하고 원래 데이터셋을 그대로 연결했다. 별도 분석이나 행동 로그를 조작하지 않았다. 테스트 실행 환경의 H2 드라이버와 테스트 전용 entity 문제는 PostgreSQL 드라이버 및 DDL/마이그레이션 비활성으로 해결했다. 데이터베이스 생성·삭제 작업은 하지 않았다.

첫 AI 퀘스트는 S01을 선택하면서 고정 예산 7,000원을 6,200원으로 바꿨고, 두 번 모두 INVALID_AI_QUEST로 실패했다. 과거에도 같은 유형의 고정 시나리오 예산 오류가 기록돼 있다. 이번에는 고정 시나리오와 CUSTOM의 예산 조건을 명확하게 분리하고, 재시도에 검증기의 구체적인 실패 항목을 전달하도록 보완했다. 상품 선택이나 사용자 능력 판단을 규칙으로 대신하지 않았다.

프론트는 이 실패 후 일반 S02를 표시했다. 이 과제는 맞춤 반복으로 재생하지 않았고 시작 전 취소했다. 취소 과정의 기술적 세션은 행동 표본이나 학습 성과에 포함하지 않는다.

## 해석 원칙

페르소나 v5와 stochastic 정책 v5, 회차별 고정 seed를 사용한다. 행동 확률을 성공에 맞춰 수정하지 않으며 실제 완료된 조작/상품 경험만 다음 회차에 전달한다. 이 actor는 안내 문장으로 내부 정책을 학습하는 구조가 아니다. 과제별 성공률과 시간은 기술적 비교 자료이며 실제 지적장애인의 능력 향상을 입증하지 않는다. 공통 사후 평가와 복수 seed 없이 인과 효과를 판단하지 않는다.

## 남은 문제와 실행 상태

1. 분석의 사실 불일치에 대한 과도한 유보, 퀘스트의 선택 원인 단정과 내부 코드 노출이 남았다.
2. 퀘스트 생성 실패 때 프론트가 일반 과제를 보여주는 경로가 있다. 실험에서는 source=AI와 분석/프로필 ID를 확인하여 혼입을 막았지만 제품 화면에서도 구분할 필요가 있다.
3. 전처리와 다수의 순차 모델 호출이 여전히 길다. 현재 설정의 최대 관찰 구간은 64이며, 긴 맞춤 회차는 전체 분석 전에 이 한도를 검토해야 한다. 이번 중단된 회차에 대한 완료 분석을 만들지는 않았다.
4. 가상 actor는 stochastic v5이고 안내 문장으로 정책을 학습하는 모델이 아니다. 이동 425개 같은 긴 탐색은 시뮬레이터 특성도 점검해야 하며 장애인 집단의 일반적 행동으로 해석할 수 없다.
5. SSH 경로에서 보완 후 모델 연결 재시도는 현재 0회다. 이는 공개 HTTPS 문제 해결이나 향후 연결 무중단을 보장하지 않는다.
