## 이것으로 확인할 수 있는 것과 없는 것

- 추천 생성에서 실제 다음 플레이와 재분석까지 이어지는 연결은 3회 확인했다.
- 첫 추천부터 정확했으므로 **정확한 수행의 유지**를 확인했다. 능력이 향상됐다는 결과는 아니다.
- 과제는 같은 상품·수량을 반복했고 마지막 예산만 200원 줄었다. 새로운 품목으로의 전이, 지원 없이 유지되는 학습, 실제 생활 수행 향상은 측정하지 못했다.
- 행위자는 assistant가 화면을 읽고 행동을 선택한 허구의 지민(v5)이다. 확률 정책이나 별도27B 행동 모델을 사용하지 않았으며 실패·향상률을 강제로 넣지 않았다. 기존 매장 경험도 있어 실제 지적장애인의 대표 표본으로 취급할 수 없다.
- 일반 조건과 비교하지 않으므로 AI 추천의 인과적 효과를 계산할 수 없다. 소요 시간도 도구 지연·매장 친숙도 영향을 포함한다.

## 확인한 품질 문제

1. **미구현 환경 변경을 안내함.** 세 번째 추천은 “오늘은 선반 위치가 바뀌었습니다”라고 했지만 실제 배치는 같았다. 추천 스키마에 배치를 변경할 필드도 없다.
2. **안내의 오류가 다음 분석에 전파됨.** 세 번째 분석은 “변화된 매장 환경에서도” 잘 수행했다고 판단하고 다시 선반 변경 연습을 권했다. 안내 문장과 실제 환경 증거를 혼동했다.
3. **조작을 인지 행동으로 확대함.** 장바구니 열기와 기록된 금액을 근거로 “내용을 확인”, “예산 이내임을 인지”라고 서술했다. 불확실성에는 의도를 모른다고 적어 모순된다.
4. **사건 횟수 요약 오류.** 장바구니를 2회 열었는데 두 번째·세 번째 분석 요약은 “각 품목 추가 후” 열었다고 썼다.
5. **목표 안내가 부족함.** 추천의 우유·생수 용량이 빠지고 상단 목록도 이름만 표시했다. 예산도 목표 목록에 상시 표시되지 않았다. 숨겨진 목표 조건을 모르는 것은 사용자 능력 부족의 증거가 아니다.
6. **연습 목표와 변화 조건이 불명확함.** 세 번 동일 품목의 반복만으로 학습 효과를 측정할 수 없었다. 성공한 수행 유지와 실제 오류 교정을 구분해야 한다.
7. **분석 대기 시간이 김.** 2분대 플레이에 10~16분 분석 API 대기가 발생했다. 이번 변경은 품질 개선이며 전체 처리 시간 최적화를 완료한 것은 아니다.

## 수정 내용

- 목록·브리핑·HUD에 상품 규격, 구매 수량/단위, 예산을 표시한다. 고정 과제의 허용 대체품은 보존한다. 기존 “사과2개 + 2개”처럼 중복된 수량 표시는 제거하고 포장 규격(10개입)은 유지한다.
- 퀘스트 모델에 실제 변경 가능한 상품·수량·예산·문자 안내 범위를 명시했다. 선반 위치나 새 UI 기능을 바꿨다고 안내하지 않도록 했다.
- 결제 전 안내에서 이미 구매가 완료됐다고 말하지 않도록 했다. 쉬운 한국어 안내를 요청했다.
- 분석·최종 검토·프로필에 관측된 조작/값과 이해·의도 구분을 일관되게 전달했다. 미션 안내만으로 실제 환경 변경을 인정하지 않도록 했다.
- 최종 검토에 이전 초안의 판단 문장을 다시 주입하지 않고 원본을 독립 검토하도록 바꿨다. 모든 인용 사건이 원본 사본에 있는 중간 관찰만 중복 제거한다. 원본이 없는 이동 관찰·부분 근거 관찰·불확실성·원본 사건은 보존한다.
- AI가 연습 목표 한 가지, 유지할 조건, 다음 회차 관찰 대상을 제안하게 했다. 성공 뒤 반복은 부족함 교정이 아니라 유지·전이 관찰일 수 있다고 명시했다.
- 능력 판단·문장 교정을 서버 규칙으로 대체하지 않았다. 원본 근거 검사는 유지했고 안전 검증을 해제하지 않았다.

## 검증

3회 플레이는 같은 기존 런타임(analysis v27 / review v17 / quest v8)으로 완료했다. 그 결과를 수정 효과로 포장하지 않는다. 수정안은 별도 고정 입력의 실제 모델 호출과 회귀 검사로 검증한다.

- 프런트 관련 테스트11개, TypeScript 검사 통과. 화면에서 사과2개·생수500mL1개·예산4,000원 표시를 직접 확인했다. 이 화면 QA는 별도 계정이며 추천3회 결과에 포함하지 않는다.
- 백엔드 관련 회귀 검사53개 통과: 원본/일부 미포함 이동 근거 보존, 목표 대조, 출력/인용 계약, 프로필 계약, 퀘스트 호환 조건 등.
- 단순 문구 보완(v18)은 실제 모델의 근거 과장을 해소하지 못했다. 그 실패 원문도 보존했다.
- 독립 검토(v19)의 기준 세션 재검증: 분석+추천 구조검증 PASS, 90.102초. 상세 관찰은 “장바구니를 열었고, 기록된 내용은…”으로 바뀌었다. 그러나 요약의 “내용을 확인”은 남았다. 추천에는 규격이 명시됐지만 일부 중국어 낱말이 섞이는 새 오류도 발견했다. 따라서 전체 의미 품질 통과라고 보고하지 않는다.
- 세 번째 추천의 잘못된 환경 안내 사례 재검증(v19): 85.625초. 환경 변경을 실제 사실로 받아들이는 의미 오류가 남았고, 추천은 계획3품목 대신2품목을 출력했다. 구조 검증에서 실패 처리했으며 원문을 `round3/live-quality-v19-failed.json`에 보존했다. 이 단일 호출 검사는 운영 서비스의 교정 재시도까지 실행한 것이 아니므로 운영 요청 전체 실패율로 해석하지 않는다.

## 최종 수정안 실제 모델 검증 (review v20 / quest v9)

- 개선: 장바구니 상세 관찰이 실제 수량·금액으로 바뀌고, 잘못된 “각 품목 추가 후” 대신2회 조작을 설명했다. 배치가 실제로 바뀌었다는 단정은 “변경 안내가 있었다”로 약화됐다.
- 개선: 새 퀘스트는 우유900mL1개·바나나1송이·생수500mL1개·사과1개, 예산8,000원이다. 목표 합계7,800원으로 실행 가능하며 계획4품목과 일치한다. 가짜 선반 변경, 제출 전 완료 선언, 중국어 낱말은 이번 출력에서 나타나지 않았다.
- 미해결: 요약의 “브리핑을 읽고”, “내용을 확인”과 해석의 “금액을 확인”은 여전히 조작만으로 입증되지 않는다. 불확실성에도 근거 없는 “습관/우연” 대안을 끼워 넣는다.
