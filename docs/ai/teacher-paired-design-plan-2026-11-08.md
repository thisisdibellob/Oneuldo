# Qwen vs 전문가 교사 쌍 설계 계획 (2026-11-08, 아직 실행 안 함)

## 1. 목적
- **같은 조건에서 Qwen 교사와 전문가 교사가 낸 연습의 차이**를 봐요.
- "교사가 있으면 나아지나"(교사 없음 대비)는 이번 목적이 아니에요. 필요하면 세 번째 갈래로 붙여요(7절).
- 방향은 미리 정하지 않아요. "차이 없음"도 결과로 보고해요.

## 2. 앞 실험(1~6)에서 바꾸는 점
| 문제 | 앞 실험 | 이번 설계 |
|---|---|---|
| 처음 실력이 우연히 한쪽에 몰림 | 교사마다 다른 참가자 | **같은 처음 시험을 두 교사에게 줘서 두 갈래로 나눔** |
| 재시험 효과가 교사 효과를 가림 | 마지막 시험 = 처음 시험 매장 | **마지막 시험은 처음 보는 매장** |
| 다 성공하면 차이 0 | 성공/실패만 셈 | **숫자 지표를 주 지표로** |
| 시범 3번으로 난이도 오판(실험 4 50% vs 실험 6 92%) | 시범 3번 | **매장마다 시범 6번, 30~70%만 채택** |
| 연습 품질을 따로 보지 않음 | 장보기 결과만 | **교사가 낸 연습 자체를 미리 정한 기준으로 비교** |

## 3. 설계

### 3-1. 갈래 나누기
```
참가자 p01..p12 각각
  r0  처음 시험 (매장 P 또는 Q) ─┬─ 전문가 갈래 pNN-E: r1 r2 r3 연습 → r4 마지막 시험
                                  └─ Qwen 갈래   pNN-Q: r1 r2 r3 연습 → r4 마지막 시험
```
- 두 갈래 r1의 `memory-in.md`에는 같은 r0 `memory-note.md`를 넣어요.
- 두 교사는 같은 r0 `outcome.json`을 받아요.
- 장보기 AI는 원래 회차마다 새로 뽑아요. 그래서 r0 하나를 두 갈래가 이어받아도 앞 실험과 같은 규칙이에요.
- 두 갈래는 동시에 돌려도 돼요. 같은 시간대의 계정 상태와 네트워크 조건을 받게 돼요.

### 3-2. 시험 매장 P·Q (교차 배치)
- P와 Q는 같은 매장 종류이고 매대 순서만 달라요. 실행기 시드(`v2executor-s01`)와 매대 크기, 재고는 같아요.
- 처음 시험 매장
  - p01~p06은 P에서 봐요.
  - p07~p12는 Q에서 봐요.
- 마지막 시험 매장은 각자 처음 시험과 반대예요.
- P, Q의 매대 순서는 연습 매대 순서 B·C·D와 겹치지 않게 새로 정해요.
- 연습에는 P·Q 매대 순서와 시험 상품을 쓰지 않아요. 검사기에 금지 규칙을 추가해요.
- 시험 물건은 실험 3~6과 같아요: 큰 흰 우유 1.8L 1개 + 낱개 바나나 1개짜리 2개 + AAA 건전지 4개입 1개, 예산 10,000원.

### 3-3. 고정 조건 (앞 실험과 같게 유지)
- 장보기 AI는 회차마다 새로 뽑는 Claude Sonnet이에요. 실행기 라벨 `gpt-6-luna`는 보고서에 그대로 밝혀요.
- 장보기 AI 안내 v4, 행동 100번, 기억 메모 300자예요.
- 교사 안내
  - 전문가: 초안 A → `quest_checks.py` → 검토 B, 실험 4 지시문 그대로
  - Qwen: `qwen_teacher.py`, 같은 모델 `qwen3.6:27b-q4_K_M`, 같은 재시도 한도
- 비교 대상은 **각자 원래 방식대로 낸 교사**예요. 두 교사의 처리 과정(2단계 검토 vs 재시도)은 다르고, 보고서에 이 점을 밝혀요.
- 실패 처리 규칙은 앞 실험과 같아요.
  - 성공은 정확한 장바구니를 장보기 AI가 직접 계산했을 때만이에요. 자동 계산은 실패예요.
  - 과제 작성 실패와 기록 오류도 실패로 세고 다시 돌리지 않아요.

## 4. 지표 (실험 전에 고정, 중간에 바꾸지 않음)

### 4-1. 주 지표 (하나)
- **마지막 시험의 헤맨 걸음 수 = 걸은 횟수 − 그 매장의 최단 경로 걸음 수**
  - 최단 경로는 감독 전용 `world-reference`로 계산해요(5절 점검 B).
  - 참가자마다 (전문가 갈래 − Qwen 갈래) 차이를 계산해요.
  - 실패한 회차는 남은 걸음을 모두 쓴 것으로 봐요(걸은 횟수 = 그 회차의 실제 걸음 수, 최소 0).

### 4-2. 보조 지표
1. 마지막 시험 성공 여부
2. 마지막 시험에서 시험 매대 표지가 처음 보인 결정 번호
3. 마지막 시험에서 찾은 물건 수(0~3), 규격 실수 수
4. 연습 3번 성공 수
5. 처음 시험 → 마지막 시험 헤맨 걸음 변화

### 4-3. 연습 과제 비교 (장보기 AI의 흔들림과 무관)
- **자동으로 세는 것:**
  - 검사기 첫 통과율, 다시 쓴 횟수, 규칙 위반 종류
  - 물건 수, 매대 수
  - 매장 종류, 공사·손님 설정
  - 시험 매대와 같은 매대를 쓴 비율
- **처음 시험 실패 원인과 맞는지:**
  - r0에서 찾지 못한 매대가 연습에 들어갔는지 봐요.
  - r0에서 겪은 장애(공사, 막다른 길, 규격 실수)가 연습에 들어갔는지 봐요.
  - 기준은 r0 기록에서 기계적으로 뽑아요(못 찾은 물건의 매대, 공사 여부).
- **눈가림 채점(보조):**
  - 출처를 지운 과제 쌍을 채점자 AI가 미리 정한 기준표로 매겨요.
  - 채점자가 Claude라서 전문가(Claude) 쪽으로 기울 수 있어요. 그래서 자동 지표를 우선하고, 채점 결과는 보조로만 보고해요.

### 4-4. 분석
- 주 지표는 짝지은 부호 순위 검정(12쌍, 양측)으로 분석해요. 효과 크기와 95% 부트스트랩 구간을 같이 보고해요.
- 성공 여부는 짝지은 McNemar 검정으로 분석해요. 12쌍으로는 큰 차이만 잡힌다는 점을 미리 밝혀요.
- 처음 시험 매장(P/Q)에 따라 결과가 갈리는지도 확인해요.
- 중간에 결과를 보고 멈추거나 인원을 바꾸지 않아요. 12쌍을 다 돌린 뒤에 분석해요.

## 8. 하지 않는 것
- 장보기 AI의 지능, 행동 한도, 기억 용량을 바꾸지 않아요. 정답 행동도 넣지 않아요.
- 최단 경로나 매장 배치를 장보기 AI나 교사에게 보여 주지 않아요. 감독 전용이에요.
