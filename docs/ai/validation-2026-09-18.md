# AI 분석 및 학교 서버 검증 기록

## 반영 내용

- 연결 수립 실패에만 제한된 재시도를 적용하고 DNS·TLS·인증·대기열·응답 시간 초과를 구분한다. 이미 추론 중일 수 있는 응답 시간 초과는 자동 재전송하지 않는다.
- 원본 사건의 순서와 값을 제공하고 AI에게 분석 문장별 근거 검토를 요구한다. 코드에서는 구조·인용·순서·누락을 확인하며 의미 판단이나 성패 점수는 계산하지 않는다.
- 관측·분석·프로필에서 근거 없는 대안 설명을 최소 1개 요구하던 조건을 제거한다. 빈 배열은 화면에서도 숨긴다.
- 세션 종료와 제출 후 화면 이탈을 구분하고, 미확인 사실을 능력 부족으로 해석하지 않도록 분석·퀘스트 프롬프트를 수정한다.
- 학교 전용 Java·네이티브 토크나이저·HTTPS 배포 스크립트와 팀원 연결 진단 명령을 보존한다.

## 분석 품질 검증 범위

2026-09-17 저장된 합성 플레이 208개 사건의 기존 초안을 3회 재검토하고, 장바구니 열기와 수량 변경 순서를 바꾼 간소화 사례를 각각 3회 검사했다. 실제 학교 모델을 호출한 9건 모두 구조 검증을 통과했고 재시도는 없었다. 관찰 문장의 수량과 사건 순서를 원본과 직접 대조했다.

208개 사건의 검토 단계는 48.3~75.1초였다. 전체 관측·분석·프로필·퀘스트 생성 시간이 아니다. 일부 해석에 구매 의도를 추정하는 표현이 남아 있어 사실성 문제가 완전히 해결됐다고 판단하지 않는다. 이 검사는 실제 장애 당사자의 교육 효과 검증이 아니다.

당시 코드 검사 64개와 오프라인 파이프라인 재생 1개가 통과했다. 실제 모델/재생 검사는 API 키와 로컬 실험 자료가 필요한 선택 실행 검사다. 기본 테스트에서 실행하지 않는다.

## 학교 게이트웨이 업데이트

2026-09-18 기존 학교 게이트웨이가 신규 관측 스키마를 `UNSUPPORTED_OUTPUT_SCHEMA`로 거부하는 것을 재현하고 업데이트했다. 설치 후 기존·신규 스키마 수용, 임의 스키마 거부, 무인증 401 및 관리자 키 인증 200을 확인했다.

신규 스키마를 사용한 실제 관측 생성은 HTTP 200, 왕복 10.509초였다. 사과 수량 1→2, 근거 E1, 빈 대안 배열, 변경 동기를 확인할 수 없다는 결과가 반환됐다. 검사 경로는 SSH로 전달한 서버 내부 게이트웨이였으며, 공개 HTTPS 복구를 의미하지 않는다. 기존 JAR은 백업했고 키·GPU·Caddy·방화벽·DNS 설정은 변경하지 않았다.

## 미해결: 외부 TCP 연결

서버 내부 HTTP·HTTPS와 실제 AI 추론은 정상이다. 공개 HTTPS는 정상 응답과 TCP 연결 시간 초과가 섞여 있다. 서버의 UFW는 TCP 443을 허용한다.

2026-09-18 12:23:21~12:24:06 KST에 서버 enp5s0에서 TCP 443 SYN/RST 헤더를 관측하면서 맥에서 접속을 시도했다. 캡처 구간에 들어간 실패 요청 5건의 패킷은 관측되지 않았고 443 허용 카운터도 변하지 않았다. 학교 Wi-Fi에서 휴대폰 핫스팟으로 바꾼 후에도 6건 중 5건이 TCP 시간 초과였다. 같은 핫스팟의 일반 HTTPS는 정상이었다.

두 접속망을 대조했지만 동일 맥을 사용했다. 학교 상위 장비·공통 경로를 조사할 근거는 있으나 특정 장비의 차단이나 IP 충돌을 확정한 것은 아니다. 학교 네트워크 담당자의 장비 로그·정책 및 ARP 확인이 필요하다. 서버 재시작이나 키 재발급으로 해결됐다고 보고하지 않는다.

팀원 진단 명령:

```bash
python3 backend/scripts/check-ai-connection.py --attempts 3
```

`GATEWAY_UP`과 `AUTH_REQUIRED_EXPECTED`가 정상이다. 개인 키 인증이나 실제 추론 검사는 포함하지 않는다. 키·설정 파일을 읽지 않으며 추론도 실행하지 않는다.

## 자료 관리

원시 응답·패킷 진단·개별 실행 로그와 배포 바이너리는 로컬 `tmp/`·`output/`에 보존하고 새 파일은 Git에서 제외한다. 이미 추적하던 과거 자료는 이번 정리에서 삭제하지 않는다. API 키와 개인 로컬 설정은 커밋하지 않는다.

## 커밋 전 검사 (2026-09-18)

- 백엔드 전체: 185건 중 163건 통과, 21건 건너뜀, 1건 실패.
- 실패는 기존 `QuestMigrationTest`의 H2 마이그레이션 검사다. 변경하지 않은 V37의 PostgreSQL `timestamptz`를 H2가 지원하지 않아 초기화에 실패했다. 해당 SQL에는 PostgreSQL 부분 인덱스도 있어 타입 별칭만 추가해 호환성을 보장할 수 없다. 운영에 적용된 마이그레이션은 이번 정리에서 수정하지 않았다. 따라서 전체 테스트 성공으로 보고하지 않는다.
- 게이트웨이 테스트 통과(Gradle의 최신 테스트 결과 재사용).
- 프론트 TypeScript 검사 및 변경된 행동 수집 테스트 5건 통과.
- Python 연결 진단/설정 테스트 4건 통과. 배포 스크립트 문법 및 Git 공백 검사 통과.
