# 실험 8 계획: 연습이 처음 보는 매장의 길 찾기를 돕는지 (2026-11-09)

> 실행 완료(2026-11-09). 결과: [REPORT](../../output/practice-effect-20261109/REPORT.md). 기준 회차 차이가 평균 12걸음이라 주 비교는 고정 연습 vs 연습 없음 하나만 남았고, 차이는 없었어요(p = 0.96).

## 1. 왜 하나
실험 7([REPORT](../../output/paired-teacher-20261108/REPORT.md))에서 처음 보는 매장의 마지막 시험은 두 교사 모두 처음 시험보다 더 헤맸어요.

| | 헤맨 걸음 평균 |
|---|---|
| 처음 시험 | 35.9 |
| 마지막 · 전문가 | 40.4 |
| 마지막 · Qwen | 44.3 |

교사끼리 비교하기 전에 두 가지를 먼저 확인해요.
- **질문 1 (연습 효과):** 연습을 3번 하면, 연습 없이 바로 보는 것보다 새 매장에서 덜 헤매는가?
- **질문 2 (맞춤 효과):** 교사가 기록을 보고 맞춘 연습이, 정해진 연습보다 나은가?

방향은 미리 정하지 않아요. "효과 없음"도 결과로 보고해요.

## 2. 설계: 실험 7의 처음 시험에 갈래 2개를 더 붙이기
- **원래 기록은 고치지 않아요.** 실험 7의 r0 기록(12명)과 기억 메모를 새 폴더로 복사해서 써요. 실험 7 폴더 원본은 그대로 둬요.
- **새로 붙이는 갈래**

  | 갈래 | 그룹 번호 | 회차 | 마지막 시험 |
  |---|---|---|---|
  | 연습 없음 | g3KK | r0 다음 바로 r4 (기억 메모는 r0 것) | 실험 7과 같은 반대 매장 (1~6번 Q, 7~12번 P) |
  | 고정 연습 | g4KK | r1~r3 고정 과제 → r4 | 같음 |

- **비교하는 갈래**
  - 실험 7의 전문가 갈래(g1KK)와 Qwen 갈래(g2KK)의 마지막 시험 결과를 그대로 써요.
  - 날짜가 다르다는 한계는 3절의 기준 회차로 확인해요.
- **바꾸지 않는 것**
  - 매장 P·Q, 준비 시드 규칙(`pairedteacher-p{k}-r{r}`)이 같아요.
  - 장보기 AI(Claude Sonnet, 안내 v4, 행동 100번, 메모 300자)가 같아요.
  - 실패 처리 규칙이 같아요.

### 2-1. 고정 연습 과제 (실험 전에 고정)
- **원칙**
  - 실험 7 전문가 연습과 같은 매대(냉장 식품·과일/채소·생활용품)의 다른 상품을 써요.
  - 시험 상품 3개(큰 흰 우유 1.8L, 낱개 바나나, AAA 건전지 4개입)와 P·Q 매대 순서는 금지예요.
  - 매장은 기본형이고, 통로형과 입구 공사는 쓰지 않아요.
  - 매대 순서는 r1 B, r2 C, r3 D예요(기본값).
- **과제** (전원 같음, 기록을 보지 않음)

  | 회차 | 물건 | 예산 |
  |---|---|---|
  | r1 | 흰 우유 900mL 1개 + 사과 1개짜리 2개 | 6,000원 |
  | r2 | 작은 흰 우유 200mL 1개 + 배 1개짜리 2개 + AA 건전지 4개입 1개 | 8,000원 |
  | r3 | 흰 우유 900mL 1개 + 사과 1개짜리 2개 + AA 건전지 8개입 1개 | 10,000원 |

- 안내 문장은 4문장 이하로 쓰고 `quest_checks.py`를 통과하게 만들어요. 실험 전에 `fixed-r1~r3.json`으로 고정해요.

## 3. 날짜 차이 확인 (기준 회차)
- 실험 4와 6에서는 같은 설정인데도 날짜에 따라 결과가 크게 달랐어요.
- 그래서 실험 7 전문가 갈래 중 3쌍(참가자 2·7·12, 무작위로 미리 고름)의 마지막 시험을 같은 기간에 다시 돌려요. 같은 r3 기억 메모와 같은 시드를 써요.
- 다시 돌린 헤맨 걸음과 실험 7 값의 차이를 보고해요.
- 차이가 크면(평균 10걸음 이상) 실험 7 갈래와의 비교는 참고로만 쓰고, 새 갈래 둘(연습 없음 vs 고정 연습)만 주 비교로 해요.

## 4. 지표와 분석 (미리 고정)
- **주 지표:** 마지막 시험의 헤맨 걸음(걷기 − 최단 걷기)이에요. `route_metrics.py`로 계산해요.
- **주 비교 2개:** 같은 참가자 안에서 짝지어 비교하고, 정확 부호 순위 검정(양측)에 Holm 보정을 해요.
  1. 고정 연습 − 연습 없음 → 질문 1
  2. 실험 7 전문가 − 고정 연습 → 질문 2
- **보조**
  - Qwen − 고정 연습
  - 마지막 시험 성공 (McNemar)
  - 처음 시험 대비 변화(마지막 − r0)
  - 첫 시험 매대 표지가 보인 결정 번호: 실행기 trace에서 읽도록 `route_metrics.py`를 고쳐요. 실험 7에서는 일부 값이 비었어요.

## 6. 실행 전에 고칠 것 (실험 7에서 배운 것)
- **실행기 작업 한도(10,000건).** 약 40회차마다 호스트를 닫고 새로 열어요. 이번 규모(63회)면 호스트 2개로 충분해요.
- **백그라운드 명령.** 셸 `&`로 띄우지 않고 도구의 백그라운드 실행만 써요. 실험 7에서 g211 r1→r2 준비 단계가 끊긴 원인이었어요.
- **동시 실행.** 장보기 AI는 동시에 6개 이하로 돌려요. 시작할 때마다 `status.sh`로 확인해요.
- **안내 위반이 잦았어요.** 반복문으로 결정 보내기가 많았어요. 결과는 그대로 쓰되, 장보기 AI 안내에 "도우미 스크립트에 반복문을 넣지 않는다"를 더할지는 사용자에게 먼저 물어요. 장보기 AI 조건이 바뀌는 것이라서 실험 7과 비교할 때 차이가 생겨요.
