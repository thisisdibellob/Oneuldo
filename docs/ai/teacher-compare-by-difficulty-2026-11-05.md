# 교사 비교 실험: 난이도별 결과 (2026-11-02 ~ 11-04)

전문가 교사(Claude A 초안 → 자동 규칙 검사 → Claude B 검토), Qwen 교사(학교 서버 `qwen3.6:27b-q4_K_M`), 교사 없음(정해진 연습 과제)을 비교한 실험 4개를 시험 난이도 순서로 정리했어요.

- **공통 조건**
  - 처음 시험 → 교사가 낸 연습 → 마지막 시험(처음과 같은 과제·같은 매장) 순서로 진행했어요.
  - 장보기 참가자는 회차마다 새로 뽑은 Claude Sonnet이에요(실행기 기록 라벨은 `gpt-6-luna`).
  - 행동은 100번까지, 기억 메모는 300자까지 다음 회차로 넘겨요.
- **성공 기준:** 시험 물건을 이름·규격·개수까지 맞게 담고, 참가자가 직접 계산했을 때만 성공이에요. 행동 한도에 걸려 실행기가 자동 계산한 경우는 실패로 셌어요.
- **기록 범위:** 모두 오프라인 실행기 기록이에요. 실제 앱 재생은 하지 않았어요.

## 난이도를 가로질러 보이는 것
1. **교사 효과는 아직 말할 수 없어요.**
   - 마지막 시험에서 교사 사이 차이는 네 실험 모두 0~1명이에요.
   - 쉬운 시험과 어려운 시험에서는 천장·바닥 효과 때문에 차이가 날 수 없었어요.
   - 중간 난이도(실험 3·4)에서는 교사 없음도 거의 다 회복했어요.
2. **중간 난이도에서는 연습만 해도 회복돼요.** 실험 3·4·5·6에서 처음 실패한 10명이 교사와 상관없이 모두 마지막에 성공했어요. 처음과 마지막이 같은 매장이라 "같은 매장을 다시 본 효과"가 섞여 있어요.
3. **실패의 주원인은 규격 실수가 아니라 길 찾기예요.**
   - 매대 표지를 못 보거나, 보이는 매대로 가는 길을 못 찾았어요.
   - 규격 실수는 네 실험을 통틀어 1번(실험 1)뿐이에요.
4. **통로형 매장은 실행기에서 유난히 어려워요.**
   - 시험: 실험 2에서 0/12
   - 연습: 실험 3에서 0/3, 실험 4에서 2/3
5. **교사 스타일은 일관돼요.**
   - **전문가:** 실패한 매대를 같은 매대의 다른 상품으로 다시 연습시켜요. 성공하면 물건 수·매장 난도를 올려요. 그래서 연습 성공률이 가장 낮아요.
   - **Qwen:** 시험 상품을 그대로 쓰거나(금지 전), 다른 매대의 쉬운 상품으로 바꿔요(금지 후). "1개 2개" 같은 같은 문장 실수를 반복해요.
6. **시험의 어려운 요소를 연습에 넣은 교사가 없어요.** 실험 4에서 입구 공사를 넣은 연습은 0개, 실험 2에서 통로형+공사를 맞춘 연습도 없었어요.
