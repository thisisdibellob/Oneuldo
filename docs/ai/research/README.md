공식 자료나 논문이라는 사실만으로 모든 개인에게 적용할 수 있는 행동 규칙이 되지는 않는다. 연구 결과, 작성한 해석, 프로젝트 적용 제안을 구분한다. 출처를 수집했다는 사실과 원문 전체를 읽었다는 사실, 학습 이용 조건을 확인했다는 사실도 서로 다르다.

현재 학습의 최종 목적은 근거 있는 분석과 퀘스트를 통해 실제 수행 향상이 나타나는지 확인하는 것이다. 후속 작업에서는 행동 특징뿐 아니라 교육·중재 방법과 수행 변화 자료를 구분해 검토할 예정이다. [학습 목적과 다음 설계](../finetuning/learning-objective-and-next-design.ko.md), [실험 기록 안내](../finetuning/README.md)를 참조한다.
