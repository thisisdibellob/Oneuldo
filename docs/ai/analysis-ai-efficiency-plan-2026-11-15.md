## 5. 단계별 진행

각 단계는 "조사 → 수정 → 자동 테스트 → 9건(또는 12건) 측정 → 전후 표 보고" 순서예요. 보고 뒤에 다음 단계로 갈지 물어볼게요.

- **0단계: 기준선**
  - 9건 비교 도구가 지금 코드에서 도는지 확인 (`ColdNineComparisonLiveTest`가 지금 코드에는 없고 예전 실행 폴더에만 있어요)
  - 지금 코드로 9건을 두 번 돌려 기준값과 흔들리는 범위를 잡기
  - 퀘스트 경로로 12건(또는 가능한 건수)을 돌려 호출 수·시간·승인 비율·채점 점수 재기
- **1단계: 계산·사실 뽑기**
  - 서버가 이미 넘기는 사실 목록 조사
  - 빠진 것 추가: 어느 상품에서 헷갈렸나, 목록을 몇 번 다시 읽었나, 어디서 맴돌았나
- **2단계: 조각 관찰 조사**
  - 관찰 입력에서 무엇이 자리를 차지하는지 재기 (이동 좌표, 반복 행동 등)
  - 줄일 방법이 있으면 따로 제안하고, 승인받은 뒤 수정
- **3단계: 프롬프트 줄이기**
  - 금지 문장마다 "기계 검사가 잡나"를 표로 정리
  - 잡는 것만 빼고, 나머지는 유지
- **4단계: 카드 다시 만들기**
  - 카드에 게임 이름 칸 추가, 낱말 대응표를 코드 밖으로
  - 어려움 기준으로 고르기, 퀘스트 설계 단계에 넣기, 카드 번호 검사
  - 새 카드 문장은 출처를 사람이 확인한 뒤에만 넣기
- **5단계: 고치기·자기 검토**
  - 고치기 호출 합치기
  - 검토 단계를 뺐을 때와 넣었을 때 비교
- **6단계: 구조 정리**
  - 퀘스트 경로 통합, 작업 DB 저장
