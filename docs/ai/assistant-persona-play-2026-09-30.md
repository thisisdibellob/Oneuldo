# Assistant 직접 페르소나 플레이 — 2026-09-30

## 범위와 결과

사용자 요청에 따라 이 대화의 assistant가 앱 화면을 관찰하고 다음 행동을 선택했다. 학교 Qwen 모델이나 확률 기반 행동 정책은 행동 선택에 사용하지 않았다. 실제 앱 UI를 조작하여 품목 선택과 구매 확정까지 진행했다. 마지막 기록 수신 확인이 실패하여 **분석 및 추천 퀘스트는 실행되지 않았다**. 성공적인 종단 간 분석 시험이나 학습 효과 검증으로 집계하면 안 된다.

- 환경: 웹 앱 127.0.0.1:18082, 로컬 백엔드 18080, 격리 DB `oneuldo_pilot_20260929`.
- 가상 인물: 기존 페르소나 파일의 지민(32세), 한 번에 한 품목씩 확인하며 낯선 환경에서는 구체적인 안내를 필요로 하는 가상 성인.
- 실제 지적장애인의 행동을 재현했다고 보장하지 않는다. assistant의 독해·기억 능력이 결과에 섞인다.
- 테스트 시나리오: S01, pilot-round-2 배치.
- 화면에서 제시된 목표: 흰 우유 900mL 1개, 바나나 1송이.

## 화면에서 확인한 행동과 결과

1. 시작 안내를 읽고 매장에 들어갔다.
2. 입구 부근 장애물에 막히자 통로를 바꿔 진입했다.
3. 종업원에게 도움을 요청했으나 대화에는 “아니에요, 감사합니다.”만 있어 닫았다.
4. 간편 식품 진열대를 살펴봤다. 카레 등을 확인했지만 목표 외 품목을 담지 않았다.
5. 과일 진열대에서 바나나 1송이와 낱개 바나나 1개를 확인하고 1송이 상품을 한 번 담았다.
6. 옆 통로의 벽을 확인하고 반대편으로 이동해 냉장 진열대를 찾았다.
7. 흰 우유 900mL와 작은 흰 우유 200mL 중 900mL 상품을 한 번 담았다.
8. 장바구니에서 바나나와 흰 우유가 각각 한 개임을 확인했다.
9. 계산대로 이동했다. 최종 확인 화면에는 바나나 1송이 × 1, 흰 우유 900mL × 1, 합계 5,800원이 표시됐다.
10. 구매 확정을 눌렀으나 “기록 전송을 확인하지 못했어요. AI 판단을 보류해요.”가 표시됐다.

품목 일치는 화면 관찰에 따른 확인이다. 서버의 AI 수행 판정은 얻지 못했다. 이벤트 수, 오류율, 정확한 게임 수행 시간은 수신된 세션 기록이 없어 산출하지 않았다. 조이스틱 입력을 짧게 나눠 실행한 횟수를 인지적 의사결정 횟수로 해석하면 안 된다.

## 발견한 문제

### 인증/수집 실패 — 이번 분석을 막은 문제

- 사용한 기존 테스트 계정 파일의 토큰 만료 시각: 2026-09-30 01:08:03 UTC (한국 시각 10:08:03).
- 확인 시각: 2026-09-30 04:11:36 UTC (한국 시각 13:11:36).
- 해당 토큰으로 로컬 인증 API를 호출하면 HTTP 401.
- DB 최신 행동 이벤트는 전날 세션 `6c57e31c-a129-434f-840a-92c50fda85d7`의 종료 기록이었다. 이번 플레이의 새 수신 기록은 없었다.
- 따라서 학교 AI 모델의 판단 실패가 아니다. 분석 입력이 서버에 도착하기 전 단계의 실패다.
- 시작 전에 유효한 로그인 확인을 하지 못한 것은 이번 테스트 준비의 누락이다.

관련 구현 확인: `frontend/src/behavior/behaviorEventQueue.ts`는 401 시 대기열을 보존하지만 대기열 키를 access token 해시로 구분한다. 토큰을 갱신했을 때 기존 큐를 어떻게 이어받는지 별도 검증해야 한다. 이번에는 브라우저 저장소를 임의로 변경하거나 이벤트를 만들어 제출하지 않았다. UI의 완료 화면을 보존했으며 큐의 실제 저장 내용은 확인하지 않았다.

### 안내 표현

- 시작 안내: 바나나 **1송이**, 흰 우유 **900mL**.
- 플레이 중 상단 목록: 바나나 **1개**, 흰 우유 **1개**.

- 규격·구매 단위 비교가 목표인 과제에서 확인 화면마다 정보가 달라진다.

### 도움의 기능

종업원 대화에서 상품 위치를 묻는 선택지가 보이지 않았다. 도움 요청 행동을 했지만 실제 탐색 지원을 받지는 못했다. 이 기록을 단순히 “도움을 받아 수행했다”로 분석하면 관찰과 어긋난다.
