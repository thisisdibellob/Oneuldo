# 고정 입력 임베딩 CPU 배치 — 2026-09-24

**전체 모델 세 스텝 모두 성공. 같은 긴 예제의 최대 Torch 할당이 v3보다 2,425MiB 감소했고, 스텝 종료 직후 드라이버 여유는 187MiB에서 2,607MiB가 됐다.** 입력·정답·학습 대상을 줄이지 않았다.

## 변경

27B의 입력 임베딩은 `248320 × 5120 × 2 bytes` 크기의 FP16 고정 행렬이다. 이번 설정에서 이 행렬은 학습하지 않으며 출력 head와 weight를 공유하지 않는다. 약 **2.37GiB**를 CPU에 저장하고, 현재 입력 토큰에 해당하는 임베딩 행만 GPU로 전달한다.

- 전체 입력과 assistant 정답을 유지한다. 원본 가중치를 바꾸거나 임베딩을 재양자화하지 않는다.
- LoRA rank/모듈/학습률/정밀도/optimizer는 직전 v3와 동일하다. GPU 1에서 학습하는 LoRA 파라미터 수가 동일한지 결과에 기록한다.
- 학습 가능한 임베딩, max_norm에 의해 변하는 임베딩, 입력/출력 가중치 공유는 명시적으로 거절한다.
- 새 CPU 배치 모듈은 시험 프로세스 안에만 존재한다. 모델 캐시·운영 Ollama·설치 패키지를 수정하지 않는다.

## 완료한 작은 검사

GPU 1에서 FP32/FP16 두 조합 모두 기존 GPU 임베딩과 CPU 조회 후 전송한 값이 **정확히 같았고**, 그 결과를 사용하는 선형 계층의 gradient도 정확히 같았다. 반복 토큰과 padding 토큰을 포함했다. 학습 가능 임베딩을 실수로 전달하면 거절하는 검사도 통과했다.

[코드](frozen_embedding.py) · [검사 코드](test_frozen_embedding.py) · [실제 결과](embedding-check.json)

서버는 준비 당시 available RAM 약 59.6GiB였다. CPU RAM 사용과 CPU→GPU 전송이 추가되므로 큰 모델에서의 실제 시간과 최대 메모리는 별도 시험으로 확인해야 한다. 단순 행렬 크기를 실제 메모리 개선 측정치로 혼동하지 않는다.

## 전체 모델 시험

새 학습 후보 native-v3의 T56(2,206토큰·정답 496), T18(3,557토큰·정답 338), T18 반복을 사용한다. v3와 같은 자료·순서·seed·설정에서 입력 임베딩 배치만 바꾸어 비교한다. 결과는 `attempt-06-cpu-embedding-v3`에 기록하고 이전 파일을 덮어쓰지 않는다. 최대 20분 후 복구하며 본학습·어댑터 저장·배포는 하지 않는다.

로드·준비 포함 시간은 늘었지만 이번 세 스텝의 학습 시간 차이는 작았다. 실행 한 번씩의 비교이므로 평균 처리량이나 통계적으로 확정된 성능 수치가 아니다. CPU 임베딩 이동 시 실제 GPU 할당 감소량 2,425MiB도 별도 이벤트로 기록됐다.

세 스텝 모두 유한 loss·gradient와 표본 LoRA B 변경을 확인했다. 학습 가능 파라미터 수는 **58,363,904개로 동일**하다. 3,557토큰을 두 번 실행한 최대 메모리가 같았으며 스텝 정리 뒤 Torch 할당도 두 번 모두 15,343.16MiB였다.

작은 lookup/gradient 검사는 정확히 일치했지만 전체 모델의 학습 경로가 bitwise 동일하다는 뜻은 아니다. T56 첫 loss는 두 경로 모두 0.763427이고, 이후 T18의 loss·gradient에는 차이가 있었다. 이 수치 차이를 모델 품질의 향상·저하로 해석하지 않는다.

최초 효율 attention v2 시험과 비교하면 긴 예제의 최대 Torch 할당은 **22.63GiB → 20.14GiB**다. 단, v2와 v4는 선행 프로필 예제가 다르다. CPU 배치 단독 효과를 비교할 때는 같은 자료·순서의 v3/v4 값을 사용한다.

## 검증 범위와 다음 단계

- 메모리가 부족했던 길이의 forward/backward/optimizer 갱신과 반복은 확인됐다. 전체 60개 반복 학습, 실제 4,096토큰 입력, 더 긴 정답, batch 증가, 동시 추론은 실행하지 않았다.
- 어댑터는 저장하지 않았으며 운영 추론은 기존 Q4 모델을 계속 사용한다. 실제 분석 품질 변화는 본학습 뒤 같은 추론 조건으로 비교해야 한다.
- 학습 후보는 60개, 동결 개발 평가는 25개다. 합성 자료의 구조 검증과 전문가/실사용 검증은 구분한다.
- 다음 본학습의 시작 설정은 **rank 8, batch 1, NF4/FP16, 효율 attention, 고정 CPU 임베딩, chunked CE 32토큰, AdamW foreach=False**다. 본학습을 시작할 때에도 운영 추론을 동시에 GPU 1에서 실행하지 않는다.
