# 본학습 전 자료 검토 — 2026-09-24

**60개 학습 후보의 관찰·해석·한계·계획과 입력 사실을 다시 검토했다. 구조상 사용할 수 있지만 그대로 본학습하기에는 계획 분포가 지나치게 한쪽으로 치우쳐 있다.** 이번에는 동결한 60/25 파일을 수정하지 않았다. 평가 응답을 본 뒤 평가 파일을 고쳐 성능을 올린 것처럼 비교하지 않기 위해서다.

이 검토는 개발용 검토다. 합성 예제가 실제 지적장애인의 행동 분포나 교육 효과를 대표하지 않으며 전문가 검토와 자료 이용 조건 확인은 여전히 별개다. GPU 메모리 시험은 이 문제를 해결했다는 뜻이 아니다.

## 확인한 점

- 60개는 세션 40개·프로필 20개. 새 사건·허용 참조와 목표 답변의 기본 대응을 검토했다. 이전에 확인한 운영 생성기/파서 왕복 85개 결과도 유지했다.
- 제출 결과와 동기·기억·이해를 구분하고, 미수집 도움을 독립 수행으로 단정하지 않는 방향은 유지되어 있다.
- T26/T27/T53 등 보고·외부 지원·기술 문제는 **합성 프로필 입력에 명시된 정보**를 사용한다. 실제 앱 수집기가 이미 이 내용을 수집한다는 뜻은 아니다.
- T21/T22/T24/T51의 같은 세션 정정, T29/T56의 근거 없는 과거 해석, T54의 달성 불가능한 예산 조건 등은 현재 입력에서 검토할 수 있다.
- 수치·라벨의 구조 검사와 판단 기준의 타당성은 다르다. 예를 들어 T04/T41의 충돌하는 과제/금액을 UNDETERMINED로 두는 것은 작성한 정책 선택이며 장애 특성에 관한 의학적 사실이 아니다.

## 본학습 전에 보완할 점

| 항목 | 60개 분포 | 영향 |
|---|---|---|
| 다음 품목 수 | 2개 59건, 3개 0건, 4개 1건 | 입력과 무관하게 2개를 제안하는 학습 위험 |
| 난이도 | 1단계 5건, 2단계 54건, 3단계 1건 | 중간 난이도로 편향될 위험 |
| 수량 복잡도 | LOW 58건, MEDIUM 2건 | 다양한 수량 조건의 근거 연결 부족 |
| 예산 압박 | LOW 58건, MEDIUM 2건 | 예산 조건에 따른 계획 변화 근거 부족 |
| 문자 지원 | SIMPLIFIED 54건, STANDARD 6건 | 보고된 선호·지원 조건보다 기본 답변을 복사할 위험 |

분포가 반드시 균등해야 하는 것은 아니다. 그러나 실제 운영 분포를 모르는 상태에서 이처럼 극단적으로 치우친 예제만 학습시키면 개인화 성능 개선을 기대하기 어렵다. 분포 편향 자체가 학습 후 저하를 실증한 결과는 아니다.

보완은 **60개를 유지하며 반복적인 후보 일부를 교체**하는 방식이 적절하다. 품목 3개·4개, 기존 지원 유지, 명시적 선호에 따른 변경, 난이도를 유지하는 이유가 서로 다른 사례를 넣어야 한다. 숫자를 맞추기 위해 근거 없이 난이도를 올리는 정답을 만들면 안 된다.

## 문장 수준의 수정 후보

- **T09:** sessionAssessments의 성공 설명이 배경 상태 180초 해석에 집중한다. 성공 판정 이유인 실제 제출 수량과 금액을 그 설명에도 넣으면 명료해진다.
- **T20/T40:** 출력에 데이터 내 지시문이나 입력 제외 구현 과정이 드러난다. 분석 결과의 사용자용 문장에는 직접 관찰과 한계를 중심으로 쓰고, 개발 진단은 별도 메타데이터로 두는 편이 낫다.
- **T01~T19 등의 반복 계획:** 서로 다른 관찰에도 같은 두 종류 반복 관찰 문장이 매우 많이 쓰인다. 단순 구조 훈련에는 도움이 될 수 있지만 맞춤 지원의 학습 근거는 부족하다.
- **평가 E09 목표 답변:** 서로 떨어진 두 시점에서 같은 좌표라는 사실을 ‘정지’라고 압축했다. 연속 정지라고 읽힐 여지가 있어 ‘두 시점의 좌표가 같음’으로 표현을 좁히는 수정 후보로 남긴다. 이미 수집한 기준 응답의 입력/목표는 변경하지 않았다.

## 새 기준 응답과 연결되는 학습 우선순위

1. **AI 해석 정정:** E22처럼 현재 AI의 잘못된 이해도 해석을 사용자 보고와 대조하여 보류하는 사례를 보강한다.
2. **과거와 현재 구분:** E09/E23처럼 새 성공·다른 환경의 보고가 이전 사건을 뒤집지 않도록 한다.
3. **출력 일관성:** 요약과 세션 판정, finding 필드 위치, 계획 참조, 품목 종류와 총 수량을 함께 검토한다.
4. **미관찰의 처리:** 스냅샷에서 인지·읽기·계산·선택 과정을 확정하지 않고 사실과 가설의 문장을 분리한다.

여기서 작성한 목록은 검토 기록이다. 사람의 성공/실패나 능력을 판정하는 운영 룰은 추가하지 않았다. 다음 데이터 개정은 새 버전으로 내고, 25개 개발 평가와 별도로 새로운 독립 평가를 준비해야 일반화를 확인할 수 있다.
