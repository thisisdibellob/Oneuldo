# 학습 후보 60개 내용 검토 결과

검토일: 2026-09-24 · 검토자: Codex · 대상: T01~T60 · 평가 E01~E25는 변경하지 않음

## 결론

**60개를 모두 대조했고 14개를 수정했다. 내용 관점의 잠정 후보는 59개이며 T47은 판정 라벨 의미를 정하기 전 학습에서 보류하는 것을 권한다. 바로 운영 모델에 학습할 준비가 끝났다는 뜻은 아니다.**

이 자료는 실제 지적장애인의 행동 데이터가 아니라 작성한 합성 로그다. 현재 강점은 근거 없는 추론·자료 유실·잘못된 프로필 누적을 줄이는 분석 예제라는 점이다. 장애 특성을 대표하거나 맞춤 교육의 효과를 입증하는 정답 모음으로 사용할 수 없다. 이번 검토 역시 같은 작성 모델의 자체 점검이며 독립 전문가 검증은 아니다.

- 입력 사건·과제 조건·목표 답변·rubric을 60개 모두 읽고 대조했다.
- 기존 문헌 카드 10종의 읽은 범위와 적용 한계를 대조했다. 논문 10편의 원문 전체를 이번에 새로 읽은 작업은 아니다.
- 구조 검사: 85개, 3,092개 검사 항목 PASS, 오류 0개. 임상 타당성이나 모델 성능을 검증한 수치가 아니다.
- 학습 60개 = 세션 분석 40개 + 프로필 갱신 20개. 평가 25개는 파일 해시가 검토 전과 같다.
- 실제 모델 추론, LoRA 학습, 서버 설정·운영 코드 변경은 수행하지 않았다. 행동 판단 규칙도 추가하지 않았다.

## 아직 남은 문제와 처리 순서

### 1. 추천 답변 분포가 한쪽으로 치우침

| 항목 | 수정 후 분포 |
|---|---|
| 다음 품목 수 | 2종 59개 / 3종 0개 / 4종 1개 |
| 문자 지원 | SIMPLIFIED 58개 / STANDARD 2개 / REDUCED 0개 |
| 난이도 | 1: 1개 / 2: 58개 / 3: 1개 |
| 수량 복잡도 | LOW 58개 / MEDIUM 2개 / HIGH 0개 |
| 예산 압박 | LOW 58개 / MEDIUM 2개 / HIGH 0개 |
| 학습 입력 사건 수 | 1개: 16사례 / 2개: 22사례 / 3개: 20사례 / 4개: 2사례 |

77개 세션 맥락 중 70개가 ‘사과 2개·생수 1개’ 목표다. 분석 40사례의 세션 판정 42개는 성공 24, 실패 10, 보류 8이다. 모든 사례가 판단 보류로 편향된 것은 아니지만, 지원 계획은 거의 같은 값을 반복한다.

**권장:** 총 60개는 유지하되 단순 2종 사례 일부를 충분한 기록이 있는 3종·4종, 일반 문자 유지, 지원을 당사자가 선택하는 사례로 교체한다. 비율을 맞추기 위해 근거 없이 난이도를 높여 정답을 만들면 안 된다. 반대 결과가 나오려면 그에 맞는 관찰·선호·과제 조건을 함께 작성해야 한다. 긴 로그·무관 사건·다중 세션 사례도 포함한다. 이 재구성은 이번 내용 교정 범위를 넘어 아직 하지 않았다.

### 2. 운영 입력 형식과 다름

현재 예제는 정규화한 사건과 펼친 JSON을 사용한다. 운영 분석의 압축 출력·E/R 참조 형식과 같지 않다. 특히 프로필 예제 20개에는 원본 사건을 함께 제공하지만 현재 `AiUserProfilePromptFactory.userPrompt`는 이전 프로필과 현재 분석을 넣는다. 실제 서비스에서 받지 못하는 정보를 학습 예제에만 주면 근거 정정 능력을 과대평가할 수 있다.

**권장:** 세션 분석 40개부터 운영 프롬프트와 동일한 형식으로 변환하고, 프로필 20개는 실제 제공 가능한 정보에 맞춘 뒤 별도 검증한다. 이번에 형식 변환을 완료한 것은 아니다.

### 3. T47의 FAILURE 라벨은 보류

목표에 ‘추가 촉구 없이’가 명시됐지만 진행자가 함께 목록을 읽었다. 품목·수량·예산은 맞다. 전체 과제 조건 달성 여부를 표시하는 라벨이면 FAILURE라고 설명할 수 있지만, 독립 수행 능력을 평가하는 라벨이면 지원이 제공돼 측정할 수 없다는 UNDETERMINED가 더 적합할 수 있다.

현재 단일 라벨의 제품 의미를 확인하기 전에는 이 목표 답변을 확정 정답으로 학습시키지 않는 것을 권한다. 도움 자체를 실패로 학습하는 부작용을 피하기 위한 사례별 보류다. T04·T43·T54에서도 실패가 과제 결과인지 개인 능력인지 구분해야 한다.

### 4. 출처 확인과 이용 조건 확인은 다름

10개 카드 중 3개(M01·P27·P40)는 이번에 라이선스 표기를 확인했다. 나머지 7개는 학습 재사용 조건 확인이 남았다. 공개로 읽을 수 있다는 사실만으로 어떤 방식의 학습·배포든 허용된다고 표시하지 않았다. 반대로 조건 미확인을 곧 사용 금지라는 결론으로 바꾸지도 않았다.

### 5. 전문가가 확인해야 할 부분

지원 방식의 적절성, 난이도 1~3과 실제 활동 부담의 대응, 필요한 지원을 유지·줄일 조건은 전문가 검토가 남아 있다. 초안의 숫자 설정은 작성자의 제안이며 검증된 장애별 교육 처방이 아니다. 자체 점검 결과를 `domain_expert_reviewed` 또는 `training_approved=true`로 바꾸지 않았다.
