# 테스트 기록 보관

사용자 요청에 따라 테스트 기록을 학교 서버의 기존 외장하드 `oneuldo` 디렉토리에 보관한다. 설정 기준일은 2026-10-10이다.

| 항목 | 확인한 값 |
|---|---|
| 서버 | `duream@117.16.44.110:22022` |
| 디스크 | `/dev/sda1` · NTFS · UUID `B4E0414DE04116D0` |
| 마운트 | `/mnt/wd_hdd` |
| 기존 보관 루트 | `/mnt/wd_hdd/oneuldo` |
| 새 테스트 기록 루트 | `/mnt/wd_hdd/oneuldo/tests` |
| 연결 | 기존 공유 SSH 소켓 `~/.ssh/oneuldo-school.sock` |

## 저장 순서

1. 격리된 앱과 DB에서 테스트를 실행하며 로컬 `output/<실행-폴더>`에 실제 기록을 남긴다. 플레이 로그, 분석 원문, 추천 퀘스트 원문, 결과·시간·문제점 요약, 화면 캡처를 모은다.
2. 테스트 종료 뒤 공통 보관 도구를 실행한다. 자동 실험 스크립트는 기록을 다 저장한 뒤 이 명령을 마지막 단계로 호출한다. 어시스턴트가 직접 수행한 테스트도 동일하게 호출한다.

   ```bash
   python3 scripts/archive-test-records.py output/<실행-폴더> --status complete
   ```

3. 보관 도구는 기록 사본과 파일별 SHA-256 목록을 만들고, 기존 공유 SSH로 외장하드에 전송한다. 디스크 식별자와 마운트를 확인한 뒤 새 스냅샷 디렉토리에 저장하고 서버에서 다시 해시를 계산한다.
4. 도구가 출력한 원격 저장 경로와 로컬 보관 확인서를 결과 보고에 남긴다. `complete`는 기록 보관 단계가 완료된 테스트 묶음이라는 뜻이며 게임 성공, 실험 목표 달성 또는 학습 효과를 뜻하지 않는다.

이 디스크의 NTFS는 덮어쓰기 금지 플래그를 붙인 폴더 rename을 지원하지 않는 것으로 실제 확인했다(`EINVAL`). 도구는 새 목적지 폴더를 독점 생성하고 파일을 덮어쓰기 없이 복사하는 방식을 지원한다. 원본 해시 검증 후 `manifest.json`을 마지막에 만들고 다시 읽어 검사한 뒤에만 보관 완료를 보고한다. 기존 스냅샷은 내용이 완전히 일치할 때 재사용하며 다른 내용이나 빈 폴더는 덮어쓰지 않는다.

중간 진행 기록은 `--status progress`, 중단 기록은 `--status interrupted`로 보관한다. 같은 실행 폴더를 다시 보관해도 앞선 기록을 덮어쓰지 않는다.

## 보관 범위

JSON·JSONL·로그·텍스트·Markdown·HTML·CSV·TSV·화면 이미지·PDF·PPTX 등 테스트 기록을 보관한다. 선택한 파일의 바이트를 바꾸지 않으며 원본 로컬 파일은 유지한다. 원본 폴더 안의 symlink는 따라가지 않는다.

개인 설정·인증 파일·비밀번호·토큰·pairing URL·DB 덤프·학습 모델·JAR·소스 실행 스크립트는 전송하지 않는다. 제외된 파일과 사유는 manifest에 남기며, 비밀 값 자체는 보고서나 콘솔에 출력하지 않는다. 이 보관은 운영 DB 전체의 백업이나 서비스 저널의 저장 위치 변경이 아니다.

## 연결 또는 디스크가 없는 경우

공유 SSH 연결이 없거나 지정 디스크가 마운트되지 않았으면 원격 저장은 실패로 처리한다. 로컬 자료를 보존하고 미전송 상태를 남긴다. 일반 SSD 폴더나 다른 서버를 대신 목적지로 사용하지 않는다. 연결을 복구한 뒤 다시 보관하고, 외장하드 읽기 검증에 성공하기 전에는 저장 완료라고 보고하지 않는다.

복사 중 장애로 미완료 원격 폴더가 남으면 확인서에 `pending_remote_path`와 `operator_action_required`를 남긴다. 같은 목적지의 기존 파일을 고쳐 재시도하지 않는다. 미완료 폴더를 확인하고 필요하면 `--run-id <기존이름>-retry1`로 별도 보관한 뒤 검증한다. 앞선 원본·완료 스냅샷·로컬 패키지는 유지한다.

설정의 단일 원본은 [test-records-archive.json](../../scripts/test-records-archive.json)이다. 기존 2026-10-07의 자료 이전 스크립트는 파일 이동과 symlink 교체를 수행하므로 새 테스트 기록 보관을 위해 재실행하지 않는다.
