# AI 행동 선택과 경험 전달 개선 — 2026-09-30

## 목적과 결론

확률 정책 대신 AI가 행동을 선택하도록 기본 경로를 바꿨다. 반복 과제에는 실행이 확인된 경험을 전달한다. 자동 성공률 증가, 능력 점수 상승, 강제 실수 또는 확률 기반 망각으로 학습 효과를 만들지 않는다.

이는 **가상 행위자의 경험 참고 기능**이다. 실제 지적장애인의 학습·기억·전이를 재현했다고 검증된 모델도, 추천 퀘스트의 교육 효과를 입증한 결과도 아니다. 이번 작업은 파인튜닝이 아니며 모델 가중치는 변경하지 않았다.

## 구현 변경

1. `generateTrace`의 기본값을 `llm`으로 바꿨다. 모델 미설정·호출 실패는 오류로 종료한다. 기존 확률 정책은 `mode: "stochastic"`을 명시하는 회귀 시험에서만 사용한다.
2. 현재 화면에서 가능한 조작을 식별자로 제시한다. AI가 식별자 하나를 선택하며 프로그램은 이를 UI 행동으로 변환한다. 상품의 정답 여부를 기준으로 후보를 정렬하거나 정답을 선택하지 않는다. 잘못된 JSON/선택 형식은 같은 관찰 상태에서 최대 두 번 교정 요청한다. 실패하면 중단하며 대신 행동하지 않는다.
3. AI 경로에서 `AttentionPolicy`의 확률 선택·능력/스트레스 수치·자동 기억 소실 계산을 제거했다. 기존의 관심·선호·강점·지원 필요 등 구조화된 개인 설정은 유지했다. 논문 전문을 매 행동에 반복 전송하지 않는다.
4. 현재 회차에는 읽은 목록, 표시 안내, 선택한 이동/매대, 살펴본 상품 페이지, 장바구니와 조작 결과를 기록한다. 초기 서버 시험에서 행동 이름만 남아 관찰 내용이 누락되는 문제를 발견해 이동 대상과 본 상품도 추가했다.
5. 다음 회차에는 앱 재생 완료·trace 일치·DB 로그 수신이 확인된 경험만 생성하는 `confirmedExperience` 경로를 사용한다. 실행 실패나 계정 불일치는 거부한다. 분석 AI의 결론이나 숨겨진 평가 정답은 전달하지 않는다.
6. AI trace에는 `generation.actorPolicyVersion: "episodic-choice-v1"`을 기록한다. 빠른 재생 설정은 실행 시간 조정이며 사람의 반응 속도나 학습 효과를 뜻하지 않는다.

## 경험이 다음 선택에 반영되는 방식

표시 안내 → AI가 조작 선택 → 관찰된 화면 내용과 결과를 경험으로 저장 → 다음 선택에서 참고한다. 실제 앱 재생이 끝난 후 확인된 경험을 다음 과제에 전달한다. 과거 목록은 과거 경험으로 구분하며 새 과제 정답으로 쓰지 않도록 명시한다.

경험은 관찰 기록이다. 행위자가 긴 전략 보고서를 작성하거나 교육자가 성공 전략을 정답으로 주입하지 않는다. AI가 경험을 실제로 활용했는지는 행동 비교로 따로 확인해야 한다. 안내를 표시했다는 사실은 이해·기억·습득의 증거가 아니다.

최근 경험 6개, 이전 실행 경험 최대 24개는 컨텍스트 예산이다. 인간의 기억 용량에서 도출한 수치가 아니다. 고정된 최근 기록만 제공하면 반복 행동이 생길 수 있으며, 현재는 임상적으로 보정된 기억 모형이 없다.

## 실행 구조와 확인 범위

현재 AI는 게임 어댑터의 제한된 관찰로 **행동 계획**을 순서대로 만든다. 이후 앱이 계획을 실제 입력으로 재생한다. AI가 매번 실시간 앱 스크린샷을 보고 반응하는 구조는 아니다. 계획 중 관찰은 `current-planning-observation`, 실제 실행 후 확인 경험은 `confirmed-app-replay`로 구분한다.

실행 후의 안내·상품 페이지는 완료된 입력과 동일 snapshot에서 재구성한다. 시선이나 이해를 측정한 것이 아니다. 실제 실행과 계획이 달라지면 완료된 경험으로 넘기지 않는다. 도움 화면을 열었다는 기록은 남기지만, 현재 도움 본문은 기록되지 않는 한계가 있다.

## 시험

- 초기 전체 관련 테스트: 50건 통과. 기본 AI 경로, 형식 교정, 앱 재생 증거, 회귀 재생 및 타이밍 등을 검사했다.
- 이후 관찰 내용 보존과 재방문 AI 요청에 경험이 실제 포함되는 검사를 추가했다. 최종 TypeScript 검사와 관련 테스트 51건이 통과했다. `git diff --check`도 통과했다.
- 첫 실제 서버 시험: 60회 호출, 257.475초. HTTP/출력 형식 오류 없이 행동을 선택했다. 목록 읽기·탐색·매대 열기 반복으로 행동 상한에 도달했다. 완성 trace와 실제 앱 플레이는 없으며 능력 실패로 집계하지 않는다.
- 첫 시험 이후 이동 대상·관찰 상품을 경험에 추가하고 수량 선택의 임의 3개 상한을 제거했다. 사용량을 제한하기 위해 최종 서버 시험은 30행동으로 제한했다.

최종 보완판 서버 시험은 30회/128.407초, 형식 오류 0건이었다. 30행동 상한까지 장보기를 완료하지 못했다. 상한이 서로 다르므로 첫 시험보다 빨라졌거나 행동이 개선됐다고 비교할 수 없다. 이번 턴의 완료된 앱 플레이·분석·추천 반복은 **0회**다.

원본 요청/응답과 테스트 로그는 로컬 `output/actor-learning-20260930/`에 보존했다. 인증 헤더와 키는 저장하지 않았다. 이 디렉터리는 Git 추적 대상이 아니다.

## 남은 검증

1. AI의 목록 재확인·탐색 반복 원인을 줄이고, 조작 가능한 완성 계획과 실제 앱 재생을 확보해야 한다. 반복을 장애 특성으로 해석하면 안 된다.
2. 동일 가상 인물의 경험 전달 유무, 안내 유무, 새 상품·새 배치 조건을 비교해야 한다. 개발자가 결과에 맞춰 인물 특성을 바꾸면 효과 측정이 왜곡된다.
3. 실제 참여자 자료와 전문가 검토로 관찰·기억·도움 활용 방식이 적절한지 보정해야 한다. 가상 사용자에서 개선돼도 실제 참여자의 교육 효과는 별도 검증이 필요하다.

운영 AI 모델, GPU 설정, 분석 프롬프트 및 서버 서비스 배포는 이번 변경 대상이 아니다.
