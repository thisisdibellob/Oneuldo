# 학교 AI 서버 TCP 443 간헐적 연결 실패 — 네트워크 담당자 전달용

작성: 2026-09-21. 이 문서는 전달용으로 준비했으며 담당자에게 발송하지 않았다. 인증키·요청 본문은 포함하지 않는다.

## 요청 사항

학교 서버 `117.16.44.110:443`의 일부 연결 요청이 클라이언트에서는 송신되지만 서버 NIC 캡처에는 나타나지 않는다. 아래 실패·성공 사례의 시각과 TCP 초기 시퀀스를 학교 경계 방화벽 및 라우터 기록과 대조해 주기 바란다. 학교 장비가 원인이라고 확정한 상태는 아니다.

- 목적지: `117.16.44.110:443`, 도메인 `oneuldo.duckdns.org`.
- 클라이언트 공인 IPv4: `116.32.235.161` (시험 중 직접 확인).
- 서버: `117.16.44.110/23`, 기본 게이트웨이 `117.16.45.254`, NIC `enp5s0`.
- 서버 캡처: **2026-09-21 11:17:17~11:18:47 KST (UTC+9)**, 인터페이스 `any`.
- 클라이언트 시험: **11:17:43~11:18:35 KST**. 프록시 우회·IPv4 고정, DNS 정상, HTTPS 인증서 검증 유지.
- 시험 요청: 키나 추론이 없는 `/healthz`와 무인증 `/api/tags` 총 10회. 무인증 401은 정상 도달 결과다.

## 동시 관측 결과

| 결과 | 연결 수 | 클라이언트 SYN | 서버 SYN | 서버 응답 |
|---|---:|---|---|---|
| TCP 연결 시간 초과 | 7 | 각 초기 시퀀스 6회 송신 | 일치 시퀀스 0회 | 일치 SYN-ACK 없음 |
| HTTP 정상 도달 | 3 | 각각 6·4·2회 송신 | 각각 1회 수신 | SYN-ACK 송신 및 클라이언트 수신 확인 |

성공 연결도 첫 SYN이 아니라 재전송 후 연결된 사례다. 일부 클라이언트 소스 포트는 NAT에서 바뀌므로 포트 번호만으로 대조하지 않았다. TCP 초기 시퀀스로 일치 여부를 확인했다.

서버는 위 SYN 수신 후 약 44~49마이크로초에 SYN-ACK를 송신했다. 성공 연결 뒤의 RST는 HTTP 결과를 받은 클라이언트에서 나온 종료 패킷이며, 실패한 연결의 서버 거절로 계산하지 않았다.

## 서버 확인 상태

- Caddy TCP 443 LISTEN, Spring 게이트웨이 loopback 8081, Ollama loopback 11434 정상.
- UFW TCP 443 허용 유지. 시험 전후 해당 ACCEPT 카운터 **329→332**, 성공 연결 3건과 일치.
- conntrack **12 / 262,144**, 443 리스너 Recv-Q 0.
- 서버 패킷 캡처 9개, 클라이언트 캡처 60개. 양쪽 `0 packets dropped by kernel`.
- 서버 캡처 필터: `host 116.32.235.161 and tcp port 443 and (tcp[tcpflags] & (tcp-syn|tcp-rst) != 0)`.
- 서버 내부 HTTPS health 정상. 별도 SSH 진단 경로에서 동일 게이트웨이·모델의 208개 사건 분석도 214.989초에 성공했다. 이 성공은 공개 경로의 안정성을 보장하지 않는다.
- 서버 방화벽·서비스·GPU 설정 변경 없이 조사했다.

## 다음 대조 요청

1. 실패 시퀀스가 학교 외부 경계에 도착하는지 확인한다. 경계에도 없다면 통신사·클라이언트 방향으로 범위를 넓힌다.
2. 경계에는 있는데 서버에는 없으면 학교 내부 전달 경로, ACL/방화벽, 연결 상태·SYN 정책, 목적지 IP의 ARP/MAC 매핑과 중복 IP 여부를 대조한다. 특정 가설을 원인으로 확정하지 않는다.
3. 성공 시퀀스와 실패 시퀀스의 경로·정책 적용 차이를 확인한다. 별도 휴대폰 데이터망 비교로 출발 네트워크 영향을 분리한다.

캡처는 TCP SYN/RST 헤더 텍스트만 보관한다. HTTP 본문·API 키를 수집하거나 제공할 필요는 없다. 원시 결과는 관리자 로컬 `output/server-connectivity-2026-09-21/`의 `synchronized.jsonl`, `synchronized-mac-headers.txt`, `server-capture.txt`, `packet-correlation.json`에 있다.
