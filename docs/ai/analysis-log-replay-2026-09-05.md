## 변경

- 구간당 최대 입력은 시스템 프롬프트를 포함한 60,000자로 유지했다.
- 최대 구간 수를 16에서 64로 늘렸다. `AI_ANALYSIS_MAX_CHUNKS`로 변경할 수 있다.
- 원본 행동, 빈 필드, 공통 문맥 및 프롬프트 내용은 줄이거나 요약하지 않았다.
- `POST /api/behavior-analyses/datasets/{datasetId}`로 기존 스냅샷 재분석을 추가했다. 로그인과 스냅샷 소유권을 검사하며, 새 분석 결과를 별도로 저장한다.
- 분할 분석의 공급자 HTTP 429를 `AI_RATE_LIMITED`로 구분해 저장한다. 429에서는 재시도하지 않는다.

64는 구간 수 제한이다. 통합 요청과 형식 오류 재시도가 추가될 수 있으므로 총 API 호출 64회라는 의미는 아니다. 서버는 이 제한으로 사용자의 성공·실패를 판정하지 않는다.
