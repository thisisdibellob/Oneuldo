# 프로파일 기반 LLM 입력 데이터

## 1. 목적

이 문서는 시뮬레이션 생성 시 LLM에 전달하는 최종 입력 데이터인 `LlmSimulationGenerationInput`의 필드만 설명한다.

프로파일 생성 및 계산 규칙은 `3.행동로그_근거자료_프로파일_설계.md`를 따른다.

---

## 2. 최상위 구조

```text
LlmSimulationGenerationInput
├── schemaVersion
├── quest
├── content
├── preferences
├── profile
└── generationPlan
```

| 필드 | 설명 |
|---|---|
| `schemaVersion` | LLM 입력 스키마 버전 |
| `quest` | 생성 대상 퀘스트 정보 |
| `content` | 시뮬레이션 종류와 사용 가능한 콘텐츠 |
| `preferences` | 사용자가 설정한 퀘스트 선호 |
| `profile` | 현재 퀘스트와 관련된 행동 프로파일 |
| `generationPlan` | 백엔드가 결정한 시뮬레이션 생성 조건 |

현재 입력 스키마 버전은 `simulation-generation-input-v1`이다.

---

## 3. `quest`

| 필드 | 타입 | 설명 |
|---|---|---|
| `questCode` | `String` | 퀘스트 코드 |
| `subcategoryCode` | `String` | 퀘스트 세부 카테고리 코드 |
| `title` | `String` | 퀘스트 제목 |
| `goal` | `String` | 퀘스트 학습 목표 |
| `difficulty` | `QuestDifficulty` | 퀘스트 난이도 |
| `targetSkillCodes` | `Set<String>` | 이번 퀘스트가 관찰하거나 훈련할 기술 코드 |

---

## 4. `content`

| 필드 | 타입 | 설명 |
|---|---|---|
| `simulationType` | `SimulationType` | 시뮬레이션 종류 |
| `placeCode` | `String` | 장소 코드 |
| `placeName` | `String` | 장소 이름 |
| `referencePayload` | `SimulationPayload` | 생성 시 참고할 기존 시뮬레이션 payload |
| `allowedAssetCodes` | `Set<String>` | 사용할 수 있는 에셋·참여자·노선 등의 코드 |

`simulationType`은 `SHOPPING`, `TRANSIT`, `COOKING`, `CONVERSATION` 중 하나다.

`referencePayload`는 시뮬레이션 종류에 맞는 `ShoppingSimulationPayload`, `TransitSimulationPayload`, `CookingSimulationPayload`, `ConversationSimulationPayload` 중 하나다.

---

## 5. `preferences`

| 필드 | 타입 | 설명 |
|---|---|---|
| `preferredDifficulty` | `QuestDifficulty` | 사용자가 설정한 선호 난이도 |
| `preferredSupportLevel` | `SupportLevel` | 사용자가 설정한 기본 지원 수준 |
| `preferredSessionMinutes` | `int` | 선호 수행 시간 |
| `preferredSubcategoryCodes` | `Set<String>` | 선호 퀘스트 세부 카테고리 코드 |

---

## 6. `profile`

### 6.1 프로파일 정보

| 필드 | 타입 | 설명 |
|---|---|---|
| `available` | `boolean` | 행동 프로파일 존재 여부 |
| `stale` | `boolean` | 행동 근거가 오래됐는지 여부 |
| `profileVersion` | `String` | 사용한 프로파일 버전 |
| `generatedAt` | `Instant` | 프로파일 생성 시각 |
| `evidenceFrom` | `Instant` | 행동 근거 기간 시작 |
| `evidenceTo` | `Instant` | 행동 근거 기간 종료 |
| `selectedSkills` | `List<SkillSignal>` | 현재 퀘스트의 대상 기술 정보 |
| `support` | `SupportSignal` | 지원 사용 관찰값 |
| `safety` | `SafetySignal` | 안전 관련 관찰값 |
| `dataQuality` | `DataQualitySignal` | 프로파일 데이터 품질 |

### 6.2 `selectedSkills`

| 필드 | 타입 | 설명 |
|---|---|---|
| `skillCode` | `String` | 기술 코드 |
| `independentSuccessRate` | `Double` | 독립 수행 성공률 |
| `supportedSuccessRate` | `Double` | 지원 수행 성공률 |
| `independentEvidenceCount` | `int` | 독립 수행 평가 근거 수 |
| `supportedEvidenceCount` | `int` | 지원 수행 평가 근거 수 |
| `confidence` | `ConfidenceLevel` | 근거 신뢰도 |
| `strengths` | `List<BehaviorSignal>` | 반복 관찰된 강점 |
| `difficulties` | `List<BehaviorSignal>` | 반복 관찰된 어려움 |
| `evidenceGaps` | `List<EvidenceGapType>` | 추가 근거가 필요한 이유 |

성공률을 계산할 수 없으면 `0`이 아니라 `null`이 들어간다.

### 6.3 `BehaviorSignal`

| 필드 | 타입 | 설명 |
|---|---|---|
| `eventCode` | `String` | 관찰된 행동 이벤트 코드 |
| `outcome` | `ObservedOutcome` | 행동 결과 |
| `independenceLevel` | `IndependenceLevel` | 독립·지원 수준 |
| `errorType` | `ErrorType` | 오류 유형 |
| `observationCount` | `int` | 반복 관찰 횟수 |

### 6.4 `support`

| 필드 | 타입 | 설명 |
|---|---|---|
| `averagePromptLevel` | `Double` | 평균 프롬프트 수준 |
| `totalSupportCount` | `Integer` | 관찰된 지원 횟수 |
| `medianHelpRequestLatencyMs` | `Long` | 도움 요청까지 걸린 시간의 중앙값 |
| `supportedSessionCount` | `int` | 지원 행동이 관찰된 완료 세션 수 |

### 6.5 `safety`

| 필드 | 타입 | 설명 |
|---|---|---|
| `overallStatus` | `SafetyStatus` | 전체 안전 상태 |
| `redEventCount` | `int` | RED 안전 이벤트 수 |
| `yellowEventCount` | `int` | YELLOW 안전 이벤트 수 |
| `nearMissCount` | `int` | 위험에 가까웠던 행동 수 |
| `professionalReviewRecommended` | `boolean` | 별도 검토 권장 여부 |

### 6.6 `dataQuality`

| 필드 | 타입 | 설명 |
|---|---|---|
| `excludedEventRate` | `Double` | 프로파일 계산에서 제외된 이벤트 비율 |
| `openSessionCount` | `int` | 아직 완료되지 않은 세션 수 |
| `gappedSessionCount` | `int` | 이벤트 순번이 누락된 세션 수 |
| `skillsNeedingMoreAssessment` | `Set<String>` | 추가 평가가 필요한 대상 기술 코드 |

---

## 7. `generationPlan`

| 필드 | 타입 | 설명 |
|---|---|---|
| `personalizationMode` | `PersonalizationMode` | 행동 프로파일 적용 상태 |
| `difficulty` | `QuestDifficulty` | 적용할 퀘스트 난이도 |
| `targetSkillCodes` | `Set<String>` | 생성 대상 기술 코드 |
| `supportLevel` | `SupportLevel` | 적용할 지원 수준 |
| `instructionGranularity` | `InstructionGranularity` | 지시를 나누는 수준 |
| `maxTaskSteps` | `int` | 최대 과제 단계 수 |
| `maxChoicesPerStep` | `int` | 단계별 최대 선택지 수 |
| `hintLevel` | `int` | 기본 힌트 수준 |
| `timePressureAllowed` | `boolean` | 시간 압박 요소 허용 여부 |
| `hazardousDistractorsAllowed` | `boolean` | 위험한 오답 선택지 허용 여부 |
| `mandatorySafetyGuidance` | `boolean` | 안전 안내 필수 여부 |
| `assessmentPriority` | `boolean` | 추가 평가 목적 우선 여부 |
| `decisionReasons` | `List<String>` | 생성 조건 결정 사유 코드 |

`personalizationMode`은 `NO_PROFILE`, `STALE_PROFILE`, `INSUFFICIENT_EVIDENCE`, `BEHAVIOR_INFORMED` 중 하나다.

`instructionGranularity`는 `COMPLETE_TASK`, `ONE_STEP`, `ONE_ACTION` 중 하나다.

---

## 8. LLM에 전달하지 않는 데이터

- `memberId`
- 사용자 이름, 이메일, 생년월일과 인증정보
- `sessionId`
- 내부 `taskId`
- 행동 로그 ID
- 정규화 이벤트 ID
- 프로파일 스냅샷 ID
- 퀘스트와 장소의 내부 DB UUID
- 원본 행동 로그 payload
- 현재 퀘스트와 관련 없는 기술 프로파일
- 훈련 세션별 내부 식별자와 전체 이력

LLM에는 위 데이터가 제거된 `LlmSimulationGenerationInput`만 전달한다.
