# 버스 재제작 · 2026-10-01

## 그림과 공간

- 내부와 양쪽 외관을 built-in imagegen으로 새로 만들었다. 원본 플레이어의 갈색 선·차분한 색채를 스타일 참고로 사용했다. 실제 한국 버스 배치의 출처는 `bus-reference-research.md`에 유지한다.
- 내부는 756×2079 PNG의 원래 비율을 보존해 350×963으로 표시한다. 캔버스 440×1080 안에서 수평 카메라를 고정해 모바일 폭 375에서도 양쪽 차체와 도로가 보인다.
- 왼쪽 운전석에 실제 앉은 기사, 오른쪽 앞문·중문, 전방을 향한 좌석, 중문 뒤 좌석을 유지한다. 반대쪽 외관은 별도로 생성하여 운전석 쪽에 잘못된 승객문을 그리지 않았다.
- 생성 PNG의 모서리 알파 0을 확인했다. 둥근 차체 밖은 투명하며, 코드로 그린 도로 위에 얹는다. 전진할 때만 차선이 아래로 흐르고, 정차·메뉴·동작 줄이기에서는 이동 효과를 멈춘다.

## 동작

- 마을과 다른 정류장의 버스 선택 화면은 `BusArrivalPreview`를 공유한다. 감속 진입 1,100ms, 가속 이탈 760ms, 작은 서스펜션 흔들림을 사용한다.
- 버스를 넘겨도 기존 차를 즉시 지우지 않고 화면 밖으로 보낸 뒤 다음 차를 들인다. 진입 중에는 타기·다음 버스·기사 대화를 잠근다. 기존 차가 떠나는 동안 방향이 뒤집히지 않는다.
- 정류장 노선과 스마트폰 앱은 동일한 실제 게임 노선 데이터를 사용한다. 마을 앞에서 도서관은 201번이고, 305번은 체육관으로 분기한다.
- 좌석은 선택 사항이다. 카드를 찍고 손잡이를 잡아 서서 갈 수 있다. 안전한 위치 종류를 세션에 기록하고, 정차 후 손잡이 놓기 또는 일어나기를 선택해 하차 단말기로 이동한다.
- 앉으면 480ms 동안 좌석으로 움직인 뒤 후면 idle을 사용한다. 하체를 자르고 등받이를 앞에 그린다. 일어나면 충돌 없는 통로 위치를 복원한다.
- 스마트폰 바로 이동은 현재 승차·주행을 종료하고 선택한 마을로 이동한다. 이동 치트로 완료 이벤트를 만들지 않는다.

## 검증

타입 검사 통과. 버스 관련 7개 Jest suite, 129개 테스트 통과:

- 모든 상호작용 지점의 충돌·경로와 실제 프레임 이동
- 마을 → 버스 → 도서관 출근 → 귀가 흐름
- 입석 이동과 정차 후 하차
- 앉기 전환·후면 idle·하체 가림
- 입출차 대기·방향 유지·오래된 애니메이션 콜백 무시
- 도로 전진 방향, 메뉴 정지, 동작 줄이기
- 앱 백그라운드·대화·메뉴의 시간 정지 및 저장
