# 작은 공공도서관 분류 조사와 게임 적용

조사일: 2026-09-29

2026-10-01 추가 구현: 같은 KDC 대분류 10개를 유지하면서 가상 도서를 52권으로 늘렸다. 한 근무 12권·최대 6권 운반을 적용했으며, 사용자 검색 자리에서 제목·소수점 분류번호·현재 위치를 확인한다. 업무 수첩의 도서 알바 가이드북에 아래 조사 내용의 청구기호 구성·배가 방향·훼손 자료 보고·이용자 안내·완료 보고를 여섯 장으로 옮겼다. 책 제목과 도서기호는 창작 자료이며 실제 도서를 분류한 목록이 아니다. 최초 구현 숫자가 남아 있는 아래 날짜별 항목은 당시 기록이다.

## 조사 목적

도서관 보조 업무에서 필요한 **책등 라벨 확인 → 서가 찾기 → 이상 자료를 담당자에게 전달하기 → 이용자에게 위치 안내하기**를 연습할 수 있도록, 실제 작은도서관 운영 자료를 확인했다.

## 실제 분류는 무엇인가

인천광역시의 『작은도서관 운영 매뉴얼 및 사례집(2022)』은 한국십진분류법 **KDC 6판**을 안내한다. 숫자로 주제를 나누며, 작은도서관도 아래 10개 큰 분류를 사용할 수 있다. [인천광역시 매뉴얼, 인쇄면 20–23쪽](https://ebook.incheon.go.kr/e-book/access/ecatalogt.jsp?Dir=483&callmode=normal&catimage=&eclang=ko&start=12&um=s)

| 번호 | 실제 분류명 | 책의 주제 예시 |
|---|---|---|
| 000 | 총류 | 백과사전, 컴퓨터, 도서관 |
| 100 | 철학 | 철학, 심리, 윤리 |
| 200 | 종교 | 불교, 기독교 등 |
| 300 | 사회과학 | 경제, 교육, 법, 사회 |
| 400 | 자연과학 | 수학, 우주, 식물, 동물 |
| 500 | 기술과학 | 의학, 농업, 기계, 요리 |
| 600 | 예술 | 미술, 음악, 스포츠 |
| 700 | 언어 | 한국어, 영어 등 |
| 800 | 문학 | 소설, 동화, 시 |
| 900 | 역사 | 역사, 지리, 여행, 전기 |

현재 공공도서관 운영 사례도 확인했다. 경상남도교육청 마산도서관의 2026년 9월 자료 현황은 위 000–900 분류를 그대로 사용한다. [마산도서관 자료 현황](https://mslib.gne.go.kr/menu.es?mid=a40802000000)

## 책을 어디에 꽂는지 판단하는 방법

책등의 **청구기호**가 위치를 알려 준다. 분류번호로 주제를 찾고, 같은 번호 안에서는 도서기호를 확인한다. 필요에 따라 별치기호·권차·복본 표시도 붙는다. 예컨대 아동 자료나 참고 자료의 위치를 따로 정할 수 있다. [국립중앙도서관 청구기호 설명](https://www.nl.go.kr/NL/contents/N30501000000.do?ackRecKey=5540806&schM=view)

일반적인 배열은 청구기호를 따라 왼쪽에서 오른쪽, 위에서 아래로 이어진다. 경기도교육청 운영 자료에서도 이 방향과 서가의 주제·분류번호 안내판을 설명한다. 이 자료는 학교도서관 지침이며, 실제 근무지의 별도 배치 규칙은 담당자에게 확인해야 한다. [경기도교육청 자료관리 지침, 인쇄면 18쪽](https://www.goe.go.kr/resource/old/BBSMSTR_000000030141/BBS_202205161035142881.pdf)

인천 매뉴얼은 책등 아래쪽의 청구기호 라벨과 색띠가 검색·배가를 돕는다고 설명한다. 훼손된 책은 다른 서가 자료와 섞이지 않도록 따로 보관하도록 안내한다. 게임의 라벨 훼손 → 사서 확인 → 확인함 전달은 이 업무를 연습하도록 구성했다. 색은 우리 게임의 보조 표시이며, 실제 근무지의 라벨 색을 따라야 한다. [인천광역시 매뉴얼, 인쇄면 24–27쪽](https://ebook.incheon.go.kr/e-book/access/ecatalogt.jsp?Dir=483&callmode=normal&catimage=&eclang=ko&start=14&um=s)

## 이번 게임에 반영한 내용

1. 서가에 **000 총류부터 900 역사까지 KDC 대분류 10개**를 적용하고, 각 분류에서 책을 정리할 수 있게 했다.
2. 책등 라벨을 `분류번호 / 도서기호` 두 줄 형식으로 바꿨다. 책과 도서기호는 게임용 가상 자료다.
3. `480 → 400 자연과학`처럼 분류번호로 서가를 찾는 예시와 전체 10개 분류표를 업무 수첩에 넣었다.
4. 라벨을 확인할 수 없는 책은 사서에게 물어보고 확인함에 전달한다.
5. 이용자가 찾는 책의 위치를 검색한 뒤 해당 분류로 안내하거나 사서에게 연결한다.
6. 전체 26권 중 서로 다른 여섯 분류에서 한 권씩 맡는다. 정상 라벨 5권은 해당 서가로, 훼손 라벨 1권은 사서 확인 후 확인함으로 옮긴다. 이용자 요청도 10개 분류 전체에서 나온다.

이번 버전의 학습 범위는 **큰 분류를 찾아 제자리 서가에 옮기는 첫 단계**다. 같은 서가 안에서 소수점·도서기호·권차·복본까지 비교하여 한 권씩 순서를 정하는 과제는 후속 단계로 확장할 수 있다. 실제 자료를 새로 분류하거나 청구기호를 부여하는 일은 사서의 기준과 해당 기관의 목록 규칙을 따라야 한다.

## 2026-10-01 전체 분류 도서 확장

기존 자연과학·기술과학·문학 각 4권은 유지하고, 다음 가상 훈련 도서 14권을 추가했다. 서가 번호와 분류명은 실제 KDC를 따른다. 제목·도서기호·표지 그림은 게임용 창작 자료다.

| 서가 | 추가한 도서 | 책등 분류번호 |
|---|---|---|
| 000 총류 | 처음 만나는 컴퓨터 / 도서관 사용 설명서 | 004 / 020 |
| 100 철학 | 내 마음의 색깔 / 생각이 자라는 질문 | 180 / 100 |
| 200 종교 | 세계의 종교 이야기 / 산사의 풍경 소리 | 200 / 220 |
| 300 사회과학 | 우리 동네 일하는 사람들 / 돈은 어디로 갈까 | 321.55 / 320 |
| 600 예술 | 색연필로 그리는 하루 / 악기들의 작은 음악회 | 650 / 670 |
| 700 언어 | 우리말 낱말 여행 / 영어로 인사해요 | 710 / 740 |
| 900 역사 | 처음 읽는 한국사 / 지도로 만나는 세계 | 911 / 980 |

분류번호의 주제는 [문화체육관광부 도서관 운영 자료의 KDC 분류표](https://www.mcst.go.kr/slibrary/contents/2013/04/05/DATA_SHARE_BOARD_20_43.pdf)를 참고했다. 직업 안내 자료의 321.55 사용은 [행정안전부 행정자료실 소장자료](https://lib.mois.go.kr/search/DetailView.ax?cid=55655)에서도 확인했다.

매 근무에서 먼저 분류 6개를 같은 확률로 뽑은 다음 그 분류의 책을 선택한다. 기존 세 분류에 책이 더 많더라도 새 분류가 덜 배정되지 않는다. 이용자 요청은 맡은 책과 겹치지 않는 별도 책이며, 모든 분류에서 선택될 수 있다. 동일한 seed와 행동 순서에서는 배정과 결과가 재현된다.

확장 검증: 도서관 관련 9개 테스트 파일·107개 테스트, 타입 검사, 웹 빌드를 통과했다. 분류별 배정·오배가 수정·이용자 안내·완료 보고, 기존 기록 읽기, 서가 사이 이동과 충돌을 확인했다. 브라우저의 375×812 화면에서 새 종교 도서의 훼손 라벨 전달과 새 영어 도서의 700 서가 배치를 직접 확인했다. 신규 표지 14종은 `frontend/assets/images/game/library/books-v3/`에 있으며 정확한 생성 프롬프트와 원본·최적화 파일의 검수 기록을 함께 보관한다.

## 공간·조작·모바일 표시 변경

- 바닥 면적: 960×880에서 1360×1240으로 약 2배. 화면을 방 전체에 맞춰 축소하지 않고 카메라가 캐릭터를 따라간다.
- 캐릭터: 기본 표시 높이 약 106px, 사서도 105px. 기존 모바일 375px 화면의 약 75px보다 크게 보인다. 서가·책상은 인물에 맞게 비율을 조정했다.
- 서가: 기존 형태를 포함해 3종. 다른 책 배열의 이미지와 PC 열람석 3개를 추가했다.
- 공통 조작: 마을·마트·집·도서관에서 같은 이동 패드와 상호작용 버튼을 사용한다. 기본은 패드를 미는 거리에 따른 걷기·달리기이며, 휴대폰 설정에서 버튼 방식으로 바꿀 수 있다.
- 조이스틱 모드에서는 오브젝트를 눌러 먼 곳으로 자동 이동하지 않는다. 터치 이동 모드에서는 해당 기능을 유지한다.
- 캐릭터 그림 로딩은 프레임마다 파일을 바꾸던 구조를 방향별 atlas로 변경했다.

## 캐릭터 로딩 문제와 수정

기존 구조는 개별 PNG 274개를 사용하고, 첫 대기 동작부터 약 37개 파일을 요청했다. 방향을 바꾸면 해당 방향의 프레임들을 추가로 미리 읽고, 매 프레임 새 이미지의 로드 완료에 의존했다. 외부 개발 터널의 응답 지연과 모바일 이미지 디코딩 시간이 애니메이션 재생에 직접 영향을 주는 구조였다.

이를 방향·동작별 **18개 묶음 이미지(atlas)**로 바꿨다. 현재 방향의 묶음만 읽고, 로딩을 마치면 한 Image 안에서 표시 좌표만 이동한다. 초기 요청은 작은 대체 자세와 현재 대기 atlas이며, atlas 다운로드는 동시에 최대 2개다. 8초 지연 또는 오류에는 대기 자세를 유지하고, 늦게 도착한 이전 방향 이미지가 현재 방향을 덮어쓰지 않도록 했다.

프레임 그림은 1x·2x 모두 원본 픽셀과 대조했다. 전체 묶음의 파일 합계는 SD 6,407,348바이트, HD 20,105,558바이트다. 기존 전체 합계는 각각 7,125,618 / 21,791,858바이트였다. 화면 배율과 기기 픽셀 비율에 맞춰 해상도를 선택하므로 scale 0.5인 2x 기기에서는 불필요한 HD 대신 SD를 사용한다. 이 수치는 **전체 자산 합계**이며, 최초 접속 때 전부 다운로드한다는 의미는 아니다.

첫 실행의 외부 터널 다운로드 자체는 남는다. 브라우저와 자동 테스트에서는 표시·전환을 확인했으며, 실제 Expo Go 기기의 프레임률과 체감 개선 정도는 아직 측정하지 않았다.
