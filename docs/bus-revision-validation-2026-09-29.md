# 버스 공간·마을 연결 수정 검증

검증일: 2026-09-29. 브랜치: `feat/8-시뮬레이션-게임-ui-제작`.

## 적용 결과

- 한국·일본 제조사 실내 사진과 배치도를 확인하고 한국형 구조로 실내를 다시 제작했다. 전방은 화면 위, 운전석은 왼쪽, 앞문과 중문은 오른쪽이다. 기사는 실내 원화 안에서 운전석에 앉아 전방을 바라본다.
- 플레이어는 기존 뒷모습 아틀라스를 재사용한다. 앉는 좌표와 접근 좌표를 분리하고, 좌석 등받이를 몸 앞에 그린다. 일어날 때는 통로의 충돌 없는 위치로 복귀한다.
- 실제 마을 정류장에서 목적지를 고르고 승차한다. 별도의 버스 게임 진입 카드와 중복된 출발 마을을 없앴다. 도서관 도착 보고는 도서관 업무로 이어지고, 업무에서 나오면 도서관 앞 거리에 서며, 귀가 버스를 타면 원래 마을 정류장으로 돌아온다.
- 현재 할 일 하나를 상단에 표시한다. 화면 밖 목표에는 작은 방향 표시를 붙였다. 조이스틱에서는 안내만 하며, 터치 이동에서는 누르면 충돌을 피하는 경로로 이동한다. 맞는 버스가 도착하면 기다리기 안내를 승차 안내로 바꾼다.
- 공통 이동·상호작용·휴대폰 UI와 캐릭터 아틀라스, 조작 설정을 유지한다.

## 실행 검사

| 검사 | 결과 |
| --- | --- |
| 전체 Jest | 68개 묶음, 763개 테스트 통과 |
| 마지막 안내 수정 후 관련 Jest | 6개 묶음, 53개 테스트 통과 |
| TypeScript | `pnpm typecheck` 통과 |
| 웹 배포 빌드 | `pnpm build:web` 통과, 901개 모듈 |
| Git 공백 검사 | `git diff --check` 통과 |

전체 Jest를 먼저 실행한 뒤 방향 안내·도착 안내를 보완했으므로 마지막 결과는 관련 테스트 재실행으로 확인했다. 기존 테스트의 일부 React act 경고 및 RN Web pointerEvents 사용 중단 경고는 남아 있다.

`expo install --check`는 현재 설치된 Expo 계열 패키지 10개의 패치 버전 차이를 안내하며 종료 코드 1을 반환했다. 이번 버스 수정에서는 의존성을 바꾸지 않았다. SDK를 임의로 올리거나 내리지 않았다.

## 브라우저에서 직접 플레이한 경로

1. 기존 마을 정류장 → 하늘도서관 목적지 선택 → 201번 승차.
2. 승차 카드 → 통로 이동 → 전방 좌석에 착석 → 하차벨 → 정차 → 일어나기 → 하차 카드 → 중문 하차.
3. 도서관 앞 횡단보도에서 신호·차량 확인 → 건너기 → 실제 도서관 입장 → 사서에게 출근 보고 → 도서관 업무 화면.
4. 업무 화면 출입문 → 밖으로 나가기 → 도서관 앞 거리 → 느티광장 방면 정류장 → 201번 귀가 승차.
5. 카드·착석·마을앞 하차 요청·하차 카드·중문을 거쳐 원래 마을 정류장 복귀.

390×844, 375×667, 768×1024 웹 뷰포트에서 배치와 조작을 확인했다. 물리적인 iPhone/Android 기기의 Expo Go 직접 조작은 이번 검증에 포함되지 않는다. 실행 중인 외부 Expo manifest의 SDK 57·계정·응답은 확인했다.
