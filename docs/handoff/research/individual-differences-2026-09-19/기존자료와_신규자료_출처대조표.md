# 기존 자료와 신규 자료의 출처 대조표

이번에 검토한 고유 출처는 29건이다. 기존 자료 재검토 8건과 이번 신규 수집 21건을 구분했다. 신규는 이번에 새로 찾았다는 뜻이며 최근에 출판되었다는 뜻은 아니다.

기존 169건 전체를 다시 읽은 것은 아니다. 검토한 부분과 직접 접근 여부를 아래에 기록했다. S05와 S06은 초록 한정이다. WHO는 공식 발행정보와 대조한 외부 저장소 원문 사본을 읽었고, 일부 논문은 원문 검색 색인 또는 저자 원고로 확인했다. 전체 원문을 읽은 자료와 동일하게 표시하지 않았다.

기존 두 출처 목록의 SHA256은 조사 시작 때와 종료 검증 때 같았다. 출처별 요약과 서지정보를 작성했으며 원문 전문·진단검사지·공식 중증도표를 이 폴더에 복제하지 않았다. 공개 열람 가능 여부와 모델 학습·재배포 허용 여부는 다르다. 후속 이용 시 원출처 조건을 별도로 확인해야 한다.
