# 관찰 사례와 게임 설계 제안

작성일: 2026-10-17. 이 문서의 상황과 기능은 이번 문헌을 바탕으로 만든 **설계 가설**이다. 실제 당사자 관찰 기록, 진단 기준, 이미 검증된 게임 효과가 아니다. 이번 요청에서는 게임 코드를 바꾸지 않았다.

## 행동을 관찰할 때 던질 질문

아래 사례는 “발달장애인은 이렇게 행동한다”는 목록이 아니다. 비장애인에게도 나타날 수 있으며, 한 사람 안에서도 장소·설명·건강·경험에 따라 달라질 수 있다. 어떤 장면이 막혔을 때 **대안 설명을 놓치지 않기 위한 질문 목록**이다.

| 관찰 가능한 상황 | 구분해서 확인할 가능성 | 확인 질문 또는 지원 후보 |
| --- | --- | --- |
| 설명 뒤 한동안 행동하지 않음 | 읽는 중, 시작점 불명확, 생각 정리, 입력 오류, 선택 보류 | “어디서 시작할지 볼까요?” / 기다리기 / 첫 단계만 보기 |
| 같은 질문을 다시 함 | 이전 답이 길었음, 조건이 바뀜, 기억 확인, 안심이 필요함 | 같은 내용을 짧고 일관되게 재제시하고 질문할 기회를 유지 |
| “네”라고 답했지만 다른 행동을 함 | 동의·이해·대화 이어가기의 차이, 질문 자체의 모호함 | “어느 쪽을 원해요?”처럼 실제 선택을 확인하고 ‘모르겠어요’ 허용 |
| 말은 유창하지만 여러 단계에서 막힘 | 표현 능력과 과제의 기억·계획 요구가 다름 | 말투로 난이도를 추정하지 말고 수행 단계와 지원 조건 관찰 |
| 대답이 짧거나 말 대신 가리킴 | 선호 표현 방식, 말 산출 부담, 낯선 상대 | 그림 선택·가리키기·문자 등 가능한 응답 수단 확인 |
| 손이나 몸을 반복적으로 움직임 | 즐거움, 집중, 감각·감정 조절 등 개인별 의미 | 본인이 불편한지 먼저 확인; 해롭지 않은 움직임을 감점하지 않기 |
| 소리가 나는 장소를 피함 | 특정 음량·음색·예측 불가능한 소리의 불편 | 음성·효과음·배경음을 각각 조절하고 조용한 방식 제공 |
| 북적이는 장면에서 멈춤 | 동시 정보량, 충돌하는 안내, 감각 부담, 길 찾기 | 손님 수·동시 요청·안내량을 각각 조절하여 조건 비교 |
| 익숙한 순서만 선택함 | 효율적 전략, 성공 경험, 다른 선택을 모름, 변화의 불확실성 | 변경 이유·바뀌지 않는 부분·대안을 미리 보여주기 |
| 한 활동에서 다른 활동으로 옮기기 어려움 | 전환 신호가 약함, 미완료 느낌, 시작/중단의 어려움 | 현재 단계 저장, 다음 단계 예고, 본인이 전환 시점 선택 |
| 직원이 먼저 말할 때까지 기다림 | 도움을 요청할 위치/말을 모름, 과거 경험, 신중한 선택 | “다시 알려주세요”를 실제로 도움이 오는 선택지로 연결 |
| 쉬운 과제에도 확인을 자주 요청함 | 확신 부족, 피드백 불명확, 실수 비용 걱정 | 확인 요청을 허용하고 완료 상태·되돌리기를 명확히 표시 |
| 특정 주제에서는 오래 집중함 | 흥미·경험·익숙함에 따른 강점 | 좋아하는 책·동선·직무 선택을 과제 진입점으로 사용 |
| 처음 장소에서는 성공하고 다른 장소에서는 막힘 | 배치·표현·색·직원·절차 차이 | 한 번에 한 조건씩 바꿔 연습하고 원래 단서도 다시 확인 가능하게 |
| 올바른 물건을 선택했으나 옮기지 못함 | 작은 터치 영역, 드래그 정밀도, 기기 지연 | 탭→담기 대체 조작; 분류 판단과 입력 성공을 별도 집계 |
| 긴 설명에서 중간 내용을 놓침 | 문장 구조, 낯선 단어, 기억 요구, 방해 자극 | 한 행동씩 분리하고 원래 설명을 언제든 다시 보기 |
| 제안받은 것을 바로 받아들임 | 진짜 선호, 상대에 대한 신뢰, 다른 선택 기회 부족 | 거절·보류·다른 사람에게 확인하기를 동등한 선택으로 제시 |
| 불편한 요청을 거절함 | 자기결정, 싫은 이유, 피로, 불충분한 설명 | 이유를 강요하지 않고 거절 존중; 가능하면 대안 제안 |
| 평소보다 말·활동이 줄어듦 | 피로·수면·통증·스트레스·환경 변화 등 | 본인이 표현할 수 있게 지원하고 실제 현장에서는 필요한 건강 확인 |
| 잘 하다가 반복해 실수함 | 피로, 과제량, 지루함, 새 조건, 시스템 문제 | 휴식·다른 활동·과제량 조절을 선택하게 하고 조건 기록 |
| 수상한 연락을 혼자 처리하려 함 | 정상 연락과의 구분 어려움, 관계 유지, 도움 요청 부담 | 처벌 없는 상담·보류 경로와 ‘이미 눌렀어요’ 회복 경로 |
| 안전을 이유로 모든 활동을 피함 | 위험 안내만 배웠음, 성공 경험 부족, 접근 장벽 | 피해야 할 상황뿐 아니라 안전하게 계속하는 방법도 연습 |

근거와 적용 범위는 [감각·의사소통](02_감각_의사소통_자기조절.md), [자기결정·안전·직업](03_자기결정_안전_직업생활.md), [건강·환경](01_행동을_읽는_기준과_건강_환경.md)에 있다. 표의 모든 가능성을 한 사람에게 붙이거나 게임 로그로 확정하지 않는다.

## 오늘도에 연결할 구체적 후보

아래 기능은 구현 계획 후보이며 이번에 적용한 변경사항이 아니다. 모든 지원을 강제로 켜는 방식보다 사용자가 고르고 조절할 수 있는 방식을 우선한다.

### 1 도움을 잘 쓰는 것도 성공으로 인정

장보기에서 직원에게 수량을 확인하거나 도서관에서 사서에게 청구기호를 다시 묻는 행동에 실제 도움이 이어지게 한다. 결과 화면은 독립 수행, 선택한 도움, 오류에서 회복한 과정을 나눠 보여준다. 도움 사용 횟수 자체를 실패 점수로 삼지 않는다.

### 2 기다릴 시간과 읽을 시간을 분리

버스 출발의 연출 시간과 안내문을 읽는 시간을 같은 타이머로 처리하지 않는다. 노선도를 펼친 동안에는 충분히 살펴볼 수 있고, 실제 대기·출발 연습은 별도 선택으로 둔다. 느린 응답을 자동 오답으로 처리하지 않는다.

### 3 갑작스러운 변화는 난이도 한 축으로

품절, 서가 위치 변경, 버스 도착 순서 변경, 카페 주문 수정 가운데 한 가지만 선택해서 연습한다. 변경을 먼저 알려주는 연습과 현장에서 알아차리는 연습을 분리한다. 화면 전체를 예고 없이 뒤바꿔 혼란을 만드는 방식은 피한다.

### 4 분류와 조작의 실패를 구별

빨래방에서 옷을 올바른 바구니로 선택했는데 드래그가 실패하면 옷 선택은 유지한다. 탭으로 선택한 뒤 바구니를 누르는 방식으로 이어갈 수 있게 한다. 사용자가 아는 내용을 손 조작 때문에 다시 설명받게 하지 않는다.

### 5 조용한 환경과 활기 있는 환경을 모두 선택

음성·효과음·배경음, 장식 애니메이션, 화면 흔들림을 구분해서 조절한다. 조용하게 설정했다고 손님·업무·보상이 사라지지 않게 한다. 감각 자극을 견디는 것을 목표로 점수를 주지 않는다.

### 6 거절과 보류가 실제로 작동하는 대화

카페 손님에게 “지금 주문부터 마친 뒤 도와드릴게요”, 친구에게 “오늘은 쉬고 싶어요”, 수상한 연락에 “먼저 확인할게요”를 고를 수 있게 한다. 무조건 친절하게 승낙하는 경로만 정답으로 만들지 않는다.

### 7 상대도 의사소통을 조정

사서·직원 NPC가 복잡하게 설명했다면 짧게 다시 말하고, 사진이나 물건을 함께 보여주게 한다. 사용자가 상대의 의도를 추측하는 문제만 반복하지 않는다. 대화 실패를 플레이어 한쪽의 결함으로만 묘사하지 않는다.

### 8 안전 학습에 회복 장면 추가

보이스피싱에서 잘못 누르거나 개인정보를 일부 보낸 상황에도 중단·신뢰할 수 있는 상대에게 알리기·공식 경로로 확인하기를 연습한다. 현실 연락이나 실제 개인정보 입력을 요구하지 않는다. 실수하면 혼날 것 같아 숨기는 경험을 게임이 강화하지 않게 한다.

### 9 성인다운 흥미와 자기 방식 유지

좋아하는 책 분야, 방문 순서, 쉬는 장소, 카페에서 맡고 싶은 일을 고르게 한다. 단순한 UI와 유아적인 말투는 별개다. 지시를 잘 따르는지 외에 원하는 활동을 골랐는지, 완성에 만족하는지도 다룬다.

### 10 전이는 별도 연습으로

같은 분류 원리를 다른 책 표지·서가 배치에서 사용하거나, 같은 노선 판단을 다른 정류장에서 해보는 식으로 변형한다. 화면에서 한 번 성공한 것, 다른 게임 조건에서 성공한 것, 실제 생활에서 성공한 것을 각각 구분한다. 실제 현장 적용은 당사자·지원자의 선택과 적절한 지원 아래 따로 확인한다.

### 11 쉬고 돌아와도 흐름이 보이게

“어디까지 했는지”를 짧게 보여주고 이어서 할지 다시 설명을 볼지 고르게 한다. 휴식이나 도움 요청 때문에 연속 성공 보상이 깨지는 구조는 다시 검토한다. 단, 이는 저장 기능의 구현을 뜻하지 않는다.

### 12 직무의 결과가 눈에 보이게

도서관의 정리된 책, 손님에게 전달된 음료, 접어 넣은 빨래처럼 자신의 행동이 환경을 바꾸는 결과를 보여준다. 직원의 칭찬 문장만 길게 붙이지 않고 무엇을 해냈는지 확인하게 한다. 빠른 수행만 보상하기보다 정확성·선택·안전·복구를 함께 다룬다.

## 설정은 진단명 대신 과제 조건으로

| 조절 축 | 선택 예시 | 목적 |
| --- | --- | --- |
| 한 번에 보이는 정보 | 한 단계 / 전체 순서 | 현재 단계와 계획 확인의 선호 구분 |
| 설명 방식 | 글 / 음성 / 그림과 글 | 표현 방식 선택 |
| 진행 시간 | 직접 다음 / 예고 후 진행 | 읽는 시간과 전환 선택 |
| 도움 강도 | 요청 시 / 첫 단계 / 시범 | 연습 목표와 지원 수준 맞추기 |
| 정보량 | 물건 수·동시 주문 수·선택지 수 | 실제 과제 부담 조절 |
| 변화 수준 | 고정 / 한 가지 변화 / 복합 변화 | 익숙함과 변형 연습 구분 |
| 감각 환경 | 소리 종류·움직임·밀도 | 자극과 과제 내용을 분리 |
| 입력 방식 | 탭 / 드래그 / 공통 이동 패드 | 운동·기기 조건과 지식 평가 분리 |
| 사회적 요구 | 혼자 / 직원 도움 / 손님 요청 | 상대와 함께 하는 과제 선택 |
| 실패 후 경로 | 취소 / 수정 / 다시 설명 | 회복 가능한 수행 구조 |

이 값을 장애 등급·IQ·진단명에서 자동 산출하지 않는다. 선호와 수행에 맞춰 설정하고, 같은 사람도 다른 날·다른 과제에서 다르게 선택할 수 있게 한다.

## 효과를 확인할 때 남길 질문

1. 당사자가 이 활동을 하고 싶었는가? 중단·거절 선택이 실제로 가능했는가?
2. 무엇을 하라는지 알았는가, 그리고 버튼을 실제로 사용할 수 있었는가?
3. 어떤 지원을 골랐고 그 뒤 무엇이 달라졌는가?
4. 속도 외에 과제 완수·오류 복구·안전한 확인·만족을 각각 볼 수 있는가?
5. 다른 그림·배치·상대에서도 가능한가? 실제 생활 결과와 혼동하지 않았는가?

이번에는 문헌 조사만 수행했다. 당사자·가족·현장 전문가의 사용성 검토와 교육 효과 연구를 대신하지 않는다.
