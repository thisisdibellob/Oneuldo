## 두 실행 모드의 범위

**A (`stochastic`)**는 세 프로필 모두 `attention`을 읽어 제한된 관찰·기억·현재 주의 상태로 의도를 계획하고, `shoppingStyle`의 구조화된 값으로 비교·확인·선택·이동 성향을 적용한다. 개인 관심은 프로필에 유지하고, 배치·게임 조작을 처음 경험하는지는 `attentionExperience`로 분리한다. 본문의 모든 심리·사회적 내용이나 character의 자연어 문장을 실행 코드가 해석하는 것은 아니다.

**B (`llm`)**는 선택한 인물의 `prompt`를 실제 모델에 제공하고 다음 게임 행동을 요청한다. 세 prompt 모두 두 원자료 전문과 각각의 개인 설정을 포함한다. 원문을 전달했다고 해서 모델이 모든 원칙을 항상 지키거나 실제 사람을 정확히 재현한다고 보장하지 않는다. 원자료가 언급하는 생각이나 감정은 장문의 내부 사고 과정으로 출력하지 않는다. 지원하는 액션과 짧은 관찰 가능한 기술을 쓰며, 게임에 없는 발화·음성·표정 행동을 생성했다고 기록하지 않는다.

서연 attention은 사과·카레/농산물의 약한 개인 관심, capture .10, 관심 구매 .05, 복귀 .85, 관심 단계 1–3이다. 민수는 초코 우유·청사과·매운 카레 관심, capture .35, 관심 구매 .15, 복귀 .80, 관심 단계 1–2다. 두 인물은 목표 기억 4, 공간 기억 96, 초회 주변 살피기 1단계로 설정하고 주의 전환 시 목표 기억 변화는 각각 .02/.03이다. 이것도 합성 조건값이며 실제 인간의 용량·빈도 자료가 아니다. `first-play`/`revisit`는 계속 회차 옵션으로 분리한다.

가격 비교는 관찰한 대안의 이름·규격과 목표를 함께 고려하는 행동이다. 특정 상품 하나를 지정한 목표를 무시하고 가장 싼 상품으로 바꾸거나 선택지가 없는 상황에서 절약 효과를 주장하지 않는다. 민수의 친숙한 선택은 맞을 수도 틀릴 수도 있고, 지민의 관심은 구매로 이어지지 않을 수도 있다. 성공·실수·이탈의 의무 횟수나 제출 전 자동 정답 복구는 두지 않는다. 설정의 적용은 실제 trace의 비교 페이지·목록/장바구니 확인·선택·관심 이동·방향 전환에서 확인해야 한다.

확인 후 수정은 실제로 살핀 장바구니와 현재 기억하는 목표를 대조할 때 선택한다. 이때 알아차린 오선택·초과수량을 반품 대상으로 기억하고, 해당 매대에서는 직접 빼거나 도움 성향과 기억한 직원이 있으면 반품 도움을 요청한다. 개인 관심으로 의도해 산 수량은 별도로 보존한다. 숨겨진 정답으로 장바구니 전체를 자동 교정하거나 아직 발견하지 않은 직원에게 전역 경로로 이동하지 않는다.

상품명으로 구역을 짐작하지 못하면 이미 발견한 매대 중 그 목표를 위해 아직 조사하지 않은 곳을 열어 실제 페이지를 살핀다. 조사한 매대는 목표별로 기억한다. 예를 들어 멜론의 위치를 원래부터 안다고 추가 설정하는 대신 관찰과 탐색으로 찾을 수 있다. 이는 모든 탐색의 완료를 보장하는 장치가 아니며, 기술적 생성 상한 초과는 계속 실패 표본으로 구분한다.
