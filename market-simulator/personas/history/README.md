# 페르소나 이전 버전

역사 보존용 사본이다. 코드와 생성기는 이 폴더를 읽지 않는다.

- 현재 실행 정의는 상위 폴더의 JSON(`mild-intellectual-disability-adult.json`, `careful-checker.json`, `quick-decider.json`)이다.
- 읽기용 현재 프롬프트는 상위 폴더의 `persona-mild-intellectual-disability-adult-v5.md`, `persona-careful-checker-v3.md`, `persona-quick-decider-v3.md`다.
- 이 폴더의 문서는 당시 본문을 수정하지 않고 보존한다. 문서 안의 "현재 실행 정의" 같은 표현은 작성 당시 기준이다.
