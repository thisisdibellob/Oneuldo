# P01 합성 사용자 반복 플레이 예비 실험

실제 참가자가 아닌 AI 역할 시뮬레이션이다. 지적장애가 있는 가상의 성인을 설정하며 장애인 전체를 대표하지 않는다. 실제 교육 효과, 임상적 능력 변화, 타당화 결과로 사용하지 않는다.

## 시작 조건
- 게임 경험 없음. 익숙한 상품명과 짧은 지시는 이해한다.
- 낯선 화면에서 여러 품목과 수량을 동시에 기억하는 데 어려움을 겪는다는 개별 가정을 둔다.
- 목록 다시 보기와 도움 요청을 선택할 수 있다. 장애명만으로 무작위 실수나 실패를 강제하지 않는다.
- 조작 도구 지연·접근성 문제는 페르소나의 어려움과 별도 기록한다.

## 절차
기본 장보기 1회 → 실제 앱의 세션 분석·프로필 갱신 → 생성된 맞춤 퀘스트 → 플레이·분석을 반복하여 총 3회 시도한다. 유효한 퀘스트가 생성되지 않으면 해당 단계의 실패를 기록하며 수동 정답 퀘스트로 대체하지 않는다.

플레이 행동은 화면에 보인 목록·상품·안내·피드백에 근거한다. 운영자로서 읽은 소스 코드, 내부 분석, 정답 또는 성공 기대를 페르소나의 지식으로 사용하지 않는다. 동일 에이전트가 운영과 역할 수행을 겸하므로 완전한 정보 차단 실험은 아니다.

매회 향상을 강제하지 않는다. 다음 회차로 이어지는 기억은 화면에서 실제 경험한 조작 방법과 피드백만 적는다. 분석이 난이도를 낮춘 결과와 동일 조건에서 능력이 변화한 결과를 구별한다. 연습 과제의 성공만으로 다른 상황으로의 전이를 주장하지 않는다.

## 기록
각 회차의 화면상 목표, 제공된 지원, 행동과 선택 이유, 원본 세션 ID, AI 분석·프로필·퀘스트 원문과 ID, 처리 시간, 검증 오류, 실제로 노출된 교육 피드백을 저장한다. 성공 여부와 지원·난이도 판단은 기존 AI 파이프라인에 맡긴다.
