# 오늘도 함께 — 보호자 앱

기존 자녀용 게임 앱과 독립된 Expo / React Native 프로젝트다. 자체 package.json, pnpm 잠금 파일, 에셋, 앱 식별자와 Metro 서버를 가진다. frontend 소스·node_modules·환경 파일을 가져와 실행하지 않는다. 같은 공식 저장소 안에서 관리하지만 별도로 설치·빌드·배포한다.

## 실행

```powershell
cd guardian-app
pnpm install --frozen-lockfile
pnpm start
# 외부 휴대폰 연결
pnpm start:tunnel
# 브라우저
pnpm web
```

기본 포트는 8082다. 자녀 게임의 8081 서버와 구분한다. Expo SDK 57 / React Native 0.86 / React 19를 사용한다. 기기의 Expo Go 호환과 같은 Expo 계정 로그인 여부를 확인한다. iOS/Android 실제 기기 검증은 별도다.

## 현재 동작

- 이메일·비밀번호 보호자 로그인 화면. 기존 서버 `/api/auth/login`의 PARENT 응답만 허용한다. 현재 백엔드는 일반 아이디가 아니라 이메일로 로그인한다.
- **시연 화면 둘러보기**로만 가상 데이터를 연다. 실제 로그인·조회 실패를 시연 결과로 대체하지 않는다. 모든 시연 화면과 상세 기록에 가상 데이터임을 표시한다.
- 독립적인 모바일 하단 탭 / 넓은 화면 사이드바. 자녀 선택, 최근 7/30일, 게임 종류별 기록, 요약·관찰·근거·지원 제안·분석 한계.
- 장보기 배치와 이동 경로의 연속 재생, 1/2배속, 처음/전체, 행동 시점 선택. 배치 변경 segment 사이를 연결하지 않고 정지 시간을 보존한다. 직원 대화·매대 열기/닫기·상품 담기/내려놓기 유형 지원. 경로가 없는 기록은 빈 상태를 표시한다.
- 가족 연결, 확인 후 연결 해제, 기록 새로고침, 데이터 안내, 로그아웃. 시연 코드 DEMO2026은 가상의 서준을 메모리에 추가하며 실제 계정과 통신하지 않는다.
- 앱 토큰은 메모리에만 보관하고 비밀번호는 디스크에 저장하지 않는다. 새로고침/앱 재실행 시 재로그인한다. 액세스 토큰 만료 시 로그아웃하며 자동 갱신·자동 로그인은 아직 구현하지 않았다.

## 실제 서버 연동 상태

**현재 운영 가능한 완성형 자녀 조회 서비스는 아니다.** 기존 서버의 보호자 연결·자녀 보고서 API가 아직 없으므로 기본 실행은 로그인 화면이며 시연 모드에서 전체 UI를 검토한다. 기존 게임과 backend는 이번 작업에서 수정하지 않았다. 자녀 앱의 연결 코드 발급·공유 승인 화면도 별도 구현이 필요하다.

실제 계정을 붙일 때 `.env.example`을 참고해 `.env.local`의 `EXPO_PUBLIC_GUARDIAN_API_URL`을 설정한다. 인증 서버와 아래 guardian API를 같은 주소에서 제공해야 한다. `EXPO_PUBLIC_*`에는 비밀키를 넣지 않는다. CORS에 웹 앱 출처를 허용해야 한다. 운영 연결은 HTTPS를 사용한다.

필요한 응답·연결 승인·권한·에러·경로 계약은 [docs/API.md](docs/API.md)에 정리했다. 기존 `/api/behavior-analyses/latest`는 로그인한 부모 본인의 결과이므로 자녀 결과로 사용하지 않는다. 타 자녀 또는 synthetic 응답은 실제 보고서로 받아들이지 않는다. 서버도 매 요청마다 부모–자녀의 활성 연결을 검증해야 한다.

## 화면과 데이터 해석

이 앱의 자료는 게임 수행에 관한 **훈련 분석**이다. 의료적 진단·장애 등급·현실 생활 능력 추정으로 표시하지 않는다. 시연 인물·이름·기록은 모두 가상이며 학습 효과나 실제 이용자 평가 자료가 아니다. 그래프는 수행 횟수이며 능력 점수가 아니다. 다른 난이도의 성적을 합쳐 성장률을 만들어 내지 않는다. 분석 화면을 열 때 새 AI 분석을 자동 요청하지 않는다.

Pretendard Regular/Medium/Bold와 오늘도 아이콘은 기존 저장소 에셋을 자체 assets로 복사했다. 게임 아트·엔진·LLM 모듈은 포함하지 않는다.

